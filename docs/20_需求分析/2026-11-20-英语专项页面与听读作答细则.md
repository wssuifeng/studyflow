## 1. 从课程进入，再回到原处

| 位置 | 用户看到什么 | 点击后在哪里继续 |
|---|---|---|
| 普通课知识点正文 | 练习所在小节显示「听力 · 2 题」或「阅读 · 3 题」、题组标题和一个状态按钮。「开始」用于空白轮次，「继续第 2 题」用于有草稿的轮次，「查看解析」用于已确认的题组 | 在当前主窗口进入该题组，保存原知识点、小节、正文阅读位置与触发按钮。返回时恢复这些信息，卡片同步题组状态 |
| 普通课右侧学习工具、拆出的答题工具窗 | 与正文同一题组对应一行摘要和「打开题组」。未完成的必答题组可从整课漏答提示直接定位 | 将同一主窗口带到对应题组，若工具窗已有未保存的普通答案，先完成现有保存握手再切换。正文和工具摘要都读取同一份答案 |
| 独立听力或阅读课程 | 课程列表显示练习种类。单组课点「开始」直达第一题，多组课概览列出标题、题数、状态和「继续」 | 保留课程和轮次。完成一组可进入下一组，最后一组完成后给出整课确认结果。返回课程列表后，「继续」定位最后作答的题组 |
| 作者预览 | 切换「学习者答前」「交卷后解析」查看同一题组。标出预览身份、课程位置和素材版本 | 预览用临时作答，退出回到来源材料。正式学习进度、批改队列和 TTS 额度均与预览隔离 |

**课程进度。** 题组在课程完整性检查中占一个必答项，题组内的题目和空位用于组内计分。题号目录允许先跳过，保留未完成草稿。「下一题」校验当前题后保存，「确认」检查组内所有必答题并定位首个缺项。题组确认后给出本地结果并锁定本轮答案。在嵌入场景，普通课其余作业继续由原整课动作提交。独立课最后一组的「确认」同时完成整课完整性检查，成功才显示「已提交」。本地已判的客观题只计一次，Agent 队列只领取需要批改的条目。

**题号目录与确认。** 目录用文字标示「未答」「填写中」「已答」，同时标出当前题。已答表示所有必填输入齐全并已保存。末题「确认」遇到漏答时提示具体题号并打开第一道漏题，补齐后在该题提供「确认题组」，省去再次翻到末题的操作。结果页对嵌入题组提供「返回当前知识点」，对独立课中间组提供「下一题组」。独立课最后一组先核对其他必答组，遇到漏组可继续完成，成功回执后给出「返回课程」。

**写作页的可验收行为。** 建议词数按英文词计算，内部撇号和连字符算作词的一部分，例如 `I'm well-prepared.` 显示 2 词。粘贴富文本时保留可读文字与分段，保存后重进能还原空行。建议词数作为题面参考。提交空白稿聚焦正文，非空稿成功提交后进入「待批改」。收到对应稿次的反馈后才显示修订入口，旧稿始终可回看。

**可访问操作。** 当前题号、选中项、保存失败和逐空对错均有文字表示。目录或笔记打开时焦点进入相应面板，关闭后回到原控件。选项组的方向键用于改选，播放器进度条的方向键用于定位音频，多空输入框内方向键优先用于光标移动。贴边导航只在光标到达空位边界时生效。字号放大后可滚动到全文和底部按钮。

## 3. 听力工作面

```text
返回当前知识点       Station announcement · 第 1 / 2 题       目录   笔记
暂停        00:08 ─────────── 00:20       从头重听      音量
Where will the bus leave from?
○ A   The library
○ B   The station
○ C   The museum
○ D   The school
上一题                                                    下一题
```

**播放和切题。** 首次进入由学习者点击播放。播放键、时间、可拖动进度与重听始终位于题面上方。共用同一音频的题目切换时维持当前播放时间和播放状态。换到另一段素材时先停止旧音频，新素材从头等待播放。返回课程或退出后，再进入同一素材从保存的时间暂停恢复。文件缺失时允许查看或保存已有答案，题组最终确认前要求恢复缺失资源，避免把损坏素材当成听力结果。

**单选。** 选项逐行排列，整行均可点击，选中用实心单选标记和文字状态表示。「选中」只更新草稿，点击另一项替换。方向键在选项组中移动，`Enter` 确认当前选择，`Tab` 可走到播放器、目录和底部按钮。上一题与目录可回看并改答。学习者切题时不会提前看到正误。

**补全。** 按作者给的句子片段原位排版，固定文字与标点可选中复制，每个单词空是独立输入框。支持单空和多空，换行后空位紧跟上下文，输入框以「第 2 空，共 3 空」命名。`Tab` 和 `Shift+Tab` 按顺序移动，边界方向键沿用词框导航，选区、退格和粘贴只影响当前空。空缺时确认将焦点移到首个空缺并保留其余内容。输入法组合回车只完成组字。作者在每空列出标准答案、允许变体和大小写要求。默认比较时去掉首尾空白并忽略大小写，词形与拼写按列出的答案匹配。固定标点由题干提供。

**当前句字幕。** 播放按钮与可拖动进度旁提供「当前句」开关，打开后在控件下方显示当前英文句子。首次进入题组默认关闭，按钮可用键盘切换。播放、暂停、拖动和重听均以音频播放位置为准，同组小题之间保留开关和播放状态。新 `/8` 课程可提供按秒标注的逐句时间轴，分段 WAV 合成可直接采用实际拼接时间。旧 `/7` 或没有时间轴的 `/8` 课可按原文拆句估算，界面显示「估算同步」。

**听力反馈。** 作答前可重听材料并主动查看当前句。题组确认后开放全文、答案与解析。单选按一题计，补全每空显示对错，所有空正确时该题计对。结果页同时显示「答对题数」和「补全答对空数」，练习结果按题数汇总。若作者提供时间段，点「重听依据」播放该段并在结束时暂停。缺少时间段则显示「重听整段」和对应原句。

## 4. 阅读工作面

```text
返回课程                 Library hours · 第 2 / 3 题          目录   笔记
Library hours                         What can a reader do after 6 p.m.?
第 1 段  ……                           ○ A  ……
第 2 段  ……                           ○ B  ……
第 3 段  ……                           ○ C  ……
                                     ○ D  ……
上一题                                                     下一题
```

**短文与选择。** 以一篇文章作为题组材料，一题一干、四项单选。作者按文章组织主旨、细节和推断题，题数取实际内容。在宽窗中左侧文章与右侧题区独立滚动，切换题目只更新题区，较长选项自动换行。以文章和题区均可读为分栏条件。窄窗改为上下排布，在题区提供「回到文章」，从文章返回时显示「返回第 N 题」，恢复刚才的选项或题干焦点。验收覆盖可用宽度 1280 与 800 CSS 像素、系统缩放和长选项。同一课程含多篇时每篇有独立的题号、阅读锚点和题组结果。

**证据与反馈。** 答前提供文章全文和普通段落标识。作者参考中的正确项、理由、答案段落关联和高亮仅在结果页交付。选择「查看依据」后定位到冻结文章中的对应段落，以文本和临时高亮标明证据。推断题可引用多段，按作者指定次序展示证据和推理。返回解析时保留题号、筛选状态与原位置。首版练习按理解答对数呈现。阅读速度另列能力需求，阅读页停留时长不参与本组计分。

**四级其他阅读形式的适配缺口。** 本版交付范围为仔细阅读。若后续排入词汇理解，交互需支持点击文章内的空位、从共享词库选词、撤回和替换，并按空位给反馈。若排入长篇阅读，文章需展示可定位的段落标号，每条陈述独立选择对应段落，答后显示证据与匹配理由。两项分别登记为后续候选。听力单选的材料可用新闻、对话或独白，逐词补全属于 StudyFlow 的听写练习。[中国教育考试网四级考核内容](https://cet.neea.edu.cn/html1/report/16123/196-1.htm)

## 5. 制课内容、旧课兼容与失败恢复

| 材料 | 作者需要提供 | 发布前可观察的校验 |
|---|---|---|
| 通用题组 | 稳定题组标识、挂载知识点、顺序、标题、材料种类、题目顺序与稳定题目标识 | 标识在对应范围内唯一，挂载和材料存在。普通课可组合普通练习、听力和阅读，独立课程至少有一个可答题组 |
| 听力材料 | 已采用的本地音频引用、摘要、原文。`/8` 可加 `listening.captions`，每项含 `start`、`end`、`text` | 校验离线可读、可解码、摘要匹配。若提供时间则起点小于终点且在音频时长内 |
| 听力单选／补全 | 单选含问题、至少两个不重复选项、唯一正确项及理由。补全含有序只读片段、具名空位、逐空答案与变体、原句解析 | 正确项指向本题选项，空位各出现一次，每空至少一个有效答案，空位数量与题面一致 |
| 阅读 | 标题、按序编号且具有稳定标识的段落、题干、四个选项、唯一正确项、依据段落与解析 | 四项完整可区分，每题至少引用一个本文段落，引用可在预览中定位。推断题有从依据到结论的说明 |

**制课到预览的最短路径。** 作者为目标知识点编写题组。听力组先关联已采用的课程音频，再按题序选择「单选」或「对话补全」。例如把一句分为只读片段 `Please bring your `、空位 `b1`、只读片段 ` and a `、空位 `b2` 和句号。空位顺序决定键盘顺序，答案按 `b1`、`b2` 绑定。阅读组先录入带稳定标识的段落，再为各题添加选项、正确项和段落依据。选项的显示字母根据顺序生成，正确项引用选项标识。增删或重排后预览器重新检查关联。若删除被引用的 P2，发布校验应定位到使用 P2 的题并提示重新选段。CLI 制课和桌面作者预览使用同一材料契约。

**接入原有学习链。** 现有课程按 `learning_mode` 校验，英语题内容以整句 `target` 为核心，英语页由 `TokenEditor` 处理输入。新增受版本约束的题组契约，按题组选择作答视图。发布前，制课工具读取本机能力与 schema，展示错误所在的知识点、题组、题目和字段，整包校验通过后才发布。同一包重复导入复用已有发布结果。既有普通课、拼写、词形和句子翻译继续按原契约加载。旧运行时读新包时给出所需能力和升级提示。[课程校验](../archive/python-runtime-20261121/INDEX.md) `packages/core/src/studyflow/modules/courses/content.py` · [现有英语内容契约](../archive/python-runtime-20261121/INDEX.md) `packages/core/src/studyflow/modules/courses/english/contract.py` · [现有英语训练页](../../apps/desktop/src/features/english/training/EnglishTrainingPage.vue)

**答案、参考与笔记。** 普通课正文、侧栏、独立工具窗与专项工作面都按同一轮次、题组和题目标识找回答案。题型决定键盘和辅助入口。听力题使用课程音频，阅读题使用文章，词句专用的词典元数据、答案查看与整句检查仅用于对应词句训练。检查答前页面与接口时，一并检查目录、资源文件名、辅助说明、工具窗和参考读取。公开音频标识使用不含台词的资源名。笔记继续随计划保存，能回到当前知识点，关闭笔记后恢复作答焦点。

**保存与材料修订。** 校验未过的输入仍可作为草稿退出。保存失败可重试、留在本页或显式放弃未保存更改退出。确认回执丢失时按原请求标识查询或重放，得到原结果。内容更新发布成功后重置目标课程学习状态，下次作答读取最新版。历史结果按原版本只读回看，旧材料窗口收到版本变化时停止写入并提供「打开最新版」。发布失败、同内容重放或仅修改外观时维持原进度。适用既有 W2 规则。[课程更新后重置学习状态](../40_开发实施/2026-10-16-派发更正-课程更新后重置学习状态.md)

## 6. 两套可直接走查的样题

以下为作者预览和隔离验收使用的原创材料。参考答案只从作者或结果视图读取。

**听力 · Station announcement**

音频台词为 “The bus will leave from the station at nine. Please bring your ticket and a jacket.” 单选题为 “Where will the bus leave from?”。选项 A–D 依次为 *the library / the station / the museum / the school*。补全题为 `Please bring your [第一空] and a [第二空].`，答案为 `ticket`、`jacket`。

从普通课进入，播放过程中点击 B 再按回车，同段音频继续播放。第二题只填 `ticket` 点「确认」，焦点应落在第二空。补上 `coat` 并确认，结果应为「答对 1 / 2 题」「补全答对 1 / 2 空」，第二空列出 `coat → jacket`。返回时显示题组结果，普通课其他作业仍可继续。同一内容作为独立课再走一遍，检查最后按钮的整课回执。

**阅读 · Library hours**

| 段落标识 | 正文 |
|---|---|
| P1 | During exam week, the library will stay open until eight on Fridays. |
| P2 | The help desk closes at six. After six, readers can return books using the box by the entrance. |
| P3 | New library cards must be collected in person at the help desk. |

| 题目 | 选项 A / B / C / D | 正确项与依据 |
|---|---|---|
| What is the notice mainly about? | Exam results / Library hours and services / New courses / Book prices | B，P1 和 P2 交代了开放时段和服务变化 |
| Where can books be returned after six? | At the help desk / In the classroom / In the entrance box / At the café | C，P2 明确说明还书箱位置 |
| What can Maya do at seven on Friday? | Collect a new card / Return a book but collect her card later / Ask the help desk for a card / Attend a class | B，P2 说明仍可还书，P2、P3 一起说明需要在服务台开放时领卡 |

在窄窗阅读至 P2，依次选择 B、C、A。确认后应显示「答对 2 / 3 题」。点「仅看错题」进入第 3 题，两处依据分别跳到 P2、P3，「返回解析」回到第 3 题。切换为宽窗，同一轮的答案与结果仍能读出。

## 7. 交付验收清单

| 场景 | 操作 | 通过条件 |
|---|---|---|
| 混合课程 | 一个知识点含普通开放题、听力组和阅读组。先完成听力，再从右侧入口继续阅读 | 正文与工具摘要显示同一状态，整课漏答提示可直达剩余题组，最终 Agent 队列只有待批改开放题 |
| 听力播放与键盘 | 同段切题、切换另一音频、回车确认、输入法选词、播放器键盘操作 | 同时只有一个音源，播放器操作和输入法选词各只触发本控件动作，保存回执返回一次才前进 |
| 听力异常恢复 | 离线运行已生成音频，另以损坏副本测试恢复，草稿中途退出重进 | 正常副本离线可听，损坏副本显示问题并保留草稿。恢复同摘要资源后续答，重进时定位原题与进度 |
| 阅读与证据 | 两篇文章各完成一组，长选项、窄窗、键盘与 150% 缩放逐项检查 | 选项全文可读，文章滚动保持独立，证据只指向所属文章和版本，目录焦点可回到当前题 |
| 写作与侧栏 | 编辑多段作文、保存失败后重试、原稿批改后修订。普通课内连续开关左右栏后进入和退出专项 | 作文稿次与反馈一一对应。普通课能恢复原知识点、可见段落、工具状态和草稿 |
| 制课配置 | 新建 Step Plan 配置，保存后主动试听，分段生成、试听成品、采用并发布到隔离课程 | 保存只做本地校验，真实帐号生成的成品可离线播放。作者预览先看答前页面再看解析，预览结束后学习进度仍为空 |
| 版本与并发 | 延迟确认回执后重试，随后发布改动文章或音频的新课，再投递一次旧保存 | 重试返回同一结果，旧保存被拒，新轮次从头开始，回看历史时文章和音频按旧版本读取 |
| 旧课兼容 | 重新打开普通理论课、英语词句训练和原题复测，各完成一次原有保存或确认 | 原有题面、词框键位、各自的学习记录与既有规则一致 |
