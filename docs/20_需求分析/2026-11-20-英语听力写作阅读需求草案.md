**2026-11-21 入口修订**　听力、阅读、写作的主入口统一为英语专注训练。混合课在同一有序题单内编排拼写、词形、翻译、句式改写和新题型。独立课使用同一入口。下文的普通知识点工具路径保留为 `/7` 存量兼容记录。常规理论课大纲折叠沿用原要求。

本轮补齐了普通课与独立课的进入和回退路径、听力与阅读的页面布局、题组确认与整课提交、作者材料校验、可实际操作的样题及预期结果。开发和验收时按[页面与听读作答细则](2026-11-20-英语专项页面与听读作答细则.md)中的页面与场景逐项核对。

从普通知识点打开听力或阅读时，建议进入英语专项样式的主工作面，返回时回到原知识点，复用原课程轮次和作答进度。独立课程使用同一套题型组件。开始时固定题面、素材与答案依据。退出可恢复草稿，提交或保存失败保留当前输入和题号。

`下一题` 确认并保存当前题后前进，最后一题换为 `确认`。建议把逐题确认作为保存动作，在题组最终确认时核对漏答并显示结果。课内题组确认只完成该组，整门常规课仍走原有提交动作。保存失败停在当前题，保留选择并提供「重试」。保存成功后焦点进入下一题的选项组或第一个空位。保存中重复按键共用同一次写入。返回常规课后可继续草稿或查看已确认的本轮结果。客观反馈沿用本地检查，开放写作沿用 Agent 批改链。参考 [学习与作答一体化设计](../30_系统设计/学习与作答一体化设计.md)。

## 2. EN-13 听力练习

### 题型和键盘

- **听力单选**　题面上方是播放控件和问题，下方纵向排列选项。点击某个选项后显示已选状态，按 `Enter` 或点击 `下一题` 确认并前进，最后一题用 `确认`。键盘可聚焦选项并用方向键调整。确认前可改选，漏选时停留原题并聚焦选项。
- **听对话补全**　同一条题干句子由只读文本和一个或多个单词输入空组成。例句 `Could you [____] the report by [____]?` 中，仅两处输入框可编辑。`Tab` / `Shift+Tab` 可在空位间移动，建议沿用现有词框的跨空导航方式。所有空位填完后按 `Enter` 或点底部按钮确认本题。校验按空位独立反馈，采用制课时明确提供的正确词和允许变体。
- **播放与焦点**　同一段对话可供多道题使用，切换组内题目时复用播放上下文。对于多角色音频，作者可为各角色选择音色，制课侧按台词顺序生成并合并为一个课程文件。提供播放、暂停、进度跳转及重听。播放器上的 `Enter` / `Space` 只操作当前控件，输入法合成、长按回车、重复点击和进行中的保存均避免触发额外提交。提交结果可查看每题或每空的正确答案和依据，并按需展开原文。答前学习端只取播放信息、可见题面和选项。

- **逐空提示**　每个输入框提供「第几空，共几空」标签。确认时把焦点移到第一个空缺并保留其他输入，正式反馈逐空显示作答、可接受答案和解释。题组确认后锁定本轮结果，防止带解析回改原答。

### 独立语音生成模块（首版必交）

现有 Core 的 `audio` 目录包含 `dictionary` 与 `resolution`。`AudioService` 读取词典发音，桌面播放器在词典音频失败后可用本机 `speechSynthesis` 朗读。Engine 声明 `tts_generation: false`。新增独立语音生成模块，由它负责外部服务配置、合成、试听和课程文件交付。建议在 Python Core 设 `modules/speech_generation`，Vue 提供对应功能页面，Engine 和 CLI 委派同一套生成逻辑。沿用现有运行时，无须另起常驻服务。课程通过固定版本的本地音频引用播放。[Core 音频服务](../archive/python-runtime-20261121/INDEX.md) `packages/core/src/studyflow/modules/audio/resolution/service.py` · [桌面音频播放](../../apps/desktop/src/shared/audio/dictionary.ts) · [Engine 能力表](../archive/python-runtime-20261121/INDEX.md) `packages/core/src/studyflow/interfaces/engine/protocol.py`

#### 服务配置与试听

| 用户动作 | 界面行为与结果 |
|---|---|
| 添加外部 API | 在模块内选择「阶跃星辰 Step Plan」预设或「自定义兼容服务」。显示配置名称、协议、Base URL、合成路径、凭据、模型、音色与格式，语速、语气等可选项按适配器能力显示。提交前展示最终请求地址，定位缺失字段。提供商凭据只发送至该配置明确绑定的 HTTPS 目的地址。 |
| 保存、切换或移除 | 支持多个命名配置及一个制课默认配置。保存只做本地校验，显示「已保存，待试听」。重开页面可继续使用。更换端点时重新绑定该端点的凭据。移除配置后，已生成的课程文件仍可播放。 |
| 填写或替换 Key | 首次录入使用密码框，保存后仅显示「已配置」和替换、清除按钮。编辑已有配置时，保留密钥的操作与清除密钥分开。建议使用操作系统凭据存储，普通配置只保存凭据引用。回读接口、CLI 输出、日志和课程导出均排除密钥与鉴权头。 |
| 测试并试听 | 点「测试并试听」后向所选服务发送界面可见的短英文样句，按钮旁提示可能消耗额度。重复点击合并为一次请求，允许停止等待。收到可解码音频后可播放，并记录本次测试对应的配置版本、时间与结果。更改地址、凭据、模型、音色或输出参数后回到「待试听」。试听文件与课程素材分别管理。 |
| 修复失败 | 鉴权、模型或音色错误定位到相应字段。限流提示何时可重试（如服务提供）。网络超时或响应音频损坏保留配置、文本及上一版文件。界面提供针对当前错误的操作。超时后若供应商处理结果未知，重新发送前提示可能重复扣费。 |

**首个适配器** 使用 Step Plan 套餐专用的非流式 `POST https://api.stepfun.com/step_plan/v1/audio/speech`、Bearer 鉴权和 MP3 输出。预设采用文档示例模型 `stepaudio-2.5-tts`，映射 `input`、`voice`、`response_format` 和可选 `instruction`。自定义同协议服务允许配置地址、路径与模型。请求格式、认证或返回编码不同的供应商使用相应适配器，例如 Azure Speech 需要生成 SSML 并指定输出格式。每个适配器声明支持的字段和格式，实测结果按供应商登记。[Step Plan 语音模型接入](https://platform.stepfun.com/docs/zh/step-plan/integrations/audio-api) · [阶跃语音合成参数](https://platform.stepfun.com/docs/zh/api-reference/audio/create-audio) · [Azure Speech REST](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/rest-text-to-speech)

#### 生成与采用为课程文件

1. 作者从知识点或独立听力课程进入模块，选择配置，填写台词。多人对话按发言顺序指定角色和音色。生成前展示服务名称、将发送的文本和目标课程，允许先试听一小段。联网范围限定为作者主动发起的制课合成与试听。
2. 点击「生成」后禁用重复触发。按文本、角色顺序、服务、模型、音色、输出格式和语音参数标记结果。参数一致时可复用已有文件。多段生成显示完成段数，失败可定位并重试该段。切换配置或编辑台词后，迟到响应仍归原请求，当前题目采用文件时校验版本。
3. 作者试听成功结果，再点击「采用为课程音频」。先校验文件可解码及 SHA-256，再登记工作区内的相对资源引用。只有完整文件可用于课程发布。中途中断保留上一版，重试采用同一结果只生成一条有效引用。历史结果引用原文件，备份恢复后按摘要验证并支持离线播放。
4. Vue 和授权制课 CLI 共用配置与生成服务。CLI 通过配置标识选择服务，能力发现分别报告模块是否可用与配置是否就绪。在线合成属于本轮提出的有限范围调整，实施前需将其与冻结定义的「在线 AI API」非目标核对并在正式规格中明确。[系统定义](../10_系统定义/系统定义.md)

### 验收

- 在新配置环境通过模块界面添加 Step Plan，保存、关闭、重新打开，核实保存动作的上游请求数为零。用明确授权的真实套餐完成短句试听，核对可听音频。更换无效凭据或不可用音色后可定位修复，再次试听成功。模拟验证计入协议测试，真实账号试听另留回执。
- 模拟超时与迟到响应，核对界面仍显示原请求所属的配置与台词，失败或取消操作只影响当前请求。
- 使用第二份自定义兼容配置接入测试服务，验证两份配置分别使用各自的地址、模型与凭据。切换默认或移除配置后，旧课程仍可播放。检查课程导出、日志和配置回读中的凭据保护。
- 使用阶跃星辰 Step Plan 生成一段英文音频，验明工作区内存在可独立播放的 MP3，发布时以课程资源引用该文件。断网后分别从普通课程和独立听力课程进入，验证两个入口都能播放、暂停和重听。
- 单选题用鼠标选中后按回车与点击按钮均可确认。长按回车、按钮连点或同一次保存中的重复触发只确认一次。多空题的题干保持只读，可逐空编辑、保存、恢复和判分。最后一题显示 `确认`，错漏空位有明确反馈。
- 将修订音频随课程更新发布后，从只读历史和新学习轮次分别播放，核对资源版本与目标课程的进度重置。文件缺失或生成失败时有明确反馈，能保留原作答或上一版可用资源，从对应入口恢复。

## 3. EN-14 写作练习

- **上方题干区**展示情境、写作任务、必写点与建议字数，内容只读。**下方文本编辑器**建议采用面向英文作文的多段纯文本编辑，首版提供选择、复制、剪切、粘贴、撤销、重做、换行和实时词数。正文里的 `Enter` 用于换行，提交由页面按钮触发。
- 自动保存作文草稿，提交时固定原题和原稿。沿用草案的 Agent 批改链，按任务完成度、结构与衔接、词汇、语法与拼写给文字反馈，并标记对应原句或题目漏项。可根据反馈提交同题修订稿，各稿及其评语可分别查看。
- 编辑器附近显示「保存中 / 已保存 / 保存失败」，失败可重试并保留选区。只含空白的稿件提交时焦点回到正文。进入批改后原稿只读，提供「按反馈修订」，创建新稿时沿用原稿段落与对应反馈。
- **验收**　以一封要求说明报名原因和可参加时间的活动邮件为样例。验证粘贴多段正文、撤销重做、字数更新、离开后恢复，以及输入法合成与回车换行。提交后保留原稿，修订稿形成独立版本，评语定位到对应稿件。

## 4. EN-15 阅读题练习

- 首版按 CET-4 的「仔细阅读」题型适配，使用一篇英文短文配一组 A–D 单选题。作者可出主旨、细节、推断等理解题。中国教育考试网把词汇理解、长篇阅读和仔细阅读列作不同题型，本项选取仔细阅读的单选作答形式。参考 [CET-4 笔试考核内容](https://cet.neea.edu.cn/html1/report/16123/196-1.htm)。
- 作答时同时可见短文和当前题。宽窗建议采用并排的短文区和答题区，窄窗改为上下布局，保留短文入口、当前位置和已选项。短文区可独立滚动，跳题后可继续在原段落读。选项组件、回车确认和按钮与听力单选共用，最终确认后显示答对数、逐题解析和可跳转的原文证据。
- 窄窗提供「回到文章 / 返回第 N 题」锚点，往返恢复段落和原选项焦点。题组确认前可回看已答题并改选。显示解析时以文字标明「你的答案」和「正确选项」，证据跳转后可回到同一题。
- **验收**　用一篇开放时间调整通知及一组四选一题验证常规课程内嵌与独立课程入口。切题保留短文位置和作答，确认后可从解析跳到对应段落，推断题有文本依据。文章修订发布后，新学习从最新内容开始，已留存的历史结果只读定位至原材料。首版按不限时理解练习验收，阅读速度仍单列为待补能力。

## 5. 常规理论课左侧导航折叠

- 用户附图一红框指向整个左侧区域，包括主导航、计划信息、课程大纲、本节大纲和底部状态。附图二用于参考右侧答题与笔记的开关交互。课程顶栏新增始终可达的「收起导航 / 展开导航」按钮，支持键盘聚焦与 `Enter` / `Space`。建议收起时释放整列宽度，保留顶栏按钮作为恢复入口。
- 左栏与右侧工具分别控制，支持两侧都开、只开一侧和两侧都收起。左栏几何沿用布局层的统一宽度计算，按现有主题和窗口宽度更新正文可用区域。切换时保留当前知识点、当前阅读段落、大纲标签和滚动位置、右侧工具和未提交答案。正文重新换行时保持当前段落在可视区。焦点若仍留在将隐藏的左栏，转到顶栏恢复按钮。
- 导航按钮提供状态文本及 `aria-expanded`，折叠后的栏内控件移出键盘焦点序列。动画中再次切换时以最后一次操作为准，阅读区、草稿编辑器和工具窗继续使用现有实例。
- **流畅度验收**　在序光、白紫、国风朱红的宽窗、窄窗和原生窗口检查四种左右栏组合。连续快速点击后，最终展开状态与最后一次操作一致，正文跟随调整，无闪白、回到页首、横向溢出或遮住右栏。观察切换的帧和主线程记录，确认无由折叠触发的重复挂载正文、请求课程或保存草稿。系统开启减少动态效果时直接切换。现有布局参考 [AppShell](../../apps/desktop/src/app/layout/AppShell.vue) 与 [CourseReader](../../apps/desktop/src/features/courses/components/CourseReader.vue)。
