## 已知限制

旧course import不能作为无条件增量更新使用；1.7.0课程修订需先preview再apply并保留学习快照。1.7.0安装候选包含独立CLI/Skill资源，不自动配置系统PATH或覆盖公共Skill。旧Web是兼容入口，不是第二套正式UI。THEME-BASE色板/预设切换已实现；布局视觉深化为最新授权，尚未编码；工程检查与用户验收分开。

## 业务闭环

Agent准备课程 → 本地固定本轮材料 → 用户逐知识点同屏学习/作答与自动草稿保存 → 整课提交 → Agent逐题批改 → 原位修正或复测 → Agent再批改 → UI分别展示本轮通过与下一学习课程。

2026-10-01用户采纳补充：允许暂时跳题；版本保护不做复杂平台功能。等待批改不默认阻塞后续课程；阅读、学习提交和本轮通过分别表达。见[一体化设计](../30_系统设计/学习与作答一体化设计.md)。

## 2026-10-02 用户确认增量：计划笔记和工具停靠

属于既有个人学习工作台范围，不新增平台业务。默认学习笔记贯穿整个学习计划，能兼容课程/知识点关联；前端支持正文摘录与来源标记。侧栏标签可调整、关闭/重开、展开和拆成原生工具窗。独立窗默认跟随主窗课程，可浏览全部知识点；同轮答案和笔记共享，不能重复建立课程轮次或割裂存储。笔记不当作作业、不触发批改。保存失败仍必须允许显式不保存退出。详细约束见[增量设计](../30_系统设计/学习与作答一体化设计.md)。

## 2026-10-02 用户确认增量：应用级右工具区

工具区属于应用整体而不是课程正文内卡片。默认关闭，只保留紧凑入口；展开时导航、阅读和工具等高且前两栏让出宽度。窄窗不得牺牲可用性，切到工具内容时仍可继续/提交并返回阅读。外观统一，提供即时、克制的视觉和可选音效反馈；不增加积分、排行等平台化功能。

## 2026-10-02 用户确认增量：结构化教学内容与阅读优先

对应R1、R2、R4、R5、R8、R9；实施证据于2026-10-03收口，不新增平台业务或第二套前端。

- Agent通过CLI输入具有知识点、内容块、题目稳定ID的整课JSON；软件校验后渲染受控教学组件，不接受Agent生成的可执行前端模板。
- 顶部保留紧凑导航，课程简介只在计划详情展示；正文知识点标题与教学小节分层，状态同时使用颜色、文字/图标，不以阅读完成冒充批改通过。
- 导入先整包校验、单事务登记，同包重放返回已有课程；冲突明确拒绝，不静默覆盖或追加。现有学习轮次内容、题目、答案保留。
- 练习链接定位同一答题入口，摘录保留冻结内容块来源；旧Markdown内容兼容，但不要求学习者查看原文。
- 当前测试课程可以重新导入，原始学习资料仍保留；材料生成和试点导入不标记学习完成。具体设计见[结构化课程组件设计](../30_系统设计/结构化课程组件设计.md)。

## 2026-10-03 用户确认增量：可切换主题专项

- 用户要求样式为可切换配置，不再只挑一个固定风格；保留唯一Vue前端。主题覆盖全部工作面及七类教学组件、Markdown兼容、练习/反馈/计划笔记与原生工具窗，不只覆盖首页。
- 主题切换保留当前答案/笔记/轮次/焦点/阅读锚点；已存阅读偏好、静音和减少动态效果优先于主题预设。配置异常回退，不阻塞学习写入。
- 可用轻量即时视觉与可选短音效，默认静音；成功只响应真实确认，跨窗不重复发声，不加入积分排行或装饰仪表盘。
- 外部主代理复用已经实现的主题契约，以不同真实设计Skill实现候选，子代理最多5并发、统一渠道/模型；每方向选一份进入同一应用。具体选择及未支持渠道须如实报告。
- 上述是早期交接；后续THEME-BASE已实现，外部旧wave矩阵当前40项submitted，不等于视觉通过。最新布局扩展另见下节。既有v1契约详见[主题与交互契约](../30_系统设计/前端主题与交互契约.md)。


## 2026-10-03 用户最新确认：主题不能只是换色

用户明确允许布局、容器、CSS与纯展示Vue/template调整，可用imagegen及相关Skill生成本地背景/纹理/局部插画；主题需要改善中文阅读、教学层次与操作体验，不把前端结构全部冻结为同一个模板。

锁定的是Core/CLI/Engine/API语义、学习轮次/冻结内容、答案/笔记/事务/幂等/保存失败与退出保护、窗口协调；展示允许有不同组织，但原有功能仍存在、可达且状态清楚。仍是一份正式Vue工程/业务实现，不建立十份保存/提交逻辑或任意脚本插件运行时。

旧studyflow.theme/1及40份旧色板保留兼容，新共享展示底座与候选overlay尚未实现。先补可运行能力，再做三个有结构差异的真实试点，效果合格才批量深化其余方向；模板/色板数量不能代替体验。图片本地化、可关闭/纯色fallback，不在正文上堆复杂背景，不传私人课程/答案/凭据到生成服务。

详见[布局视觉设计](../30_系统设计/主题布局与视觉扩展设计.md)与[执行计划](../40_开发实施/主题布局与视觉扩展实施计划.md)。布局换主题不能丢输入/焦点/IME/阅读锚点或重发未确认请求，浏览器真实渲染、Core闭环、原生窗口/系统DPI、用户长期体验分层验收。

## 2026-10-10 用户确认增量：课程正文折叠详解

对应 R11/C2/C4；用户要求先加入软件文档目标。本次仅登记需求与建议方案，不表示已经开发或获得实施授权，不改变已确认的个人本地学习工具定位。

- **阅读目标**：正文保留简述、必要定义、关键结论和作答前置条件；较长推导、补充解释和详细示例通过“展开详解 / 收起详解”按需阅读。不能为缩短正文而隐藏首次使用的术语定义。
- **交互目标**：详解默认收起，标题与简述始终可见；可用鼠标和键盘展开，状态有文字/图标而不只靠颜色。收起不导致答案、笔记或阅读定位丢失，不以展开操作判定学习完成。
- **制课目标**：Agent 经 CLI 写入受控结构化内容，由共享 Vue 组件渲染；禁止用任意 HTML/JS/CSS 绕过课程契约与消毒规则。具体块类型、字段和版本策略待设计确认。
- **兼容目标**：旧七类内容块和旧 Markdown 仍可阅读；兼容输出保留完整详解文本。新内容在不支持的旧 CLI 上必须明确报能力/契约不兼容，不静默丢弃详解。
- **版本目标**：已开始轮次继续使用冻结的课程版本；课程修订仅对后续轮次生效，不自动重建、清理或替换学习者正在使用的内容。

建议方案和验收见[结构化课程组件设计](../30_系统设计/结构化课程组件设计.md)中的“折叠详解增量”；待实施项见[组件实施计划](../40_开发实施/结构化课程组件实施计划.md)。


## 2026-10-10—11 用户请求增量：英语专项、分域错误管理和词典优先

需求意图来自用户提出英语/普通课程两种模式、错题本与预生成语音，并于本日完成Earthworm体验核对。既有个人本地定位不变；原系统定义不被本次设计稿重写。

- **已确认意图**：计划→课程可复用；课程内部项不同；中文提示/英语输入、准确错词位置、自动修正焦点、空格/回车推进、答案与语音、退出恢复。需要清楚知道哪些课程完成，不依赖账号登录。
- **错题目标（2026-10-11修订）**：以计划→课程→学习项划分；普通错题和英语高频训练错误分别管理，英语使用聚合统计与按需复习清单，不将每次即时答错都转成长期待办。只引用原作答/尝试和反馈，保留错误位置、来源与修正/复测历史；按范围读摘要、条目和证据，支持逻辑归档。
- **语音目标（2026-10-11修订）**：首版优先词典发音、音标/释义；缺失/离线不阻塞文字训练，不要求制课先生成音频。预生成本地资源保留后续兼容路线，但学习端不内置TTS供应商Key、不实时生成；词典整句不可用时不能拼接词音冒充自然整句。
- **拟议而非已批准**：英语固定题默认Core本地校验、Agent处理开放题/争议；普通错题条目与英语聚合/复习表分开，采用冻结计划作用域；`course-package/2`及两级职责包。用户确认改进方向不等于审核全部字段、算法或授权开发。
- **未验证项**：参考项目登录后完成/掌握跳过、美音/英音入口的当前部署可达性；供应商具体语音模型/口音质量/套餐权限。不能据此宣称已具备相应功能。

第一版方案与验收条目见[英语专项功能设计稿-v1](../30_系统设计/英语专项功能设计稿-v1.md)。普通课程的既有批改链不变；英语受限本地校验属于待批准增量。本次只写文档，不授权迁移、实课改写、公共Skill同步、代码、TTS调用或发布。


### 英语增量的页面与制课要求补充

- R12：英语新增专用页面/大组件。训练页占满应用客户区，默认不挂普通左侧主导航与文档三栏；保留原生窗口控制、返回课程、按需目录/笔记以及共享保存/退出链。唯一Vue前端不等于只能沿用已有页面。
- R4/R5/R12：教学设计与提示词的权威来源为Skill课程编写部分，覆盖普通/英语；CLI只承担能力发现、数据契约、校验/导入与回读，不输出另一套长教程。课程需有目标、前置知识、递进内容、对应练习与作者自查，不只是任意句子列表。
- 参考MHTML为答案态，输入/纠错采用已体验Earthworm行为设计，不能把静态快照描述为所有功能验证。商业积分、掌握承诺、AI助手、会员/账户等不纳入需求。

### R12—R14工程验收目标（未执行）

1. 混合计划下普通/英语身份与顺序正确，英语单组不新增跳转层级。
2. 输入/纠错/答案共用全窗口训练页；多错词定位、首键上屏、Space/Enter/IME/粘贴及边界行为正确。
3. 检查保存不可变尝试、编辑使旧匹配失效；幂等不重复计错，整课提交/单项审核分流正确。
4. 退出恢复草稿和位置，课程完成与有提示/待复测分开；不可用音频不阻塞训练。
5. 普通分册与英语分册按计划/课程正确归属；同轮多次纠错只增加尝试，不重复增加复习任务；多个错词在同一证据内定位。移动课程、语义ID碰撞、规则变更、Agent判有效表达和新失败激活均不污染原历史。
6. 首版词典发音/音标/释义独立可用，缺失/离线提示、过期响应取消、实际口音、跨窗单播放与独立音量正确；本地预生成兼容扩展另行验证，不成为首版必备条件。
7. 独立窗只有一个编辑器、不重开轮次；两主题/窄窗/保存失败不保存退出无回归。
8. 旧包/旧轮次/旧队列与导出恢复保护；聚合可重建，归档不删除原证据；Skill/提示词/能力回执一致，不上传私人资料。
9. Agent按计划/课程/领域/时间/目标读取摘要再取有限证据；大量历史下游标分页、范围隔离、统计口径和版本变化提示正确，不默认全量拉取。
10. 一级业务模块、二级职责包有清晰归属，旧导入兼容、单一Base/Runtime/Session和整课单事务不退化。
