# StudyFlow 需求规格说明 · v1.11

直接上游：[系统定义](../10_系统定义/系统定义.md)。本文件是软件需求，不是私人学习计划。

| 需求 | 功能 | 验收要求 |
|---|---|---|
| R1 | C1 | 计划内顺序课程、当天排课；控制台按计划聚合，不重复主推进容器 |
| R2 | C2 | 知识与对应练习同屏；导航自动保存、允许跳题；整课事务提交，正式提交校验完整性；学习中的材料版本固定 |
| R3 | C3 | 原答案、评语、修正/复测父子版本可查；说明错误位置、原因和下一动作 |
| R4 | C4 | CLI提供JSON、稳定错误码、能力发现和准确待批改队列 |
| R5 | C4 | Skill适用任意Agent；不伪造答案、不直接SQL、不盲重试写入 |
| R6 | C5 | 文件限制于选定工作区；迁移有快照、清单和校验和 |
| R7 | C6 | 自动启停Engine；一体窗口保留拖动、最大化、最小化、关闭 |
| R8 | C2/C3 | 中文emoji原样往返；版本、幂等、状态冲突不产生部分写入 |
| R9 | C5 | 日志不记录答案、SQL参数和凭据；公开仓库无用户数据和私人历史 |

## 已知限制

已有路径的course import不增量追加新增练习；不能声称更新成功。MSI不含独立CLI、不配置系统PATH。旧Web是兼容入口，不是第二套正式UI。工程检查与用户验收分开。

## 业务闭环

Agent准备课程 → 本地固定本轮材料 → 用户逐知识点同屏学习/作答与自动草稿保存 → 整课提交 → Agent逐题批改 → 原位修正或复测 → Agent再批改 → UI分别展示本轮通过与下一学习课程。
