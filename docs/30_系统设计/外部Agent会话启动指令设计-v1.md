# 外部 Agent 会话启动指令设计 v1

**状态：** 设计已采纳；源码实现已完成。Skill未修改；安装包重建、同步与部署另行处理。

## 1. 目标与边界

设置页的“复制 Agent 接入说明”应提供足够明确的路径和会话入口要求，使外部 Agent 能恢复跨会话上下文，并在读取完成后汇报当前状态与可做事项。

复制文本只承担**会话启动路由**。课程编写、计划、参考资料、学习记录、批改和质量检查等具体业务流程继续由当前实际加载的 StudyFlow Skill 定义；复制文本不重复这些流程，Skill 是唯一细则来源。

本设计不改变 StudyFlow 数据工作区、Agent 协作工作区或 Skill 的业务职责，不实施课程/学习数据操作，也不授权发布或安装。

## 2. 运行时入口信息

设置页继续提供当前已有的三项动态信息：

- Skill 的绝对路径及其来源类型（安装内或仓库）。
- CLI 绝对路径和完整参数数组；不要求 Agent 猜测可执行文件或修改 PATH。
- 当前 StudyFlow 数据工作区绝对路径。

另为 `system.installation` 增加只读的协作区入口发现结果：

- `agent_workspace_entry_path`：发现有效入口时返回协作区入口文档的绝对路径，否则为 `null`。
- `agent_workspace_entry_status`：`found`、`missing` 或 `invalid`。`invalid` 表示指针存在但无法安全解析或目标不合法。

发现以当前用户的 Skill 约定指针 `~/.studyflow-agent/workspace.json` 为准，并验证其格式、绝对根路径和目标 `AGENTS.md`。发现过程只读，不创建、修复或迁移文件。此字段为可选增量，不要求数据库迁移；旧调用方可忽略。

`found` 时，复制文本给出实际协作区入口文档路径。`missing` 时，复制文本明确要求先读取所给 Skill，再遵循其初始化规则建立协作区，之后读取新建的入口文档。`invalid` 时要求停止初始化并报告指针问题，避免误建第二个工作区。

三类路径必须明确标注，不能把 Skill 路径、Agent 协作入口和 StudyFlow 数据工作区互相替代。

## 3. 复制文本的会话入口顺序

复制文本采用短指令，按以下顺序组织：

1. 读取给定绝对路径的 Skill，并按 Skill 指定的会话入口恢复流程行动。
2. 使用给定 CLI 路径、参数和明确的数据工作区运行入口预检，核对返回的工作区路径及实际能力；不静默切换数据根。
3. 读取已发现的协作区 `AGENTS.md`。入口缺失时，先读取 Skill 并依其规则初始化；入口状态无效时停止并报告。
4. 按 Skill 的恢复要求读取协作区和当前任务所需上下文。完成后简要汇报核验结果、恢复状态和当前能做的事项。
5. 可做事项必须以刚读取的工作区记录和 CLI 实测能力为依据，不默认假设用户要制课。用户已经明确具体任务时，说明该任务并继续，不重复要求从菜单选择。

启动文本不内嵌协作区的逐文件读取清单、业务菜单固定内容或任何业务执行步骤；这些由 Skill 单一维护，避免复制文本与 Skill 漂移。

### 复制文本示例

```text
StudyFlow Skill：{skill_path}
请先读取此 Skill，并按其中的会话入口流程操作。

CLI 路径：{cli_path}
CLI 参数：{cli_argv}
StudyFlow 数据工作区：{data_workspace}
Agent 协作区入口文档：{agent_workspace_entry_path 或“未发现”}

使用上述 CLI 和明确的数据工作区执行 version、capabilities、doctor，核对实际返回路径与状态；然后按 Skill 恢复协作区上下文。
若协作区入口未发现，先按 Skill 初始化，再读取新入口文档；若入口无效，停止并报告。
读取完成后，简要汇报核验与恢复结果，并根据工作区状态和实际能力列出当前可做事项。具体业务流程以 Skill 为准；不要静默切换数据工作区。
```

示例中的路径和状态由运行时生成；Skill 定义入口细节和后续业务，不由本模板维护第二份规则。

## 4. 缺失与异常处理

- 协作入口未发现：先读 Skill，再初始化；不得在 StudyFlow 数据根、安装目录或源码仓库创建协作区。
- 协作入口无效：报告发现状态与路径，不自动修复指针、不另建目录。
- Skill、CLI 或数据工作区路径缺失/不匹配：停止后续业务操作，报告具体缺项，不以旧会话记忆补路径。
- CLI 预检不可用或返回工作区根不符：不读取或写入其他数据根。

## 5. 验收条件

- 复制结果包含 Skill 路径、CLI 路径与参数、数据工作区路径，以及协作区入口路径或明确的缺失/异常分支。
- 任一路径均来自运行时发现；不硬编码个人目录、Skill 版本或 CLI 能力，不出现空值、`undefined` 或未展开的伪绝对路径。
- 首次初始化分支明确要求“先读 Skill”；异常指针不会触发自动初始化。
- 启动读取完成后会汇报可做事项，且事项依据工作区状态和实测能力；不会默认询问是否制课。
- 复制文本不重复定义课程编写、计划、参考资料、学习、批改等业务流程。
- 路径发现只读；本设计不引入数据库迁移、业务数据写入或协作区自动修复。
