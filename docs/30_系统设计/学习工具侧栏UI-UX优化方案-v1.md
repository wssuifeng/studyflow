日期：2026-10-11。**状态：用户已确认“轻量工具窗体 + 连续文档式笔记”结构方向；精修v2三图已获采纳，Vue原型生成已授权，未实施正式前端。**

直接上游：[学习体验收口计划](../40_开发实施/学习体验与制课质量收口计划.md) LC-06、[英语统一设计](英语专项功能设计稿-v1.md)、[UI标准化与主题契约](UI标准化与主题契约-v2.md)。原版以展示整理为主；新增笔记编辑/范围契约按上述完整设计单独审查，不重开产品阶段。

## 1. 现状判断

源码依据：CourseToolsSidebar.vue、CourseToolContent.vue、KnowledgeExercises.vue、PlanNotebook.vue、ToolSession.vue、EnglishTrainingPage.vue。未读取真实课程或答案。

- 右侧已有练习/笔记页签，但“学习工具”命名含糊；常驻学习进度、下一知识点、窗口协作、保存保护又复制了主阅读区的职责。
- 练习外层“答案草稿”、内部“把理解写下来”和题目层级叠加；正常提示重复，降低题面与作答的辨识度。
- 笔记顶部标题/说明、范围标签、搜索、阅读、导出和状态占用多层高度；每段均为独立编辑卡片，连续阅读体验不理想。
- 普通侧栏、英语笔记抽屉、独立工具窗口有不同外壳，未来只改一个入口容易再次遗漏其他入口。
- 保存、冻结、修正/复测和跨窗单编辑权是可靠性功能，不因视觉精简取消。

## 2. 方向选择

| 方案 | 优点 | 局限 |
|---|---|---|
| A：保留卡片结构，仅压缩标题/间距 | 变动小，可快速改善空间 | 连续笔记和工具窗口仍割裂，不能根治重复层级 |
| **B：轻量工具窗体 + 文档式笔记（推荐）** | 删除职责重复容器，让内容成为主角；可共享侧栏/独立窗结构 | 需要审慎适配现有输入组件和不同入口 |
| C：完整富文本编辑器/多笔记库 | 编辑能力更多 | 超出本轮范围，增加数据迁移与维护复杂度，不采纳为默认方案 |

本轮先探索B的局部设计图，不增加新主题、知识库、标签系统、在线AI或第二前端。

## 3. 共享工具窗体

### 3.1 入口与几何

- 默认收起，由现有学习工具按钮打开；主阅读区和右侧工具区等高，共同分配当前窗口宽度，不增加第二条整页滚动。
- 普通课只显示“练习／笔记”；英语只有“笔记”，不能通过隐藏入口留下可打开的英语练习工具。
- 右侧工具头固定，正文独立滚动，底部一条保存状态；目标普通宽屏侧栏约420—480 CSS px，实际断点/可用宽度由工程验证确定，不拿图片像素当CSS几何。
- 支持拖动边界调宽、展开/恢复；窄窗采用已有紧凑工具工作面，不强行塞三个小列，也不遮住关键退出操作。
- 左侧课程／本节大纲保留；课程进度、知识点切换和整课提交仍由主学习面负责，不复制到右侧。

### 3.2 信息层级

1. 单行工具头：当前页签 + 弹出/更多/收起；低频操作渐进显示。
2. 一行必要上下文：当前知识点与题数，或计划名称与查看范围。不要连续三行大标题。
3. 内容工作面：练习或连续笔记。
4. 保存状态：从真实保存状态读取，不能因有文字就显示“已保存”。失败才展开操作区；正常不常驻“保存保护”说明。

恢复关闭工具的入口仍可保留在更多，不用常驻“+”、菜单和窗口介绍同时占位。图标保留名称/tooltip和键盘可达性。

## 4. 练习设计

- 一个作答工作面展示当前知识点的多道题；题间用分隔/轻量锚点，不新增逐题独立页面或单题提交。
- 题号/题型 → 清晰题面 → 必要要求 → 作答区。去掉重复装饰标题与层层嵌套卡片。
- 答案输入高度按内容/用户调整，不采用图片中的过大固定高度；已输入内容、IME组合、选择区和焦点必须保留。
- 普通草稿不显示可操作状态管理栏。确实等待审核/需要修正/复测时显示必要文字，不允许前端手动切换业务状态。
- 有批改时才出现反馈区域，保留原语句引用、错误原因、正确方向和新的修正版；历史答案不可被覆盖。
- 最后仍按原业务整体提交课程。暂时跳过、父子修正/复测链、原幂等键与保存失败出口不改。

## 5. 笔记设计（最新完整稿为v1.1）

笔记详细规则唯一入口是[计划笔记连续编辑与引用设计v1.1](计划笔记连续编辑与引用设计-v1.md)，其完整设计已获用户采纳；按[实施计划](../40_开发实施/计划笔记v2实施计划.md)先可操作原型、后正式业务实现，2026-10-12已交付P1展示基线和P2真实编辑原型，关键体验待确认，正式业务未接；见[记录](../40_开发实施/2026-10-12-笔记v2原型实施与验证记录.md)。此前逐段textarea、默认全计划和筛选只读的取舍已被替换，不以旧原型为实现标准。

- 学习中首次打开默认当前知识点；用全计划/实际课程及课程下知识点的小列表切换，范围内直接编辑。
- 不在单知识点正文重复课程/知识点大标题。全计划则按课程→知识点分组标题与轻渐变层次组织。
- 保留舒适大小、自适应增高的记录卡片，卡内可多自然段；连续输入、跨卡操作不退回每行小框或手动加行。
- 一个计划一份笔记，按稳定记录ID增量保存，折叠/筛选/分页不能覆盖隐藏内容。归属和原始来源分开。
- 引用可编辑/剪切/复制，原始摘录不可变；来源默认悬浮/按需展开，保留冻结来源、撤销、恢复、导出及安全退出。
- 普通/英语侧栏、计划页、独立窗及序光/白紫共用内容组件与状态，不各自实现一套。

## 6. 独立工具窗口与反馈

- 弹出的是当前工具标签，不复制计划笔记/答案；仍共享本轮数据及已冻结上下文。
- 独立窗保留可拖动标题栏、最小化/最大化/关闭/置顶；“放回主窗口”是一处明确操作，不重复铺窗口说明卡片。
- 主窗保持只读并提供聚焦/放回，子窗未就绪或状态未确认不能解除单编辑权。关闭必须经过原保存协调与不保存确认，不直接调用裸window.close。
- 功能性布局由共享结构约束，序光/白紫只表达视觉变量；独立窗不另实现一套数据流。
- 交互反馈克制：页签选中/按钮按压/拖动/摘录定位有即时视觉回应。尊重现有音量、静音、后台不发声和减少动态偏好；不每次输入或自动保存都播放音效。

## 7. 必须覆盖的状态

| 状态 | 表现与保护 |
|---|---|
| 收起／展开 | 不破坏阅读位置与答案/笔记；工具头可达 |
| 空练习／空笔记 | 一条说明+明确行动，不空白，不制造假内容 |
| 编辑／阅读 | 同一笔记数据，不丢草稿、选择与来源 |
| 保存中／已保存 | 状态来自真实确认；不显示虚假的已保存 |
| 保存失败／结果未知 | 保留输入、原键重试、导出、明确不保存退出 |
| 历史／等待审核 | 正文只读、原因可理解，不开放状态切换 |
| 修正／复测 | 原答案引用与本次编辑分开，父子链和冻结保护不变 |
| 工具已弹出／子窗未就绪 | 主窗只读、聚焦/放回；保留恢复出口 |
| 窄窗／高DPI／双主题 | 几何不溢出、工具与退出可达，无主题业务差异 |

首轮三张图只确认练习/笔记常态及独立笔记窗。选定方向后补保存失败、空态、只读/弹出和窄窗的局部状态稿；不能以首轮图片宣称全部状态已设计或验收。

## 8. 图到工程流程与审查点

采用mockup-to-page visual-exploration：gpt-image-2-style-library选择UI模板 → imagegen实际生图 → 用户确认 → design-intent精确几何/状态 → screenshot-to-code单文件原型 → 当前Vue/TS/CSS适配 → 独立验证 → 用户体验验收。

- 私有候选只写本轮新目录，旧被否决候选不恢复。生图输入仅合成文案。
- 每张图独立用途，不重复生成主窗口，不从多张完整应用稿拼接冲突布局。
- 图转代码使用html_css视觉原型，随后提取结构/样式为Vue组件；不将原型CDN、假数据、事件和自有保存逻辑复制进生产。
- 状态仍由既有CourseReader/Dock、答案/笔记composable与EnglishNotesWindow负责。共享外壳只收展示数据与派发动作，不写Core/数据库/CLI或新的学习业务规则。
- 不派子代理；图转代码当前源码新建4变体，串行占生成租约，实际运行先确认variantCount与共享通道占用。不用wait-first假装其余请求没有消耗并发。
- 工程验证覆盖主普通侧栏/英语笔记/计划笔记页/独立工具窗，保留learning/themes/English测试、真实Vue/Core交互和原生关口。不能只检查一页。

**本轮终点：用户确认高清精修图和关键交互。** 结构方向已确认，工具专用服务已依最新授权恢复，仅本机访问；之后才进入原型与正式适配，本稿不是前端实施已完成记录。


## 9. 2026-10-11 结构确认与精修约束

用户采纳结构方向，精细视觉继续调整。新两侧栏2048×4096，独立窗3200×2400；图片真实生成，交接见[精修与恢复记录](../40_开发实施/2026-10-11-侧栏结构确认与高清设计精修记录.md)。这些是局部高清画布，不是把软件侧栏固定成数千CSS像素，实际容器仍随主窗口等高/让宽。

- 统一无衬线字体，正文约17px/29px，辅助14px，标题21—24px；像素稿的比例不能代替实际DPI/窄窗验证。
- 计划名只读，范围筛选可下拉；英语仅笔记，普通练习/笔记，两主题和独立窗共用结构。
- 答案约7行起步；滚动条仅溢出时出现；阅读/编辑一处分段切换，不让生图近似图标决定产品语义。
- 本轮精修原型的标题/段落是合成展示，不代表新增数据字段。最新笔记卡片、范围与结构化编辑按第5节完整稿审查；仍不新增题目状态管理。
- 两工具容器已恢复，仅本机访问且不改其他服务；真实图转代码请求仍未执行，精修确认后才调用。
