# 前端主题与交互契约 · THEME-01

> **最新边界优先：** 用户已授权布局/容器/纯展示Vue/CSS和本地图片，见[布局视觉扩展设计](主题布局与视觉扩展设计.md)。第8节仍是已经实现的v1数据schema，不是对新展示包的上限；新能力尚未编码。唯一Vue意味着共享业务，不是固定DOM。

日期：2026-10-03。THEME-BASE共享运行基础已实现并完成前端/隔离浏览器验证；app/Core仍为1.7.0、协议1.2。本轮不构建安装包，原生工具窗及10×3设计候选另行验证。

直接上游：[需求规格说明](../20_需求分析/需求规格说明.md)R10及既有R1—R9；实施入口：[主题专项主代理提示词](../40_开发实施/前端主题样式专项-主代理提示词.md)。用户确认目标为可切换主题，不再沿用“最终只能保留一个固定风格”的旧建议。仍然只有一套Vue业务前端。

## 1. 产品边界

- 一套Vue组件、业务状态、路由、Core与CLI；不同主题是同一软件的展示配置，不是十套业务前端。
- 主题文件真实存在、可独立校验并随发行打包。通过设置切换，覆盖全应用、教学内容、独立工具窗与交互反馈。
- 本专项做内置主题与开发候选比较，不做主题商城、账号、在线AI、任意脚本插件、网络主题下载或课程内注入样式。
- 用户答案、学习轮次、计划笔记、冻结课程版本不属于主题；切换主题不触发提交、重新导入或新建轮次。
- 外部Agent创建的课程仍是受控语义内容包，不允许课程作者附带CSS/JS改变主题。

## 2. 配置与运行模型

```text
内置主题文件 + 受审查的本地样式/反馈预设
  → schema/type校验与主题注册表
  → 应用级主题状态（单一来源）
  → 根节点标识 + CSS语义tokens + 受控展示预设
  → 同一Vue组件的主窗 / 工具窗
```

优先使用JSON manifest/tokens；伴随CSS必须是源码中受审查、构建期打包的静态文件，不从任意用户路径或远端动态执行样式。每个主题一份配置，禁止凭主题ID复制整套组件或业务。

历史设计阶段的配置语义示意（非完整输入；**当前准确schema已实现，见第8节和contract.ts，不再重新定义**）：

```json
{
  "schema_version": "studyflow.theme/1",
  "id": "sequence-light",
  "name": "序光",
  "appearance": "light",
  "tokens": {
    "surface.canvas": "#F6F2E9",
    "surface.panel": "#FFFCF5",
    "text.primary": "#272A28",
    "accent.primary": "#2D6B60"
  },
  "presentation": {
    "density": "comfortable",
    "heading": "editorial",
    "teaching": "paper"
  },
  "motion_profile": "gentle",
  "sound_profile": "soft-tap"
}
```

该片段只示意格式，不能因为存在四个颜色就宣称主题完整。完整主题至少具备：

| 配置域 | 必须表达的语义 |
|---|---|
| 界面表面 | 主背景、导航、阅读、工具区、浮层、选中/悬浮、分隔与阴影 |
| 排版 | 中文正文与标题层级、代码字体、字重、段距、行距推荐值、密度 |
| 操作 | 主/次/危险/禁用按钮、输入、焦点、加载、图标及滚动条 |
| 生命周期 | 未学、当前位置、已读、待批改、待修正、待发复测题、待复测、通过；文字/图标不可仅由颜色替代 |
| 教学 | 概念、比较、步骤、例题、提醒、小结、练习关联，以及代码/公式/表格/引用 |
| 反馈 | 成功、失败、冲突、未确认、只读、来源和恢复提示 |
| 动态与声音 | 已注册预设及适用事件，不是任意脚本、远程资源或自动播放设置 |

主题可改变层次、边界、留白、密度、受控标题/教学展示方式；不能改变导航信息架构、按钮含义、保存语义或读写规则。通用展示变体应由主代理一次性加入共享组件，不能为各主题复制renderer。

### 校验与安全

- 必填tokens/枚举/版本/ID/数值范围应校验；不认识的ID、缺字段、损坏配置或不受支持的版本均回退默认主题，并给可理解的非阻塞提示。
- 字体取本地可用/随包且有许可的注册项；颜色、尺寸、时长分别按类型解析，不把整个字符串当任意style文本执行。
- 不接收主题内JS、HTML模板、函数、路径跳转、外部URL、`@import`或跟踪资源；禁止`eval`及削弱Tauri CSP来迁就主题。
- 配置文件限制大小/数量，避免无限watch、恶意超大值、重复ID及层叠爆炸；主题资源离线可用。
- 若需要高级静态CSS，只能作用于约定的主题命名空间/展示hook，不用`!important`战胜未知结构，不修改事件/数据绑定。

## 3. 持久化、偏好优先级与多窗口

1. 主题偏好是本机应用级外观设置，不是课程数据；优先复用现有轻量持久化。该专项没有引入Redis或额外后端的依据。
2. 显式保存的字号、行距、正文宽度等阅读偏好优先于主题推荐值。旧偏好无法判断是否显式时保守保留，不靠换主题重置用户习惯。
3. 音效总开关、减少动态效果优先于主题预设；主题不能偷偷启用声音或恢复已关闭效果。
4. 加载启动偏好要避免先闪白再切深色；存储不可用时保持会话级偏好及可用默认值，不阻塞学习与保存。
5. 主窗、已拆出的练习/笔记/大纲窗共享同一外观偏好；新窗在首屏取得当前主题，切换同步不能形成事件回声/重复提示。
6. 切换仅更新样式与展示参数：不重载页面、不以themeId给编辑器重新key、不破坏焦点、选文、答案、笔记、阅读位置和未确认请求的原幂等键。
7. 展示调整导致几何变化时尽量保留当前内容锚点，而不只盲目保留一个过期scrollTop。主题设置与阅读偏好的重置分别确认。

## 4. 需要全覆盖的工作面

| 工作面 | 必须覆盖 |
|---|---|
| 应用壳 | 无边框标题区、窗口控制、侧导航、可调整分隔器、细滚动条、焦点与禁用状态 |
| 学习控制台 | 按计划聚合课程、今日安排与主推进、空/加载/故障；不叠重复仪表盘 |
| 我的计划 | 列表、详情、课程顺序、安排/编辑/暂停/归档等已有入口 |
| 课程学习 | 紧凑路径导航、多个知识点、状态图标、阅读布局；简介仍在路径/详情，不恢复巨大顶部卡片 |
| 结构化教学 | `concept/comparison/steps/example/callout/summary/practice`全部七类及嵌套内容 |
| Markdown兼容 | 标题、列表、引用、代码、链接、表格及长内容；不重新添加强制查看原文入口 |
| 作答与批改 | 题目、约束、输入、自动草稿、整课提交、等待/修正/独立复测、原句引用与只读历史 |
| 连续计划笔记 | 浏览/编辑/搜索/摘录来源/导出、关联课程知识点、冻结来源只读 |
| 右工具区 | 默认收起、紧凑入口、展开等高三栏、标签/双窗格/拖宽/拆出/放回；不得变回正文中的小卡片 |
| 独立原生窗 | 同一Vue工具组件、跟随整课、共享答案与笔记、置顶、关闭协调与失焦/后台行为 |
| 工作区与外观 | 工作区选择、备份恢复、阅读偏好、主题选择/预览、声音开关/试听及已有设置 |
| 全局反馈 | toast、loading、empty、error、冲突、未确认、恢复、离开确认/导出/明确不保存退出 |

执行时依据当前路由/组件生成逐项覆盖清单；上表不是凭历史猜出页面路径的许可。

## 5. 视觉与听觉反馈

- 即时反馈要明确“点到了、正在处理、结果如何”，不要持续闪光、粒子雨、全屏运动或积分/排行。
- 采用受控hover/press/focus、面板开合、定位高亮、保存状态与完成提示；长正文不能被装饰和动画遮挡。
- 默认轻量，尊重`prefers-reduced-motion`和用户关闭；减少动态效果时保留文字/静态状态，不让重要状态消失。
- 复用现有`shared/ui/interaction.ts`入口。主题选择音色预设，不建立十套AudioContext/事件监听器。
- 默认静音；总开关/静音偏好独立于主题。试听须用户主动触发，不能在启动或换主题时自动响。
- 音效只能辅助既有操作，不能替代文字；禁止每次输入/自动保存/跨窗同步持续鸣叫。
- 同一业务事件去重；只由当前交互所属窗口发声，后台/非活动窗不重复响。音频不可用不得阻止操作。
- 成功动画/声音只能响应已确认成功；等待、失败、超时与未确认请求不得伪装完成。错误必须可见并保留真实下一动作。

## 6. 候选与发行分离

候选工作区不是成品源码权威，不读取/恢复旧V-A/V-B/V-C。默认10个主题方向、每方向3个不同适用设计Skill实现，总计30个候选；可扩展但不无限重复。

候选必须使用同一冻结展示基线、同一组纯合成内容与主题契约，通过真实Vue组件比较全工作面。可信CSS/纯展示Vue/本地图片新包按最新设计实施，旧v1 preview只加载JSON。静态HTML可以作为过程草图，不能作为交付或业务验收。最终每个主题方向选一份最优实现进入同一注册表；其余候选/截图/临时环境留在私有候选区，不混进发行。

选择理由必须涵盖中文长读、层次、操作、教学块与一致性；出现丢输入、误报保存成功、破坏生命周期/窗口或关键入口不可达，直接淘汰。主代理技术选型不代替用户长期阅读与审美验收。

## 7. 验证门槛

- 配置schema/默认回退/异常偏好/主题切换单元测试。
- 每主题覆盖全工作面，包含长中文、多知识点、所有教学块、长表/代码、错误/只读/空状态。
- 浅深主题及窄窗、宽窗、100%/150%/200%缩放、键盘和减少动态效果；对比度和状态语义不能靠截图臆测。
- 切换时有未保存输入、IME组合输入、阅读滚动、打开/拆出工具窗、保存中/未确认/恢复操作，均不丢输入或重发请求。
- 真实Core隔离闭环：保存→整课提交→批改→修正→独立复测→再次通过；主题不得改变API或幂等/事务行为。
- 音效关闭/试听/开启/跨窗去重/后台静音/音频失败；监听、定时器、AudioContext和CSS不随反复切换泄漏。
- 工程测试、原生烟测、人工长期舒适度分开记；没有执行的测试不能填通过。

## 8. THEME-BASE已实现的配置与接口（2026-10-03）

权威源码是`apps/desktop/src/shared/themes/`，不是本节示例的复制品：

- `contract.ts`：`studyflow.theme/1`精确字段/28个语义tokens，完整`#RRGGBB`不透明颜色；文字/按钮/状态至少4.5:1、焦点至少3:1；非法版本、未知字段、外部资源和脚本式值拒绝。
- `builtin/*.json`：当前正式内置主题为“序光”（`sequence-light`）与“白紫轻学”（`white-violet`）；`white-violet`仍是`DEFAULT_THEME`。`catalog.ts`构建期发现所有内置JSON，不需逐主题复制Vue代码。历史退出主题只在`docs/archive/2026-10-06-retired-builtin-themes/`保留迁移证据，不参与构建。
- `controller.ts`：纯偏好/注册、导入导出/移除、损坏回退及revision去重；快照不含业务数据。最多32KB/主题、20份本地自定义主题；同自定义ID导入为显式更新，不覆盖内置ID。
- `index.ts`：`initializeThemes/selectTheme/importTheme/exportTheme/removeTheme/resetTheme`；根节点语义CSS变量及白名单preset。偏好键`studyflow:theme-preference:v1`；浏览器storage/BroadcastChannel与原生`studyflow-theme-updated`、`studyflow-theme-request`同步，新窗口请求当前快照；不调用Core。
- `runtime.css`：应用、教学、练习、反馈、笔记及工具区共用语义颜色和展示预设。`readingPreferences`与`interaction.ts`仍是既有唯一入口；只有音色预设变化，总开关不随主题开启。
- 外观设置`ThemeSettings.vue`提供两套正式内置主题预览与选择、JSON本地导入/导出、移除自定义和恢复默认，挂在工作区设置，不新增独立业务前端。

允许的presentation：density=`comfortable|compact`；heading=`editorial|modern|technical`；teaching=`paper|clean|outlined`。motion=`gentle|minimal|none`，sound=`soft-tap|glass|muted`。预设是受审查源码，不是主题文件任意CSS。减少动态效果始终优先；声音默认关、后台/失焦窗静音，音频失败不阻塞。

### 外部Agent的扩展方式

1. 复制任一内置JSON作为完整起点，改为自己的唯一ID/名称/说明和色板；不要从不完整旧示例猜tokens。
2. 在`apps/desktop`执行`npm run theme:check -- <配置文件路径>`只读校验，返回JSON与退出码。
3. 用户可在工作区→外观主题直接导入；偏好仅在本机WebView/profile保存，不是学习工作区数据库的一部分。迁移自定义主题使用导出/导入，不承诺工作区备份自动带走外观偏好。
4. 被选为内置主题时，由主代理审核后放入`builtin/`，运行主题测试及生产构建。新布局/排版hook仅在共享源码经过审核后成为白名单预设，再重新冻结候选基线；子代理不能任意注入样式或写共享文件。

工程验证见[主题基础计划](../40_开发实施/主题切换基础实施计划.md)与[验证记录](../40_开发实施/验证记录.md)。三主题只证明底座和兼容性，不代表十个方向已完成或长期舒适度已验收。


## 9. THEME-VISUAL-B最新设计权限（尚未实现）

v1配置导入仍是纯数据；可信构建期主题包允许独立CSS、纯展示Vue及本地图片改变布局、容器、教学模板、排版/几何/表面。不是只挑几个固定preset，也不是动态执行任意外部程序。CSS可用审核本地url，但不请求网络资源或遮挡错误/退出，布局语义和键盘顺序需检验。
