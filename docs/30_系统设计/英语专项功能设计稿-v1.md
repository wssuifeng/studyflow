## 1. 设计总览

### 1.1 在既有学习系统中增加英语模式

```text
学习计划 → 有序课程
            ├─ 普通课程：知识点 → 教学正文 + 练习
            └─ 英语课程：可选训练组 → 有序词句训练项

共用：课程身份、冻结学习轮次、答案/反馈、修正/复测基础能力、计划笔记和工作区。
错误管理：按计划分册；普通错题与英语训练错误分域，课程内再定位到具体学习项。
```

- **训练项**：一次可输入和检查的单词、词组或句子。
- **训练组**：复用既有Lesson组织相关训练项；只有一组时直接进入训练，不增加一次选择跳转。
- **学习轮次**：一次学习使用的固定课程版本；课程修订不改变正在学习的题目、规则或音频引用。

英语新增专用页面和组件，仍属于同一Vue应用。训练页占满应用客户区，不强制使用普通课程的固定左栏和文档阅读三栏；保留共享主题、原生窗口功能与可靠保存链。

### 1.2 核心设计选择

| 方面 | 设计 |
|---|---|
| 即时训练 | 固定答案由Core本地规则检查；开放表达/争议由Agent审核，不要求每句等待Agent |
| 提交 | 本句检查保留一次尝试；整课提交统一确认本轮结果，二者不是同一操作 |
| 错误管理 | 按计划与课程分层；普通错题本、英语训练错误统计和英语复习清单分开，不把每次答错都变成待办；共用证据引用与复测基础能力 |
| 语音与辅助 | 首版词典优先，音标/释义也优先查询词典；保留预生成本地资源的兼容扩展，不要求制课先生成语音，不在学习时调用TTS供应商 |
| 进度 | 本地保存位置、已练项、整课提交和待复测情况；不依赖登录，不宣称长期掌握 |

不引入登录/会员、AI对话、积分排名、常驻后端或第二套前端。课程编写流程与提示词的单一来源是[通用制课规则](../../skills/studyflow-agent/references/course-authoring.md)和[英语制课规则](../../skills/studyflow-agent/references/english-course-authoring.md)。

## 2. 页面与操作

### 2.1 页面入口和关系

```text
学习控制台 / 计划详情
  → 英语课程概览
      → 开始 / 继续 → 英语训练页
                         输入 → 纠错 / 答案 → 下一项
                         → 整课结果 → 返回课程 / 下一课 / 错题复测

错误管理入口 → 选择学习计划
                ├─ 普通课程错题 → 课程 → 错题详情 → 修正 / 复测
                └─ 英语训练 → 课程 → 训练错误统计 / 复习清单
                                      → 错误证据 / 无提示复测 → 英语训练页
```

| 工作面 | 呈现与主要操作 |
|---|---|
| 英语课程概览 | 课程目标、训练组/项列表、完成情况和继续入口；课程简介只在这里展示 |
| 英语训练页 | 专用全窗口工作面，输入、纠错、答案和本轮结果共用同一页面/控制器 |
| 错误管理入口 | 先按计划展示普通/英语分册及简洁摘要，不默认平铺全工作区错误 |
| 普通错题本 | 按课程浏览需修正/待复测的题目，条目内对照原题、原作答、原因与历史 |
| 英语错误与复习 | 按课程展示高频错误聚合；“全部训练错误”与“需要复习”分开，详细尝试按需加载 |
| 按需目录/笔记 | 显式打开才占空间；目录定位训练项，笔记仍归学习计划 |
| 独立工具窗 | 显式拆出后转移编辑权，复用同轮次，不另开课程或答案副本 |

建议路由为`/english/course/:id`、`/english/study/:studyId`；`/mistakes`仅作为分册入口，计划内分别进入`/mistakes/plan/:planLineId/general`和`/mistakes/plan/:planLineId/english`。课程筛选保留在分册内，不为每个课程建一套错题软件。复测用既有普通作答页或英语训练页的任务模式进入。

### 2.2 全窗口训练布局

```text
┌──────────────────────────────────────────────────────────────────┐
│ 返回课程  课程短标题 · 17/24                    发音设置  笔记  窗口控制 │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│                        中文提示 / 当前训练目标                      │
│                                                                  │
│                    [输入位] [输入位] [输入位] ...                   │
│                    或：原错误 → 当前修正输入                         │
│                    或：英文答案 / 音标 / 释义                        │
│                                                                  │
│                    当前反馈 / 必要提示 / 播放入口                    │
│                    再练 / 检查或下一项 / 暂时跳过                    │
│                                                                  │
├──────────────────────────────────────────────────────────────────┤
│ 课程目录   上一项                         快捷键提示          保存状态 │
└──────────────────────────────────────────────────────────────────┘
```

- “全窗口”是占满StudyFlow客户区，不强迫操作系统全屏；保留拖动、最小化、最大化、关闭。
- 连续工作面，不堆大白卡和仪表盘。课程进度只在顶部表达，不在底部重复课程简介。
- 输入/词句居中但不无限拉宽；短词、长句、纠错使用同一自适应宽度，长句可按顺序换行。
- 输入态主动作是检查，答案态是下一项，末项是完成本课；跳过/再练是次要操作。
- 目录默认不占固定左栏。笔记宽窗让训练区适度让位、窄窗使用可关闭覆盖面；关闭后不留空栏。

布局借鉴用户保存的商业答案态快照的顶部导航、居中词句和底部操作关系；输入/纠错结合已体验的Earthworm行为。商业积分、“掌握”、生词本、AI助手和会员菜单不复制进本项目。

### 2.3 训练页的状态表现

| 状态 | 显示内容与操作 | 保留的业务信息 |
|---|---|---|
| 输入 | 中文提示、可聚焦单词位；答前不直接展示完整参考。Space/Enter推进，最后一位检查 | 当前输入、位置、草稿版本 |
| 纠错 | 按位置标识不匹配；聚焦首个错位。开始输入后首键直接上屏，原错误在邻近对照中保留 | 原尝试不可变，修正输入另存 |
| 答案 | 目标词句为主，音标/释义分层，播放靠近内容；可继续或再练 | 本地匹配/辅助证据，不冒充Agent批改 |
| 等待/失败 | 保留输入，不白屏。保存/引擎异常与答错明确分开，支持重试/导出/不保存退出 | 未确认请求、原幂等键及本机编辑 |
| 整课结果 | 简洁显示完成/未完/辅助项、待复测或待Agent；提供下一动作 | 整课是否提交与题目处理结果分别表达 |

键盘仅作用于当前输入组件，不抢笔记/设置操作；IME组合时不提交。鼠标/Tab可定位，空位Backspace可返回，整句粘贴不悄悄丢词。按住按键或请求处理中不重复派发检查。正确反馈使用克制的动画/可选音效，不为每题或每个单词加生命周期状态栏。

### 2.4 工具、主题和窗口尺寸

- 课程目录展示组别/训练项和已练/未练，选择后关闭并恢复焦点；练习总览定位未完成项，不复制第二个答案编辑器。
- 2026-10-11 最新确认：英语侧工具区只保留笔记；取消侧栏练习和独立答题窗。训练/纠错/复测在全窗口英语工作面完成。笔记可复用既有独立笔记窗及单编辑权，不与答案混存；普通课程练习工具不受影响。
- 训练页使用共享AppShell的`immersive-learning`变体；普通课程继续现有阅读布局，不随英语页改成另一种壳。
- 根容器使用标题栏、`minmax(0,1fr)`训练区和底部操作区的Grid或等价Flex，占用可用高度，不随内容无限向下扩展。
- 1080p、1440p、4K保持完整工作面；窄窗压缩辅助信息、长句换行，极低高度允许训练区内部滚动，不能裁掉主动作和退出。
- 序光/白紫共用功能布局、状态和控制器；主题只改变视觉。焦点、错误文字、对比度、减少动效和音量偏好始终有效。

## 3. 核心业务流程

### 3.1 创建课程到恢复学习

Agent经CLI发布课程（首版不要求生成音频） → 用户从课程概览开始或继续 → Core创建/恢复CourseStudySession → 训练页使用冻结题面/校验策略，需要发音与辅助信息时按词典策略查询。

课程目录和完成记录读取本轮证据，不能仅靠滚动百分比或恢复位置判断学完。当前轮次不自动升级到新课程版本。

### 3.2 本句检查与整课提交

```text
输入 / 自动保存 → 提交本句检查 → Core计算并持久化一次尝试
                                      ├─ 不匹配 → 定位 → 修正 → 新尝试
                                      └─ 匹配 → 答案/语音 → 下一项
完成训练 → 检查未完成项 → 整课提交 → 本地规则反馈或Agent队列
```

- 本句检查不等于整课提交；中途退出可以恢复训练/草稿，不显示整课已完成。
- 保存/检查串行化，结果必须对应当前答卷hash/版本。检查后继续编辑使旧匹配失效，迟到回执不覆盖新输入。
- Core使用冻结目标、受控分词和策略，不接受前端传matched=true。默认处理多余空白，大小写策略显式声明；标点支架不冒充标点考核。
- 缩写/连字符按受控分词；变体按完整句白名单，不任意拼接位置答案。首版单词位支持等token数变体，不同结构可送Agent审核。
- 本地只判断是否符合声明答案规则，不凭词差猜测语法原因。引擎失败不是答错。
- local_exact课程完成需必做项有有效匹配或明确Agent裁定。中途可跳过，最终定位缺项；有提示完成与无提示结果分开。

### 3.3 单项Agent审核

学习者显式提出争议 → 锁定该项输入并提交通用Submission，评估方式转为agent → Agent读取冻结题面/原输入 → 写正常ReviewFeedback。

审核中其余句子可继续。需要修正时产生子Submission，本地匹配不能消除未解决Agent意见。整课确认复用已经审核的有效答案，只确认剩余本地草稿并登记批次，不重复提交该项。裁定仅对当前冻结题/答案有效，新增课程白名单另走修订。

### 3.4 分域错误管理、修正和复测

两类错误的频率和用途不同，不能共享一个平铺集合或强行套用同一状态机。

| 对比 | 普通课程错题 | 英语即时训练错误 |
|---|---|---|
| 来源 | Agent对正式作答的有效批改 | 明确提交的一次词句检查；或该项的有效Agent反馈 |
| 记录粒度 | 同计划、同课程、同语义题的错题条目，内部有多个问题 | 每次检查保存证据；按同课程、同语义训练项与规则版本聚合 |
| 初次答错 | 根据批改进入修正/复测流程 | 在当前训练页即时纠错，不立即创建一条长期待修正任务 |
| 后续处理 | 待修正 → 已修正/待复测 → 本次复测通过 | 训练统计保留；只有被选入复习清单的项才进入待复习 → 复测中 → 本次通过 |
| 再次失败 | 新证据重新打开条目，不覆盖历史 | 更新聚合；已进入复习清单的项重新待复习，不重复建条目 |

跳过、未作答、词典/保存/引擎失败不计为答错；未完成项在课程结果中定位，不能自动转成错误证据。

英语复习清单的首版收录条件为：**学习者手动标记、结束训练/完成检查时仍有未解决错误（即使尚不能正式提交）、无提示复测失败**。跨轮次反复失败可以推荐关注，但首版不依据未经确认的次数阈值自动派任务。瞬间拼写失误即使已在本轮改对，仍有证据，但不自动占据长期复习清单。

- 英语检查统计区分“失败尝试次数”和“发生失败的轮次/复测任务数”；同一轮反复纠正不能伪装成多次遗忘。
- 同一次幂等重放不增加次数；普通反馈和英语检查若属于同一作答证据链，不重复计算同一次错误。
- 错词位置属于证据细节，不将每个错词拆成独立待办；英文相同但课程/教学目标不同的项不按文本自动合并。
- 原输入在EnglishCheckAttempt或Submission中，错题/统计/复习条目只引用证据。Agent裁定某个不同表达有效时，原本地不匹配保留为历史，但不继续当作有效语言错误安排复习。
- 普通复测沿用 Agent 发布的 RetestTask；英语原冻结题的无提示复测保留。2026-10-11 用户将原“新句型迁移复测”意图调整为：Agent 依据英语错误编写从单词到词组/句子/变式的渐进式补充学习，作为错误与复习功能的补充；MAIN/SUPPLEMENT隔离、/4递进内容和来源发布见§5.4。本次通过不宣称长期掌握。
- 已归档条目遇到新的有效失败证据重新成为活跃；归档不代表学会，也不抹除历史。

### 3.5 语音与辅助信息：词典优先

```text
首版默认 dictionary_only：目标词/句 → 受控词典 → 可用发音/音标/释义
                                            └─ 缺失/断网 → 已校验缓存或内容自带信息 → 不可用提示
后续兼容 auto：词典 → 同文本/请求口音的已登记本地资源 → 不可用提示
后续兼容 local_only：仅已登记本地资源
```

首版优先接通词典模式，不依赖语音供应商配置或每课预生成；语音与释义可以分别失败，不因缺少一项而隐藏另一项。目标句可能没有词典整句音频，应显示实际可用的词级信息，不能把拼接单词音频冒充自然整句朗读。词典释义仅作辅助，不能替代课程提示、合法答案或教学目标。

- 词典请求只发送目标词/句及必要语言/口音参数，不发送用户错答/笔记。在线访问、缓存/使用范围按实际提供方约束，不默认获取永久音频副本。
- 缓存绑定查询文本、提供方、语言/口音和资源标识；已校验的本地缓存可复用，没有缓存就明确离线不可用。不能把上一题释义或声音显示到新题。
- 查询和播放均可取消；切题/换窗/换口音后拒收旧响应，全应用只有一个语音播放所有者。语音与界面音效分别有音量、静音和自动播放偏好。
- 请求口音不可用时明确说明；用户可显式选择可用口音，不能修改标签冒充英音/美音。
- 查看答案、答前听目标语音或查看能直接泄漏目标词的辅助信息记录为有提示；正确后的正常朗读不改变既有无提示结果。
- 保留AudioAsset与冻结引用的扩展位。后续经授权在外部制课生成语音，再由CLI校验文本、格式、大小、hash及工作区路径后登记；学习端不持有TTS供应商Key，也不实时请求供应商。

## 4. 程序架构与职责

### 4.1 模块协作

```text
Vue页面 / 外部Agent CLI
         ↓ shared API、Engine桥或CLI适配器
application：组合用例、统一事务与跨模块只读视图
         ↓
Python Core（一级业务模块 → 二级职责包）
  planning → 计划归属、课程顺序和日程
  courses  → 普通/英语内容、修订发布与冻结材料
  learning → 轮次、草稿、英语检查事实与整课提交
  reviews  → Agent审核、反馈与复测任务发布
  mistakes → 普通错题、英语聚合/复习、分层查询与归档
  audio    → 词典适配、资源登记和来源解析
         ↓ 同一Runtime / Session / Base
SQLite + 工作区不可变课程资源（后续可包含本地音频）
```

错误管理共用查询与证据基础设施，**不共用两类错误的业务表和状态机**。learning/reviews输出检查或批改事实；application在同一事务中调用mistakes更新索引，禁止两个模块各自commit，也不让它们循环调用对方服务。词典网络请求不占用学习写事务；发音失败不是答错。

### 4.2 两级包结构

以下是**目标结构，不是当前目录已迁移完成**。`modules/`下第一级按业务模块，模块内第二级按实际子业务/职责划分；模型、服务、查询就近放在所属子包，不在模块根目录继续堆全部实现。

```text
packages/core/src/studyflow/
├─ modules/
│  ├─ planning/   → plans/、curriculum/、scheduling/
│  ├─ courses/    → catalog/、content/、english/、publication/
│  ├─ learning/   → sessions/、drafts/、english/、submissions/、progress/
│  ├─ reviews/    → assessment/、queue/、retest/
│  ├─ mistakes/   → general/、english/、query/、archive/、remediation/
│  ├─ audio/      → dictionary/、assets/、resolution/
│  ├─ documents/  → catalog/、storage/
│  └─ workspace/  → lifecycle/、snapshots/、context/
├─ application/  → 学习用例编排、跨模块只读聚合
├─ interfaces/   → cli/、engine/、web_compat/（薄适配器）
└─ infrastructure/ → persistence/、diagnostics/等共享基础设施
```

| 子包 | 主要归属 |
|---|---|
| courses/content、courses/english | 普通教学块契约 / EnglishItem内容契约；不保存学习者作答 |
| courses/publication | 包校验、导入/修订、冻结材料构建；不另建数据库连接 |
| learning/sessions、drafts、submissions | 冻结轮次 / 草稿与CAS / Submission及整课保存提交 |
| learning/english | 分词、checker、EnglishCheckAttempt和输入扩展；可信结果只有一份实现 |
| reviews/assessment、queue、retest | 批改事实 / Agent待办 / 不可变复测任务发布；作答仍由learning承载 |
| mistakes/general | 普通错题条目、错误来源与修正/复测投影 |
| mistakes/english | 高频训练聚合、错误证据引用与精简英语复习清单 |
| mistakes/remediation | 补充课程来源引用与有界查询；跨模块发布事务在application装配 |
| mistakes/query、archive | 分册目录、作用域校验、摘要/分页读取 / 逻辑归档与历史定位 |
| audio/dictionary、assets、resolution | 词典提供方适配与缓存 / 本地资产校验 / 来源、口音及可用性解析 |

例如`learning/english/`可有`models.py`、`checker.py`、`service.py`，`mistakes/english/`可有`models.py`、`projection.py`、`queries.py`。只在存在实际职责时创建文件，不机械复制controller/service/mapper/impl或空repository层。模块根保留必要的公开入口与装配；旧导入路径用薄兼容导出。模型仍共用单一Base及显式registry，不把所有模型重新塞到基础设施文件。

Vue同样保持`app/features/shared`，英语在`features/english/{course,training,remediation}`，错误管理在`features/mistakes/{overview,general,english}`，各子功能内放页面/组件/状态；共享播放能力属于`shared/audio`，不反向依赖某个课程页面。已有模块逐个有测试地迁移，不在新增功能时一次性移动全仓。

### 4.3 页面与适配器边界

| 单元 | 责任与边界 |
|---|---|
| EnglishCourseOverview | 课程概况、训练目录、进度和开始/继续入口 |
| EnglishTrainingPage及其控制器 | 同一轮次下管理输入/纠错/答案/结果；复用保存链，不另建状态机 |
| EnglishPrompt / TokenAnswerEditor / EnglishAnswerView | 展示与输入/焦点，不承担可信评分 |
| EnglishCourseDrawer | 按需目录与未完成定位，不常驻占宽 |
| MistakeWorkspace及普通/英语子视图 | 共用计划/课程导航，不共用内部错误列表、统计口径或状态机 |
| 共享音频协调器 | 取消过期播放、单播放所有者与音量；不执行TTS生成 |
| Tauri | 窗口、Engine和受限本地资源访问，不写教学或评分规则 |

沿用模块化单体，不加入Redis、微服务、每计划独立后端或手动启动服务。

## 5. 数据模型与关系

### 5.1 课程、轮次与事实源

```text
PlanLine → Course → Lesson → Exercise
                            └─ EnglishItem（1:1，exercise_id为PK/FK）
CourseStudySession → 冻结题面、英语规则与可选音频引用
Submission → EnglishSubmissionDetail（1:1，可选）
           → ReviewFeedback / RetestTask / 后续Submission
EnglishCheckAttempt → 某轮/复测任务、某题的一次明确检查
```

| 对象/拟议表 | 数据与职责 |
|---|---|
| Course扩展 | learning_mode与英语策略；旧课默认general，保留content_type语义 |
| EnglishItem / english_items | 与Exercise一对一；目标文本、完整句变体、tokens、可选音标/讲解/资源引用和作者目标标签；顺序及语义ID归Exercise |
| EnglishSubmissionDetail / english_submission_details | Submission的token输入、辅助/跳过标记、评估方式及有效尝试引用 |
| EnglishCheckAttempt / english_check_attempts | 不可变输入、差异位置、matched_variant、rule_hash/checker版本、课程/轮次/任务与答卷版本、请求hash和稳定回执；非逐键流水 |
| AudioAsset / audio_assets（兼容扩展） | 已校验本地资源hash、相对路径、格式、实际语言/声音与参数；首版不要求每项有资源，不存Key |
| ReviewFeedback / RetestTask扩展 | 评估来源、元数据 / 普通或英语任务模式与私有参考；沿用原父子链 |

EnglishItem不能另建悬空答案身份。最终作答由Submission承载，训练尝试由EnglishCheckAttempt承载；错题/复习结构只存引用，不再复制一份原答案。课程、规则及可选资产清单随修订冻结；词典实时结果是辅助，不改变评分规则。rule_hash覆盖冻结目标/合法变体、影响题意的提示、分词与大小写/标点策略及checker版本，不只对英文文本求hash。

### 5.2 按计划分册、按课程分区

```text
学习计划（PlanLine）
  ├─ 普通分册（MistakeNotebook: general）
  │    └─ 课程 → GeneralMistakeEntry → 多问题/错误证据 → Submission/ReviewFeedback
  └─ 英语分册（MistakeNotebook: english）
       └─ 课程 → EnglishErrorAggregate → 多次错误证据 → CheckAttempt/ReviewFeedback
                       └─ 按需选入EnglishReviewItem → 修正/无提示复测任务
```

| 对象/拟议表 | 范围与数据 |
|---|---|
| MistakeNotebook / mistake_notebooks | 分册身份；`(scope_key, domain)`唯一，scope_key为`plan:<稳定ID>`或`unassigned`，关联可空plan_line_id；仅公共元数据，不承载混合错题表 |
| GeneralMistakeEntry / general_mistake_entries | 分册、课程、稳定题目身份、评估版本与当前修正/复测投影；普通题一条可定位多个问题 |
| GeneralMistakeOccurrence / general_mistake_occurrences | 条目关联批改/原作答/复测证据，来源唯一；原错误文本不复制 |
| EnglishErrorAggregate / english_error_aggregates | 分册、课程、稳定训练项、rule_hash；首次/最近错误、失败尝试数、失败轮次数、辅助情况和最近有效结果的可重建聚合 |
| EnglishErrorEvidence / english_error_evidence | 只引用检查或Agent反馈二者之一，来源唯一；同链关联而不重复计次，保留来源修订/轮次/任务信息 |
| EnglishReviewItem / english_review_items | 仅需要复习的聚合项建立条目；聚合引用、收录原因、复习状态、任务引用；每聚合只有一个复习条目，再失败重新打开，非每次失败一条 |

**作用域以学习时的计划上下文冻结**，不能回头仅用Course当前归属推导。既有Course允许未绑定计划，且学习计划有自己的课程挂载关系：未归属内容进入显式“未归属课程”分册，不混入任一计划；同课在多个计划下学习时各自统计。后续移动/重新挂载课程不自动搬移旧证据，迁移归属必须显式确认。已有活跃轮次从其他计划入口打开时，明确提示原归属，不静默切换作用域。旧轮次无可验证计划来源时归未归属，不猜测回填。逻辑分册不等于为每个计划/课程建库或建表。

聚合键为“分册 + course_id + 稳定exercise语义身份（带Lesson作用域） + 评估规则版本”，不是题目文字或裸semantic_id。无稳定语义ID时回退真实Exercise身份，不凭句子相同猜测合并。规则/题面实质变更产生新评估键，旧复测结果不能直接套用；相同规则的格式修订可归同聚合，但每份证据保留实际课程修订/冻结题面引用。多个错词是证据内的定位，不增加额外错题身份。

### 5.3 长期数据治理与查询口径

| 层次 | 使用场景 | 首版规则 |
|---|---|---|
| 分册/课程摘要 | 页面首页、Agent规划 | 只读计数、活跃项/待复习/最近变化；普通错题与英语失败分别统计，不全量返回答案 |
| 活跃条目/聚合 | 当前修正、短期复习与重点发现 | 按计划→课程→题/目标标签过滤，游标分页，有限条数 |
| 历史证据 | 解释具体为什么错、跨轮对比 | 按条目和轮次/时间范围读取不可变尝试/反馈；分页，不随列表整批带出 |
| 归档历史 | 旧课、已关闭任务、长期回顾 | 显式归档后默认不进入活跃列表；可按相同作用域检索，重新失败可激活 |

- 首版仍使用应用管理SQLite。对分册、课程、条目、时间/稳定ID建立复合索引；聚合是可重建读模型，单事务增量更新，不在打开页面时遍历所有历史。
- 错误事实只在明确检查/有效批改时产生，不保存每个按键；短时多次修正仍保留检查证据，但不重复增加复习清单条数。
- 统计必须注明时间范围与口径；区分累计失败尝试、失败轮次和当前需复习项数。没有记录不等于“没有错误”，复测通过也不是长期掌握。
- 归档是逻辑检索分层，**不会减小数据库，也不等于删除**；首版不设置未经确认的自动保留天数、不自动删原答案。确需减容时另行设计按作用域预览、完整备份校验、显式确认且保护活跃轮次/任务引用的清理操作，不能借归档暗中清库。
- 工作区导出包含分册、聚合、事实证据和任务，恢复后可校验/重建聚合。课程资源被删除/修订时保留冻结证据的可读入口，不能产生找不到原题的错题。

英语与轮次/补充来源已追加迁移0013—0015；本节表达设计关系，实际字段以模型与system.schema为准。真实工作区尚未升级，新安装包尚未构建。

### 5.4 基于错误的渐进式补充课程

计划课程挂载增加 `track=MAIN|SUPPLEMENT`（旧数据默认 MAIN），两个分组各自排序。主线总数、重点、进度与重排只统计 MAIN；补充列表单独计数，明确安排日期可进入今日课程但不挤占自动主线重点。

| 对象 | 职责 |
|---|---|
| EnglishRemediationCourse / english_remediation_courses | 课程来源档案：course_id、plan_line_id、目标标签、简明理由、来源hash；一课一档案 |
| EnglishRemediationSource / english_remediation_sources | 课程关联 aggregate/evidence 引用、来源版本和rule_hash；一课多来源、多课可复用来源，course/evidence唯一；不复制原答案 |
| Exercise.english.progression（课程包/4） | chain_id及stage；阶段vocabulary/chunk/pattern/variation/transfer；随正常内容修订/轮次冻结 |

Agent按限定计划/课程读取真实有效错误和上下文，判断小范围教学目标，不从单次词差自动诊断。默认从必要单词、短语逐步组合句型与变式，最后用新表达迁移验证。补充发布要求每项有递进标识、同链不倒退、至少词汇/句型/最终迁移；普通主线的/4局部递进不强制套用整条补充结构。

preview只读校验包路径/范围/目标/来源有效性和版本，hash绑定内容及计划/来源；publish重检后在同事务内创建正常英语课程、SUPPLEMENT挂载、来源与幂等回执。来源变化、跨计划、已接受表达或归档来源拒绝，登记失败整体回滚。旧/1—3仍拒绝新增字段，不偷偷扩白名单。

计划详情和英语错误页提供补充学习入口，进入既有课程概览和全窗口训练，侧工具只有计划笔记。必要规则常显，细节可展开；迁移项答前不显示组讲解支架。辅助使用必须有记录，辅助通过不算无提示通过。补充完成、当前轮次迁移结果、原题复测分别显示，不自动消除原错题或宣称长期掌握，不递归生成新课。补充错误仍由原英语分域处理。

修订继续保护已有轮次，补充课不能静默降级/删掉必需阶段或目标；清理源课程需明确处理其补充依赖，不能留下悬空来源。现有真实工作区和安装版本轮未操作。

## 6. 接口与Agent协作

### 6.1 学习与制课接口

| 操作 | 拟议或复用接口 | 读写对象与结果 |
|---|---|---|
| 制课/修订 | validate/import/update preview/apply | 原子登记Course/Exercise/EnglishItem，保留修订与稳定身份 |
| 开始/继续 | 既有course.study.open/get的计划上下文扩展 | 冻结CourseStudySession的计划/课程挂载来源，不从独立窗重开 |
| 草稿/整课提交 | course.english.save/submit（普通answers入口拒绝英语写入） | Submission/Detail；统一事务、CAS和幂等回执 |
| 本句检查 | course.english.check | 写EnglishCheckAttempt及英语聚合，不对每次失败创建普通错题 |
| 请求审核 | course.english.request-review | 仅该项进入Submission/Agent队列，锁定原输入 |
| 批改/复测发布 | assignment.summary/context、review.write、retest.publish | 冻结上下文与准确待办，不重投本地已确认条目 |
| 词典辅助 | audio.dictionary.lookup / audio.resolve | 返回实际发音/音标/释义来源与可用性；允许取消，不执行TTS |
| 本地音频登记 | audio.import/inspect（后续兼容） | 校验资产引用，缺少此能力不阻塞首版课程编写 |
| 计划笔记 | 既有plan.notebook能力 | 连续计划笔记，不提交答案、不进入批改队列 |
| 补充预览/发布 | course.remediation.preview/publish | 计划、工作区内path、目标、理由、真实aggregate/version/evidence引用；发布增加preview_hash/idempotency_key |
| 补充查询 | course.remediation.list/get | plan_line_id及可选源course/aggregate过滤，有界limit/offset；返回来源与学习/迁移投影，不复制答案 |

当前已实现方法以capabilities/system.schema发现为准，包括course.english.*、course.remediation.*、mistakes.*与audio.dictionary.lookup；补充学习与仅笔记工具已源码接入，audio.resolve/import/inspect及真实原生拆窗/声音验收仍待后续；英语独立答题窗/侧栏练习已取消。能力发现先于调用，Agent不能伪造LOCAL_EXACT或擅自代学习者检查/提交。

### 6.2 错误数据的精准读取

| 拟议能力 | 作用域与返回 |
|---|---|
| mistakes.notebooks | 返回计划分册和领域身份；计数由范围summary提供，不返回全量题目/答案 |
| mistakes.summary | 必须指定分册或`plan_line_id + domain`，可再指定课程、时间范围和作者目标标签；返回口径清楚的摘要 |
| mistakes.list | 同样限定作用域；普通返回错题条目，英语明确选择`training_errors`或`review_queue`，游标分页 |
| mistakes.context | 传条目/聚合ID与已读版本；回传冻结原题、相关作答、错误位置、评估来源和有限证据，可继续分页 |
| mistakes.english.review.select | 经用户授权将指定聚合加入复习清单；不能修改原尝试或直接标“掌握” |
| mistakes.retest.request | 引用明确条目/聚合和冻结来源，发布真实任务；不随便创建无来源复测 |
| mistakes.archive.preview/apply | 显式计划/课程/条目范围、预览和版本校验；只逻辑归档，不清除事实 |

ID定位后仍核验分册/课程归属；不允许传一个计划的ID却取另一个计划的答案。上下文响应包含course_id、exercise身份、课程修订/rule_hash、来源轮次/任务及聚合版本，后续读取发现变化就明确提示，而不是无声混合不同时间的统计。

**Agent编排课程的读取顺序**：发现能力 → 指定计划与课程范围 → 读取普通摘要或英语复习/训练摘要 → 选有限重点项 → 按需取原题及证据 → 提出课程修订或迁移练习 → 获授权后通过正常课程CLI写入。不全量拉取整个工作区，也不能仅凭失败次数推断未学概念或自动改写课程。

课程包已增`studyflow.course-package/2`：course.learning_mode判别，Exercise内受控english字段及稳定objective_ids；不是顶层english_items数组。v1普通包保留。未知模式/字段/版本整包拒绝。CLI只提供能力、schema、校验和回执；课程设计、错题取数顺序与提示词由Skill维护，不输出另一套长教程。

## 7. 兼容与异常处理

- **旧内容**：旧课默认general，旧包/普通队列/答案/笔记保持；迁移追加且先备份，不删除旧答案或轮次。
- **冻结版本**：当前学习不热替换题面、规则或音频；更新先preview，课程进度只按本轮证据计算。
- **参考可见性**：学习端答前只返回允许的提示/输入结构，答案态或显式查看才显示完整参考；词典辅助不能答前自动泄漏目标词，显式答前查看计辅助。Agent可读取完整冻结上下文。
- **并发与窗口**：沿用CAS、稳定回执和单编辑权；独立窗复用同一Engine/轮次，不产生同题双编辑器。
- **保存失败**：返回、原键重试、导出、不保存退出始终可达；舍弃不承诺回滚已落库/未确认请求。
- **资源保护**：工作区导出/恢复包含普通错题、英语聚合/复习、原证据与可选音频；安装升级不抹掉学习数据。词典远端资产不可用不伪装成导出完整本地音频。
- **权限与隐私**：资产路径限定工作区，网络词典地址受控；凭据、真实答案和个人音频不进入公开源码。
