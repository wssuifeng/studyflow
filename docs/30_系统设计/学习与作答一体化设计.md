# 学习与作答一体化设计

依据：用户于2026-10-01采纳同屏学习、整课提交及改进建议，并确认允许暂时跳题、保护学习中版本；随后明确授权优化核心业务链。
直接上游：[需求规格](../20_需求分析/需求规格说明.md) R1—R5、R7—R9。

## 产品边界

StudyFlow是本地开箱即用的个人学习软件。沿用唯一Vue前端、Tauri自动管理Engine、Python Core和默认SQLite，不要求手动启动数据库/后端。外部Agent经CLI准备课程和批改，学习者不需要Agent在线才能阅读和保存。
不做账号/租户/SaaS、排行榜、积分、内置AI API、复杂版本管理界面或多份前端。控制台简洁展示继续学习和需要处理的反馈。

## 连续学习流程

计划 → 课程 → 当前知识点材料与对应练习 → 保存并切换下一知识点 → 最后一项检查整课必答题 → 统一提交 → 逐题反馈 → 原位修正/复测。

知识点目录可直接切换；允许空题保留草稿，不在导航时阻塞学习。整课首次提交仍校验全部必答题，缺题定位到对应知识点与输入区。已提交题只读；修正/复测仅编辑需要处理的题，不覆盖原答案。

输入防抖自动保存到工作区；正常导航先保存。保存失败保留输入，但不无限强制保存或锁住退出：失败、超时、挂起时提供返回学习、重试、导出与明确不保存离开/退出。明确不保存后停止后续自动写入；已在处理的请求可能已经提交，不能承诺回滚。本设备缓存用于故障兜底，不冒充数据库保存。恢复时不静默覆盖其他窗口的新版本。保存/提交串行化，重试必须复用原载荷和幂等键。

阅读确认、本次学习提交、本轮通过分开。没有练习的课程可明确完成阅读。等待批改不阻塞下一课程，除非另有明确先修约束。本轮通过不宣称长期掌握。

## 轻量版本与批次

新增一个课程学习会话表：冻结知识点正文、题干和约束，保存该轮阅读位置；提交记录与现有整课写入凭据关联会话。正文内容固定，不复制一套课程/题目关系模型。
打开课程时开始或恢复当前会话；文件后来被Agent修改，不改变当前会话材料。来源变化仅提示，不静默升级。只有本轮收口后，才允许显式开始新版学习；旧作答仍引用旧快照。已有历史无快照的作答如实标注，不伪造其当时题面。
复用整课写入凭据作为提交批次，不另建平台式批次系统。按批次和逐题状态汇总待批改、部分反馈、待修正、待复测和本轮通过。Agent队列保留逐题载荷，附带批次/冻结上下文，避免读取已变更文件进行批改。

## 交互与验收

同屏材料与右侧工具标签（练习/个人草稿/大纲），窄窗口可折叠工具；只在当前知识点渲染题目，切换不丢整课草稿。保存反馈在底部轻量显示，不对每次自动保存弹Toast。支持键盘焦点、缺题跳转、减少动画偏好。
必测：空题跳转、导航保存失败、关闭恢复、重复提交、并发版本冲突、批改部分返回、原位修正/复测、源材料修改后保持冻结、旧记录迁移不丢失、待批改不占学习推进点、纯阅读完成。


## 学习侧栏与窗口增量（2026-10-02）

- 正文不显示Markdown原文入口；不夹带工时、教材页码、Agent范围提示。旧资料的开头显式元信息只在呈现层隐藏，代码块和冻结源内容保持原样。个人草稿与答案并行保留，保存中的旧结果不覆盖新输入。

- 知识点导航用正常尺寸按钮、文字/符号和颜色区分未学、学习中、已读、草稿、待批改、待修正、待复测、通过；当前知识点与生命周期状态分别表达。

- 独立学习窗口复用Vue路由、冻结轮次和同一Engine；钉住是可取消的Always on Top，不是Windows桌面壁纸嵌入。每个原生窗口有独立恢复缓存，主窗口保留旧缓存键兼容。

- 正常自动保存只显示轻量状态，不闪错误恢复容器。显式重试成功、且所有未确认/冲突内容都已处理后才显示恢复成功，不对每次自动保存弹提示。离开后的迟到请求失败不污染新页面。

- 可用高度不足时操作栏改为随页面滚动，避免覆盖正文；侧栏/正文独立滚动。来源变化、恢复提示、窗口大小与工具折叠都会重新计算可用高度。

- 退出确认包含风险说明、导出与“不保存并退出”，重试挂起时该按钮依旧可用；普通浏览器不能代替原生窗口关闭与失焦置顶测试。

## 计划笔记与可停靠工具增量（2026-10-02，用户确认）

- 默认学习笔记属于计划，跨课程连续查看；课程/知识点只是块关联和筛选。旧随手草稿原文保留，用户显式复制，不静默迁移或删除。
- 正文选文可以记入计划笔记，摘录保存课程、知识点、冻结轮次、标题与内容hash；正文只做临时视觉标记，不改原材料和冻结快照。
- 练习、笔记、大纲使用同一组Vue工具组件。标签可关闭/重开、重排、拖宽、展开、最多双窗格；不足宽度拒绝分屏，窄屏降级覆盖，收起零占宽。
- 标签拆出是真正Tauri OS窗口，不复制完整CourseReader。每种工具最多一个独立窗；默认跟随主窗所选课程，但可独立浏览该课全部知识点。
- 独立窗不调用study-open，不产生新轮次。练习共享主窗冻结study_id和答案；主窗整课提交前请求所有工具保存并暂停编辑，完成后刷新/释放。拆出时主侧栏只显示放回/聚焦入口，避免两个编辑器双写。
- 主窗退出汇合工具保存；失败/超时提供返回、重试、导出和明确不保存退出。主窗关闭级联关闭工具，失焦和主窗最小化不主动关闭工具。原生层级、拖动、多显示器和安装体验仍需用户复验。
- 无新框架、无第二套前端、无内置AI API。布局/窗口几何只保存视图信息，不保存真实答案。

### 二次审核后的边界补强（2026-10-02）

1. **计划笔记是长期内容，不是一次性草稿**：默认全计划，可从独立窗选择整课任意知识点作关联。删除提供当前编辑器内最多20次撤销；撤销不是跨重启版本历史，离开提示明确此范围。
2. **恢复不能二次覆盖**：重开后重试必须复用原幂等键，成功后用确认载荷更新未编辑的旧工作区视图；更晚本机输入保留待合并。冲突读取返回时才抓取本机编辑，避免等待期间输入丢失。
3. **损坏副本不是空副本**：恢复内容和待重试请求分别校验；导出包含两份原始文本。明确舍弃损坏副本可解锁，不能同时清除仍合法的未确认请求。
4. **离开页面与退出程序不同**：前者停止已卸载页面自身自动保存，不永久暂停仍存活的独立工具；后者才统一暂停/保存或明确丢弃并级联关闭。
5. **原生窗口可见与内容就绪不同**：先注册就绪监听再创建窗口；工具内容读取成功后确认。12秒内未确认显示可恢复提示，不假定保存成功，不自动创建第二轮。打开期间主窗编辑锁定，避免转移编辑权期间输入双写。
6. **轻量反馈不遮挡核心操作**：工具窗口提示位于下方，普通提示自动收起；错误提示保留并可关闭。Windows主窗关闭原生文件拖放接管，使HTML标签拖放可工作；不承诺此设置额外支持外部文件导入。

不在本轮扩展：富文本完整编辑器、跨重启笔记版本历史、离线同步平台、双向任意拆分布局。继续优先验证保存和单一编辑者，不引入第二套前端或分布式锁。

## 2026-10-02 应用级侧栏修订（替代正文内嵌布局）

AppShell持有右侧布局宿主，CourseReader通过共享注入契约发布可见性/尺寸并以Teleport投送工具；答案与计划笔记控制器仍由原课程持有，不新增轮次/编辑副本。默认收起，仅恢复宽度/排序，不沿用旧自动打开状态。用户明确进入修正/作答可展开。

左/中/右同高；宽窗导航压缩让位，中窗导航变为有可访问标签的图标栏，小于900px工具占内容区并保留同一StudyActions动作组件。收起不卸载编辑区；隐藏阅读区时保留滚动位置。显式放回在窗口实际关闭事件后展开，不提前抢编辑权。页面切换释放面板所有权。

音效本地合成、默认关闭；仅显式动作成功后触发完成音，不对自动保存持续鸣叫，不以声音替代文字。动效遵循系统减少动态效果偏好。app1.5.1复用Core1.5.0/协议1.2，无数据库迁移和CLI/Skill契约变化。
