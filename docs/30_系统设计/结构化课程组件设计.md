# 结构化课程组件与阅读优先布局

日期：2026-10-02。用户已批准：课程组件由外部Agent通过CLI输入数据，由唯一Vue前端渲染；测试课程可重新导入，不清空工作区或修改本地资料原稿。

## 目标与边界

- 课程头部两行紧凑导航；简介回归计划详情；正文知识点标题进入滚动区，顶部用短标题提供位置。颜色+SVG表示状态，当前位置独立描边，已读与通过不混淆。
- course-package/1 JSON整课输入；七种受控块：concept、comparison、steps、example、callout、summary、practice。每块稳定id；题目有lesson内稳定id，practice按id引用。
- CLI提供validate-package和import-package；导入前验证全部知识点/引用。一个事务登记完整课程；产生的Markdown只是便携存储与旧客户端兼容，不要求用户编辑它。内容哈希目录不可覆盖，重复包返回原ID，已存在同package_id但内容不同则显式拒绝，未来的通用更新另批完成。
- 不新增数据库迁移：使用既有课程/知识点/题目与文档模型。生成Markdown的Front Matter保存结构化内容，正文保留完整线性回退。冻结轮次同时捕获结构块；旧轮次缺块走原Markdown展示。
- Vue组件映射固定白名单，不编译Agent模板、不接受任意JS/CSS/HTML。富文本小段复用服务端消毒，结构块用Vue文本绑定。
- 练习入口打开现有侧栏并定位题目，不产生第二套作答；结构块摘录继续使用冻结学习轮次验证，补source_block_id来源。
- 不做全量课程更新编辑器、自动迁移所有旧课程、积分排行、第二套前端或在线API。

## 实现与验收

1. 源码与Skill加入协议样例；CLI dry-run没有数据库和文件写入。
2. 包导入验证大小/数量/未知字段/重复id/题目引用/类型；错误整包拒绝。崩溃遗留只会是未登记的不可变内容，不覆盖已有记录。
3. 概念段落、对比表、步骤流、已知-推导-结论案例、提醒、小结、练习组件；减少边框容器。
4. 桌面常规尺寸首屏能读到正文；900px及以下不横向溢出；键盘可用，颜色不独立承载信息，减少动效偏好有效。
5. 旧Markdown、冻结版本、答题保存/退出恢复、摘录笔记、右栏/独立窗不回归。
6. 用户真实安装与阅读舒适度需用户验收，不用测试代替。
