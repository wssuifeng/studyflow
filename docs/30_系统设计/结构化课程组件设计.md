# 结构化课程组件与阅读优先布局

日期：2026-10-02。用户已批准：课程组件由外部Agent通过CLI输入数据，由唯一Vue前端渲染；测试课程可重新导入，不清空工作区或修改本地资料原稿。

## 目标与边界

- 课程头部两行紧凑导航；简介回归计划详情；正文知识点标题进入滚动区，顶部用短标题提供位置。颜色+SVG表示状态，当前位置独立描边，已读与通过不混淆。
- course-package/1 JSON整课输入；七种受控块：concept、comparison、steps、example、callout、summary、practice。每块稳定id；题目有lesson内稳定id，practice按id引用。
- CLI提供validate-package和import-package；导入前验证全部知识点/引用。一个事务登记完整课程；产生的Markdown只是便携存储与旧客户端兼容，不要求用户编辑它。内容哈希目录不可覆盖，重复包返回原ID，已存在同package_id但内容不同则显式拒绝，未来的通用更新另批完成。
- 不新增数据库迁移：使用既有课程/知识点/题目与文档模型。生成Markdown的Front Matter保存结构化内容，正文保留完整线性回退。冻结轮次同时捕获结构块；旧轮次缺块走原Markdown展示。
- Vue组件映射固定白名单，不编译Agent模板、不接受任意JS/CSS/HTML。富文本小段复用服务端消毒，结构块用Vue文本绑定。
- 练习入口打开现有侧栏并定位题目，不产生第二套作答；结构块摘录继续使用冻结学习轮次验证，补source_block_id来源。
- 不做全量课程更新编辑器、自动迁移所有旧课程、积分排行、第二套前端或在线API。

## 实现与验收

1. 源码与Skill加入协议样例；CLI dry-run没有数据库和文件写入。
2. 包导入验证大小/数量/未知字段/重复id/题目引用/类型；错误整包拒绝。崩溃遗留只会是未登记的不可变内容，不覆盖已有记录。
3. 概念段落、对比表、步骤流、已知-推导-结论案例、提醒、小结、练习组件；减少边框容器。
4. 桌面常规尺寸首屏能读到正文；900px及以下不横向溢出；键盘可用，颜色不独立承载信息，减少动效偏好有效。
5. 旧Markdown、冻结版本、答题保存/退出恢复、摘录笔记、右栏/独立窗不回归。
6. 用户真实安装与阅读舒适度需用户验收，不用测试代替。

## 2026-10-10 折叠详解增量（R11，历史建议）

### 目标与方案选择

用户已要求登记“简述常显、详解折叠展开”；以下是待确认的工程建议，不修改上文已实现的七类内容块基线。

优先采用独立、受控的**折叠详解内容块**：稳定块 ID、标题、可见简述和详解正文分开表达，由唯一 Vue 教学渲染器处理。相比直接允许任意 `<details>` HTML，这条路径可校验、可冻结、可追溯；相比给全部 concept 块自动折叠，也不会误藏关键定义。确切类型名称、字段、长度限制及协议版本在实施前确认，不将这里的概念结构当作现有 CLI 已支持的字段。

### 展示约束

1. 标题、简述始终可见，详解默认收起；用于补充解释、推导与详细案例，不替代正文必要知识。首版只做一层展开，不堆多级嵌套折叠容器。
2. 使用共享组件和语义样式，序光/白紫行为一致；不另建主题专属业务。含详解的教学单元保持线性单列，不能因 concept 自动成对分组而把相关简述/详解拆开。
3. 展开控件提供键盘 Enter/Space、可访问名称、展开状态及可见焦点；减少动态效果偏好优先。状态不只通过颜色表达。
4. 大纲或来源跳转若指向折叠内容，先展开对应详解再定位；不能出现“跳转成功但内容不可见”。用户主动收起后保持可见简述附近的阅读位置。
5. 开合状态属于阅读展示偏好，不进入提交/批改/掌握状态；如需要暂存，按冻结内容版本与稳定块 ID 隔离，不能跨修订错误继承。首版不引入数据库状态模型。
6. 摘录详解保留原块来源；选中文本、右侧练习/笔记、独立工具窗口与可靠保存/退出链不受影响。

### 内容契约与兼容

- 新增类型应同时覆盖 Core 校验、完整线性 Markdown 回退、冻结快照、前端类型和组件映射；旧七类内容块的合法输入语义保持不变。
- 旧轮次继续读其冻结内容，新修订对新轮次生效；不借此自动清理或重建真实学习轮次。
- 新包对旧 CLI 的兼容要显式设计：能力发现、协议/类型校验和明确失败提示；降级包须由调用方明确选择，并保留完整详解，不静默降级。
- 不为支持折叠泛化放宽富文本 HTML 白名单。兼容 Markdown 默认保持完整线性输出；只有独立、必要且可测试的兼容需求才考虑最小白名单调整。
- 仓库 Skill 源、包示例、CLI capabilities 和软件内制课提示词在功能实现后一起更新；公共/安装副本另行同步并核验，不在文档登记时宣称已支持。

### 增量验收目标（当日未执行；最新结果见下节）

- 隔离课程包导入、修订、冻结轮次及 CLI 回读可保存全部简述/详解；无效字段或不兼容包在写入前被完整拒绝。
- 两主题在右栏开/关、常规/窄窗、独立工具窗口下可展开与收起，无溢出/白屏；键盘和大纲跳转可用。
- Markdown 回退包含全部文本；课程修订不改当前轮次的内容/作答；折叠不影响笔记来源、自动保存、提交和失败退出。
- 工程回归与用户阅读舒适度分别验收；没有执行测试时不标通过。

另行待复现：连续 concept 块被自动成对排版是否违背线性教学；无作答/低阅读进度轮次是否缺少安全放弃/重新开始入口。前者不能只让制课方合并长正文规避；后者必须区分有无草稿/答案和冻结保护，不能先假定可无损结束或自动切换版本。本次只登记，不随折叠需求顺带实施。

## 当前增量契约与共享模板

- `studyflow.course-package/3` 允许 `details`：`id/type/title/summary/body`，标题/简述/详解分别最多 200/3,000/20,000 字符且非空；不接受嵌套块、JS/CSS 或任意组件。`/1`、`/2` 保持原七块白名单；`/3` 兼容 general/english，不另建课程模型。
- Core 生成消毒后的 `summary_html/body_html`，完整 Markdown 回退包含全部详解；旧内容与冻结轮次不自动改写。折叠只在数据明确声明时生效，不从旧正文猜测隐藏内容。
- `teachingGroups` 始终按作者顺序单列；concept 不再自动成对。comparison 保留内部显式对照。共享文档模板统一开放式正文、标题/段落/列表层次、对比表、案例推导/结论和详解提示，序光/白紫只使用各自语义颜色。
- 唯一 Vue disclosure 默认收起，简述常显；本地展开偏好按工作区指纹、冻结内容 hash、lesson/block ID 隔离。大纲/来源定位先展开；不可见标题不参与当前可见标题判断。作者正文标题规范化到 h5/h6，不改原 Markdown 或冻结内容。
- 来源摘录保留冻结块；指定块或无锚点历史来源都能看到完整详解。来源阅读只读且不新开轮次。教学 DOM ID 带 lesson ID，避免英语多组同名语义块冲突。
