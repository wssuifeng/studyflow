## 1. 根因与方案选择

本轮仅抽查T01/s02、T04/s03、T09/s04三份候选：全部是28颜色token加少量presentation/motion/sound；schema不允许布局、圆角、排版阶梯或图片。当前runtime.css的compact只作用三个选择器，teaching变化集中于example，heading作用两类标题。无论文案如何描述，现有可执行载体不足以表达大部分设计意图。

候选矩阵当前为40项submitted（10方向×4槽位），这是元数据事实，不表示40份视觉通过。抽查三份均无渲染图片、较多not_run；主代理交接中的CSS统计未逐项复算，不当作本轮独立验证。需要允许设计表达，不应继续以更多色板候选解决结构问题。

三条路线：

- 仅扩充颜色/数值tokens：低风险但仍可能固化模板，不能单独满足用户此次目标。
- 任意运行时HTML/JS/CSS插件：表达力高，但把外观导入变为宿主程序执行，增加无关插件/沙箱成本，不采纳。
- **采用：可信展示主题包**。数值tokens + 独立主题CSS + 展示层Vue组合/变体 + 本地静态资产。构建期审查与打包，同一业务Core/状态所有者/路由和接口。外部用户导入仍是数据，不动态执行任意主题程序。

“唯一Vue前端”约束解释为**一份业务实现与正式UI工程**，不是一套不可改变的DOM或栅格。可以有多个呈现组件/布局组合，不能有十套保存/提交/批改/IPC实现。

## 2. 允许变更矩阵

| 部分 | 明确允许 | 保留的硬约束 |
|---|---|---|
| 应用壳与导航 | 顶部导航、宽侧栏、图标窄轨；品牌与标题合并；导航分组、比例和表面分区 | 窗口拖动/最小化/最大化/关闭、返回/计划入口可达；按钮区不误触拖动 |
| 计划/控制台 | 卡片、列表、时间线、组合面板；按计划聚合、主次布局与密度不同 | 同计划课程保持聚合和顺序；不增加重复仪表盘、积分、排行榜或无用容器 |
| 阅读壳 | 书页式、分栏工作台、轻轨专注；题目引导/章节导航可顶部或侧轨 | 多知识点仍属于整课，学习/作答同一工作面；不靠重新挂载换皮 |
| 教学内容 | 七类块的容器、边界、排列、标记、例题条件/推导/结论与摘要样式；可改展示template/slots | 数据字段/练习关联/正文顺序与含义不改，不能CSS伪造题目、反馈或按钮文案 |
| 作答/反馈/笔记 | 输入框外观、题面排列、错误原句区、笔记读写分区、工具tabs与拖拽把手 | 保留共享编辑器、字段值、保存/提交/修正/独立复测语义；计划笔记不拆成孤立草稿 |
| 右工具区 | 宽度、分隔器、tabs、双窗格样式可不同；宽窗合理改变其他区域尺寸 | 默认收起、有小入口；展开仍是右侧等高工具区，挤占而不是盖住正文；窄窗全屏/抽屉退化可用 |
| 表面/形状 | 圆角阶梯、描边、阴影、局部纹理/插画、平面/浮层、容器减少或合并 | 模态/错误/未确认保存不被装饰遮蔽；状态不能只有颜色，无障碍焦点清楚 |
| 排版/几何 | 系统/合法本地字体族、字号/字重阶梯、行高/段距/间距、导航与面板推荐宽度 | 用户显式阅读/拖宽偏好优先；中文正文不被强制终端化；最小窗可操作 |
| 反馈 | 不同触感的hover/press/focus/开合/定位，已确认结果反馈与可选短音色 | 尊重静音和减少动态效果；默认不响，不为逐字输入/自动保存持续响，不把失败演成成功 |
| 主题图片 | imagegen生成纹理、边缘背景、封面、非知识性插画；本地可关闭资产 | 默认正文表面清楚；图片不包含题目/答案/按钮/状态文字，不接线上图片服务，不影响功能 |

不是每个主题都必须改变所有部分。但相对于基线，**至少三个非颜色维度有可观察差异**，至少一项是布局/容器/教学块结构。以实际渲染和交互证明，文案、配色差异表或静态概念图不能替代。

## 3. 锁定层与展示层

```text
外部Agent/CLI课程语义数据
  → 既有Core/Engine接口与冻结学习轮次（锁定）
  → 共享答案/笔记/导航/恢复/窗口协调状态（锁定）
  → 展示适配：稳定slots/props/事件，只分发布局和风格（可扩）
  → 主题CSS + 几何/排版 + 展示Vue + 本地资产（可设计）
```

### 锁定层

- Python Core/CLI/Engine、数据库模型、事务、幂等/版本CAS、学习轮次、答案/笔记和反馈/复测生命周期。
- shared/api接口类型和方法语义；主题不得直接请求、调用SQL/文件系统/IPC或创建新存储副本。
- useCourseAnswers、usePlanNotebook、useSafeStudyExit、dock/state与窗口协调的业务/持久化部分；展示组件不重写这些规则。
- 只有明确审核发现前端适配缺陷时，主代理可做最小共享修复并记录原因/测试；不能借主题任务顺手改业务协议。

### 可变展示层

主代理可调整AppShell、SidebarNav、WindowTitlebar的template/布局；从CourseReader拆出纯展示壳与教学容器，以slots/props和现有事件提供设计挂载点。子代理在私有目录**直接写CSS和纯展示Vue变体**，不必把所有创意退化成shared-proposal。其源代码经主代理集成审查后进入同一软件工程。

展示组件可使用Vue computed、ref及事件做开合/过渡/布局响应，不能用JS查询/改写学习数据、发新业务请求或修改答案/笔记来源。复杂拖拽继续消费既有协调逻辑，不每主题重写一套。

### 学习状态与组件身份

- 编辑器和composable所有者独立于themeId；主题切换不得重key或切换多个带状态编辑器分支。
- 优先CSS grid/layout改变位置；需要移动工具时可复用Vue slots/Teleport等标准能力，但**组件实例保持不等于DOM焦点/选区一定保持**，必须实际测试。
- 记录当前知识点/教学块锚点、焦点、选区和IME状态；几何改变后恢复语义锚点，不只照搬scrollTop。
- 活跃IME组合期间可延迟结构性切换到compositionend，不强制中断输入。正在保存/未确认请求仍保留相同载荷与幂等键；切换不自动重放/提交。
- 拆出的工具窗使用相同展示包与原学习上下文；无资产/同步失败仍提供原工具功能和清楚降级说明。

## 4. 可信CSS与资产边界

**允许候选作者写实际CSS，不限于28个颜色或既有固定preset。** 可覆盖纯展示容器的布局、尺寸、font、radius、spacing、shadow和样式层次；构建后按主题ID限定scope或专用root class，不堆通用全局!important来污染其他主题。

CSS也能隐藏错误/挡住按钮、通过url请求网络、改变视觉阅读顺序，因此“不会直接写数据库”不能推出“没有功能或隐私风险”。审查与测试保护：

1. 不允许外部url/@import、data:执行资源、任意绝对路径/路径逃逸；图片/字体通过Vite构建资源导入或审核后的资产注册表解析。允许本地图片URL，不再一概禁止url()。
2. 不隐藏或截断错误正文、未确认提示/幂等恢复、关闭/不保存退出、题目与要求；布局移动需保持DOM/键盘阅读顺序合理，不用order制造认知跳跃。
3. 装饰层pointer-events:none、aria-hidden；有意义图片给alt，装饰图片空alt。对话框/退出提示的基础层级归平台展示基础，不由主题覆盖到不可达。
4. 不用CSS伪造反馈文字或更换语义图标，不把disabled操作做成看似可点或让有效按钮无法点击；原生点击/拖动区域均需测试。
5. 标题栏Vue外观允许变化，Tauri权限/命令/窗口关闭保护不变；不是全面禁止“碰标题栏”。
6. 主题JSON仍纯数据。应用外观导入不执行候选CSS/JS；源码主题包只作为受审查的内置资源打包。本专项不做第三方任意主题安装平台。

## 6. 图片生成与防疲劳

用户已允许使用本机imagegen和相关Skill。生成前读取对应Skill，按图像容器实际比例指定方向、安全区与尺寸；高级提示词可调用gpt-image-2-style-library。调用本机已有gen.py并把产物写到候选assets，运行工具使用其已有配置，**不把配置/Key抄入项目、提示词或报告**。

- 可做：纸纤维、石墨颗粒、自然/海盐色低细节边缘背景、课程路径封面、安静的局部插画；不可将文字课程和业务控件栅格化成图片。
- 明确纯色fallback、正文实色/足够对比的表面、图片关闭入口；不要在长正文正下方放高对比复杂纹理或持续运动背景。减少疲劳是需用户比较的目标，不是假定某张图一定有治疗/防疲劳效果。
- 布局先行，再生成对应比例的资产；图片不能成为遮掩固定模板的廉价换皮。比例与容器一致、声明安全裁切及object-fit策略；多屏/缩放验证。
- 用本地png/webp等静态资源、压缩、稳定尺寸和懒加载；目标每主题关键资产合计≤8MiB，超出时说明性能成本并审核，不为严格数量牺牲设计。禁止自动视频/无限生成；默认先为试点方向各1—2张图取得反馈。
- assets记录源提示词、用途、实际生成工具/模型（脱敏）、尺寸、hash、许可/来源及处理步骤。失败有纯色兜底，不更换未授权渠道、暴露凭据或循环请求。
- 生成调用会发送提示词到既有图片服务，只提交抽象设计/纯合成素材，不发送私人课程/答案/截图。应用运行仍完全离线，不内置生图API。
