# StudyFlow 术语表

| 术语 | 含义 |
|---|---|
| StudyFlow | 本地优先个人学习软件，不是考试专用课本 |
| 软件治理 | 软件自身定义/需求/设计/实施/验收 |
| 学习计划/PlanLine | 用户数据工作区中的学习线，不是研发阶段 |
| 课程/Course | 计划中的顺序课程，包含多个知识点和练习 |
| 知识点/Lesson | 课程内有序子单元，UI导航页 |
| 整课作答 | 批量原子写入，不改变逐题反馈和历史 |
| 数据工作区 | 用户Markdown与运行数据根，不是源码/安装目录 |
| Python Core | CLI和Engine共享业务规则与事务 |
| Engine | Tauri管理的Python进程，协议1.2 JSONL stdio |
| Agent CLI | 任何外部Agent/脚本/人工可用的统一入口 |
| Skill | CLI操作知识和约束，不是内置AI API |
| 工程验证 | 特定检查，不自动等于用户验收 |
| 计划学习笔记/PlanNotebook | 一个计划一份连续笔记；课程/知识点仅关联，不属于作答 |
| 旧随手草稿/StudyNote | 1.4.0按冻结轮次+知识点保存的兼容数据，不静默删除 |
| 工具窗口 | 从侧栏拆出的原生单工具页，跟随整课且共享既有学习轮次 |

## 1.7.0增量术语

| 术语 | 含义 |
|---|---|
| RetestTask | 与父答案/冻结轮次关联的独立复测题，评分参考不返回学习UI |
| CourseRevision | 同一课程身份的发布修订；不是学习轮次，也不覆盖旧答案 |
| SubmissionChainLink | 父答案唯一有效子链接，历史分叉须显式裁决 |
| assignment.summary | 分页轻量行动投影，不返回答案正文 |
| assignment.context | 领取条目后按需读取答案和去重冻结知识点上下文 |
| 未确认写入 | Engine超时/断线后未知是否已落库；保持原幂等键，回读或重放 |
| 工作区租约 | 运行共享、维护独占的跨进程锁，不因目录改名丢失 |

## 主题专项术语（v1底座已实现，私有试点已有，正式展示地基未落实）

| 术语 | 含义 |
|---|---|
| 展示主题/Theme | 同一正式Vue工程/业务状态使用的配置与可信CSS/展示Vue/本地资产，可有不同容器，不是另一套业务实现 |
| 主题候选 | 某主题方向由指定设计Skill实现的私有研发备选，不自动进入发行 |
| 主题注册表 | 软件允许加载的受审查主题集合；损坏或未知主题回退 |
| 交互profile | 受控视觉/短音效预设，服从静音/减少动态效果（当前没有音量控制）且不改变操作结果 |
