# StudyFlow 术语表

| 术语 | 含义 |
|---|---|
| StudyFlow | 本地优先个人学习软件，不是考试专用课本 |
| 软件治理 | 软件自身定义/需求/设计/实施/验收 |
| 学习计划/PlanLine | 用户数据工作区中的学习线，不是研发阶段 |
| 课程/Course | 计划中的顺序课程，包含多个知识点和练习 |
| 知识点/Lesson | 课程内有序子单元，UI导航页 |
| 整课作答 | 批量原子写入，不改变逐题反馈和历史 |
| 数据工作区 | 用户Markdown与运行数据根，不是源码/安装目录 |
| Python Core | CLI和Engine共享业务规则与事务 |
| Engine | Tauri管理的Python进程，协议1.2 JSONL stdio |
| Agent CLI | 任何外部Agent/脚本/人工可用的统一入口 |
| Skill | CLI操作知识和约束，不是内置AI API |
| 工程验证 | 特定检查，不自动等于用户验收 |
