## IDEA-UI-20261003 · 外部AI前端多样式试做（建议草稿，未实施）

> **已被2026-10-03最新用户决定替代。** 以下是历史“试做后仅合一套固定风格”建议，不再是当前指令。现行目标是一套Vue前端、10个配置驱动可切换主题、多Skill候选，覆盖全应用与教学组件。唯一执行入口：[主题专项主代理提示词](../40_开发实施/前端主题样式专项-主代理提示词.md)；设计见[主题契约](../30_系统设计/前端主题与交互契约.md)。本轮仅编写交接，未启动候选代理。

来源：用户希望先走通当前手动批改闭环，再使用更快捷的外部AI制作候选样式，选择更舒适的一版。本轮只提供建议/交接提示词，不创建新工作树、不改UI、不安装依赖。

### 建议工作法

1. **锁定业务基线**：选定同一份1.7.0源码/构建作为参照，保留未提交改动；不能凭remote/main当前旧版本开做。每个候选使用独立、只含软件源码的副本或明确基线工作树，排除真实数据、私人文档、数据库、.env、依赖/缓存与安装包。
2. **先试一个关键工作面**：阅读区+默认收起/展开的答题笔记工具区+反馈展示，先做3个可运行候选，选方向后才统一控制台、计划、反馈及设置；不要一开始做三套完整业务前端。
3. **同数据、同状态、同窗口条件**：短/长课程、七种内容块、已提交/待修正/待复测、保存中/失败/未确认、长笔记和无数据状态。使用隔离合成工作区或纯展示fixture，不让候选访问当前学习工作区。
4. **最终只合入一份前端**：候选是开发实验，不增加用户侧多套UI、主题商城或运行时样式管理平台。Vue/TypeScript、组件props/events、Core/CLI/Engine/Tauri均保持。
5. **评估体验而非只看截图**：同一材料各试读约15—20分钟，覆盖阅读、输入、翻页、收起/展开、定位反馈、笔记和保存失败退出；确认舒适度后再看整站统一效果。

### 三个候选方向

- A：纸感阅读——暖白低饱和、正文层次清楚、轻边界、阅读舒适优先；不是大段同质Markdown或卡片墙。
- B：精致工作台——清晰灰白/青绿或克制中性色、紧凑工具标签、排版与操作反馈明确，避免仪表盘压正文。
- C：柔和深色——非纯黑、少装饰、正文/题目/反馈区分清楚，比较夜间阅读感受，不强制最终产品包含双主题。

不只换颜色/圆角：真正比较字体层级、内容块组织、行距/宽度、信息密度、工具区占比、状态与焦点反馈。

### 必须保留的交互

- 唯一Vue前端；多个知识点在同课程内导航，不拆成多门课或单独答卷子页面。
- 右工具区默认收起、应用级等高、展开时主区让宽、可调宽，原有标签、分屏、拆窗/放回保持。
- 自动保存、跳题、整课提交、原幂等键重试、恢复、冲突及不保存退出；不可用漂亮成功提示掩盖实际写入失败。
- 批改原句/原因/方向可定位；修正返回同轮同题，复测显示新题，不泄漏Agent私有参考。
- 连续计划笔记、来源摘录、阅读/编辑/导出；原生工具窗共享同轮/同计划，不另开学习轮次。
- 中文/代码/表格/长文/空状态/720px、正常窗口与实际系统缩放；键盘可见焦点、文字状态、对比度和减少动态效果。
- 音效默认关闭，反馈轻量，不做积分、排行榜、炫光或持续打扰阅读的动画。

### 给外部AI的提示词

```text
你正在为StudyFlow现有Vue3/TypeScript桌面前端制作一个视觉候选，任务是改进阅读与交互呈现，不是重写软件业务。

先读取本副本AGENTS.md、工程总控、直接相关UI组件和样式；不要递归读所有源码/归档/私人学习资料。当前远程main可能落后于本地基线，不允许reset、覆盖未提交内容或自行拉取旧版覆盖。

目标：按指定视觉方向，先制作知识点阅读+答题/笔记右工具区+批改反馈的可运行候选。不要只做首页或静态截图。内容使用同一组隔离测试数据，不读取真实工作区。

可改：CSS/design tokens、展示模板布局、SVG图标、纯展示子组件和轻量反馈。必须保留现有props/emits、数据绑定、功能入口、中文状态、焦点和响应式语义。

不可改：Python Core、SQLite/schema、CLI、Engine协议、公共API契约、Tauri/native窗口逻辑、自动保存/幂等/冲突/恢复/安全退出规则；不得删功能解决样式问题，不改技术栈、不另做前端或内置AI API。遇到必须改业务逻辑的问题先单独报告，不擅自修。

右工具区默认收起、应用级等高、展开挤占主区而非悬浮卡片；多知识点仍属于一课程；题目和答案在同学习界面。保留整课提交、新题复测、计划笔记、拆窗/放回。

请交付：设计方向与依据、实际改动文件、可运行预览、正常/长文/窄屏/右栏展开/批改修正复测/保存失败六类截图。实际运行npm run build与现有test:learning，明确未执行项；纯展示fixture不等于业务测试通过。不自动安装额外依赖，不提交/推送、不合并main、不操作真实数据。
```

### 选择标准与后续关口

内部比较可按阅读舒适35%、操作顺畅25%、信息层次20%、视觉一致20%做辅助记录；这是开发选型，不是软件学习积分。出现隐藏按钮、丢输入、误报保存成功、破坏生命周期或需重复理解一套导航的版本直接淘汰。选中后只迁移一套视觉实现，再跑现有合成闭环与原生回归；未经用户明确开始，不自动实施。
