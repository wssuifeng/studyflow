# 英语专项页面设计

版本：v1，待审。程序依据：[英语专项程序设计](英语专项功能设计稿-v1.md)。

## 1. 页面结构

| 工作面 | 页面形态 | 入口/退出 |
|---|---|---|
| 英语课程概览 | 新页面；课程目标、分组/项目录、本轮完成情况、继续入口 | 从计划/控制台进入，返回该计划 |
| 英语训练 | **专用全窗口页面**；默认无固定左侧导航、无文档阅读三栏 | 开始/继续打开冻结轮次；左上返回课程 |
| 输入、纠错、答案 | 同一训练页的状态切换 | 不跳转、不重建控制器 |
| 整课结果 | 训练页内收口工作面 | 查看错题/复测，返回课程或进入下一课 |
| 错题本 | 普通/英语共用独立页面及详情 | 主导航/整课结果进入；定位原题或启动任务 |

“全窗口”是占满StudyFlow应用客户区，不是强迫操作系统全屏。保留原生拖动、最小化、最大化、关闭；不要求隐藏任务栏。

## 2. 专注训练页布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ 返回课程  课程短标题 · 17/24                         发音设置  笔记  窗口控制 │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│                         中文提示 / 当前训练目标                      │
│                                                                    │
│                     [英文输入位] [英文输入位] ...                    │
│                     或：原错误 → 当前修正输入                         │
│                     或：英文答案 / 音标 / 释义                        │
│                                                                    │
│                     必要提示、当前反馈、播放入口                      │
│                                                                    │
│                     再练 / 检查或下一项 / 暂时跳过                    │
│                                                                    │
├────────────────────────────────────────────────────────────────────┤
│ 课程目录    上一项                         快捷键提示          保存状态 │
└────────────────────────────────────────────────────────────────────┘
```

- 全页是一个连续工作面，不围出多个仪表盘和大白卡。课程进度在顶栏一处表达，底部不重复课程摘要。
- 训练主体居中，但不无限拉宽。短词、大句、纠错均用同一自适应阅读宽度；长句换行仍保持单词位顺序。
- 主动作固定一个：输入态“检查”、答案态“下一项”、末项“完成本课”。跳过/再练为次要动作，不能争抢视觉主位。
- 原生窗口按钮仍位于右上，一体标题栏使用应用主题；可拖动区域不能遮住实际按钮和输入。

## 3. 五种核心状态

### 3.1 输入

中文提示位于词句区上方，大小适中；输入位为主视觉。当前位清晰聚焦，未输入位不过度强调。答前默认不直接显示目标句/完整目标音标。

Space/Enter推进；最后一位检查。鼠标和Tab可定位；IME组合期间不提交；键盘规则只作用于当前输入组件，不抢笔记快捷键。

### 3.2 纠错

保留本次原输入，以位置描边/短标识指出不匹配；编辑层焦点落在首个错误位。开始输入后直接显示新值，原错误在紧邻对照中保留，不能静默清空后让用户不知道错在哪里。

底部用一句可理解反馈，不猜测语法原因，不为每个单词加状态管理条。多个错误可按位置依次切换，未错位置保留。

### 3.3 答案

目标词句为视觉焦点，音标/释义在下方分层；播放入口靠近内容。可按偏好自动朗读，随后继续或再练。

正确后可以给克制的确认动画/音效；不显示积分、连击、排行榜。“本地匹配/有提示完成”只作必要结果说明，不挤占词句。

### 3.4 等待/失败

检查期间保留输入，不转空白加载页。保存失败/引擎未确认与答错是不同视觉信息，提供原键重试、导出、返回和不保存退出。

音频失败在播放入口附近提示，下一项仍可用。请求迟到不覆盖新输入或播放上一句。

### 3.5 整课结果

简洁显示本轮完成项、未完成/辅助项、需要复测/Agent审核的数量。列必要行动，不显示花哨仪表。

完成、通过、待复习分开；中途退出不自动显示整课完成。

## 4. 按需工具，不恢复固定三栏

- **课程目录**：底部/顶栏按钮打开抽屉，显示组别、训练项位置及已练/未练；选择后关闭并恢复输入焦点。默认不占左侧宽度。
- **笔记**：共享计划笔记，显式点击才打开；宽窗让训练画布适度让位，窄窗使用可关闭覆盖面。不开启时训练画布占满，不保留空栏。
- **练习总览**：可从课程目录/本轮结果定位未完成题与反馈，不复制第二个词句编辑器。
- **独立练习窗**：显式拆出才转移当前编辑器，主窗显示聚焦/放回入口，不双写、不重开轮次；保持相同词句布局与同轮进度。
- 笔记独立窗复用既有工具行为，不与英语答案混存。

这是一种新的`immersive-learning`壳变体；普通课程继续现有统一阅读布局，不因英语专注模式而改动所有页面。

## 5. 尺寸和主题

- 根容器占应用客户区可用高度，采用标题栏/`minmax(0,1fr)`训练区/底部操作区的Grid或等价Flex，不按内容向下无限增高。
- 1920×1080/2560×1440/3840×2160都保持完整工作面。高分辨率增加舒适留白，不把输入位做成巨型控件。
- 窄窗优先压缩辅助信息，长句换行；极低高度允许训练区内部滚动，不裁掉主动作和退出。
- 序光/白紫共用页面结构、状态和功能。主题可变背景/字体/按钮/视觉反馈，不决定是否有课程目录或笔记。
- 正文对比度、焦点、错误文字、减少动态效果和独立音量设置保持有效；颜色不是唯一反馈。

## 6. 参考映射

用户保存的商业MHTML为**答案态**：紧凑顶部课程信息、中央词句/音标/释义、继续/重练/播放、底部快捷键。它只证明该状态的静态布局，不能当作输入/纠错/笔记功能已实测。

借鉴其空间关系和操作层级，结合Earthworm已体验的单词输入与修正。排除积分、“掌握”承诺、生词本、AI助手、会员/账户和商业菜单；不直接复制商业页面代码/资产进正式工程。

本轮`mockup-to-page`采用audit/设计映射阶段：参考提取与功能筛选→上述页面契约→用户确认。尚未生成新视觉图、调用图转代码或适配正式Vue源码。进入视觉实施时，再按该Skill的视觉基准→原型→工程适配→独立验证执行，不能把当前文字规格冒充已经落地的页面。
