# StudyFlow 英语专项程序设计

版本：v1.1，待审。上游：[需求规格说明](../20_需求分析/需求规格说明.md) R12—R14。

## 1. 功能结构

在同一个Vue桌面应用中增加英语课程概览页和**占满应用窗口的英语训练页**。它们是新增页面/大组件，不是把英语题硬塞进现有文档阅读页，也不是第二套前端程序。

```text
计划 → 课程（general / english）
        ├─ general：知识点 → 教学正文 + 练习
        └─ english：训练组（可选）→ 有序词句训练项

共用：课程身份、学习轮次、答案与反馈、修正/复测、笔记、错题本、工作区。
```

单组英语课程直接进入连续训练，不多增加一次“选择知识点”的跳转。课程概览仍显示顺序、完成项和继续入口。

推荐默认：

1. 固定答案英语训练由Core本地规则即时检查；开放表达/争议由Agent审核。
2. 本句检查保留一次不可变尝试；整课提交统一确认本轮结果。
3. 错题本按一题一条聚合，多处错词在条目内定位；普通和英语课程共用。
4. 语音采用制课时预生成、本地复用，词典在线兜底；学习端不调用TTS供应商。
5. 本地保存位置、完成记录与待复测任务，不依赖登录。
6. **英语新增专用全窗口页面；沿用唯一Vue工程、共享主题/窗口控制与保存链。** 不强制沿用普通课程的固定侧栏/三栏排版。

## 2. 模块架构

```text
Vue
  EnglishCourseOverview / EnglishTrainingPage / MistakeBook
       ↓ shared API / Engine桥
Python Core
  courses  → 内容包、英语项、修订和冻结
  learning → 输入、检查、草稿与整课提交
  reviews  → Agent审核、修正/复测
  mistakes → 普通/英语错误索引与来源定位
  audio    → 本地资产登记、解析、词典回退
       ↓
SQLite与工作区不可变内容/音频目录
```

- Tauri只管理窗口、Engine进程和本地资源访问，不写课程或评分规则。
- 英语分词和确定性检查放在learning的独立checker，reviews只调用它，不再实现一份。
- CLI和Engine调用同一Core；CLI提供数据操作/校验，不输出长篇制课教程。
- 课程教学设计、编写流程和Agent提示词放在[Skill制课规则](../../skills/studyflow-agent/references/course-authoring.md)及[英语制课规则](../../skills/studyflow-agent/references/english-course-authoring.md)。

## 3. 数据关系

```text
PlanLine → Course → Lesson → Exercise
                            └─ EnglishItem（1:1，exercise_id为PK/FK）
CourseStudySession → 冻结题面、英语规则、音频引用
Submission → EnglishSubmissionDetail（1:1，可选）
           → ReviewFeedback / RetestTask / 后续Submission
EnglishCheckAttempt → 某轮某题某次整句检查
MistakeEntry → MistakeOccurrence → 检查尝试或批改反馈
```

| 对象/拟议表 | 数据与职责 |
|---|---|
| Course扩展 | 新增learning_mode与英语策略配置；旧课默认general，保留现有content_type语义 |
| EnglishItem / english_items | 关联Exercise；目标句、完整句变体、tokens、可选音标/讲解与音频引用。提示、顺序、语义ID仍归Exercise |
| EnglishSubmissionDetail / english_submission_details | 关联Submission；原始token输入、辅助/跳过标记、有效评估方式、最后有效尝试引用 |
| EnglishCheckAttempt / english_check_attempts | 不可变整句输入、差异位置、matched_variant、checker版本/rule_hash、答卷版本、请求hash与稳定回执；不存逐键流水 |
| AudioAsset / audio_assets | 已校验本地资源的hash、相对路径、格式、语言/实际声音和合成参数；不存Key |
| MistakeEntry / mistake_entries | 同一语义题目的错误聚合与可重建状态投影；不是第三份答案库 |
| MistakeOccurrence / mistake_occurrences | 一次错误证据，引用检查或反馈二者之一；唯一来源防止重放重复计数 |
| ReviewFeedback扩展 | 本地规则与Agent来源分开，保存可追溯评估元数据 |
| RetestTask扩展 | 任务模式、受控英语载荷与私有参考；旧任务保持普通Agent模式 |

上述均为拟议扩展，尚未迁移。EnglishItem不能脱离Exercise另建答案身份；旧答案与轮次不删除。

## 4. 学习状态与数据流

### 4.1 连续训练

```text
开始/恢复冻结轮次
→ 输入 → 提交本句检查
→ Core确认并保存尝试
   ├─ 不匹配 → 错词定位 → 修正 → 新尝试
   └─ 匹配 → 答案/语音 → 下一项
→ 最后检查未完成项 → 整课提交
→ 本地规则反馈或Agent队列
```

输入、错误修正、答案和整课结果是同一训练页的状态，不为每种状态另建一份页面和控制器。

- 本句检查不产生整课已提交状态，退出后能恢复已确认训练和草稿。
- 保存/检查串行化，CAS和幂等沿用共享规则。结果必须对应当前输入hash/版本；匹配后编辑使旧结果失效。
- 本地检查只负责声明的固定答案规则，不凭词差猜测语法根因；引擎错误也不能显示成答错。
- local_exact课程的必做项需有效匹配或明确Agent裁定才能完成；允许中途跳过，最终定位缺项。
- 查看答案/答前播放目标语音记录辅助证据；不能伪造无提示答案或自动证明掌握。

### 4.2 Agent审核例外

学习者显式请求审核某句时，锁定该项答案并提交通用Submission，标记有效评估方式为agent；其他句子可继续。Agent读冻结题面和原输入，写正常反馈。

需要修正时生成子Submission；本地匹配不消除未解决Agent意见。最后整课确认复用已审核有效答案，仅确认剩余本地草稿并登记统一批次，不重投已审核题。

### 4.3 错题与复测

```text
待修正 → 已修正/待复测 → 本次复测通过
   ↑                         │
   └──── 新失败证据重新打开 ──┘
```

英语整句检查失败即保留错误，普通题经Agent反馈后收录。一次重放不是一次新错误。原始错误从不可变尝试/反馈读取；修正不能抹掉它。

普通复测使用Agent发布的RetestTask；英语可由用户显式发起原冻结句子的无提示复测，Core发布英语RetestTask并校验。新句型迁移题仍由Agent编写。

## 5. 校验与声音服务

### 5.1 固定答案规则

- Core按冻结目标、tokens和策略校验，前端不提供可信matched结果。
- 默认忽略多余空白；大小写是否敏感由课程策略声明。标点支架不冒充标点考核。
- 缩写/连字符使用受控分词；合法变体按整句白名单，不任意拼接位置答案。
- 首版单词位支持等token数的声明变体；不同结构的合理表达可送Agent审核，不伪称语法错误。
- 答前学习视图只返回提示和允许的输入结构；完整参考只在答案态/显式提示返回。Agent上下文可读取完整冻结参考。

### 5.2 音频解析

```text
auto：请求口音本地资产 → 同口音词典 → 不可用提示
local_only：仅本地
dictionary_only：仅词典
```

外部制课工具生成资源，经CLI校验格式/大小/hash/边界后登记；供应商凭据不进入学习端。资产hash包含文本、实际模型/声音、语言与生成参数，跨题复用，不覆盖旧轮次引用。

语音音量和界面音效独立，自动朗读开关与手动播放分开。切题/换窗/换口音取消旧播放；全应用只有一个语音播放所有者。词典只发送课程目标，不发送用户错答/笔记。实际口音无资源时提示，不改标签冒充。

## 6. 页面和控制器

详细界面契约见[英语专项页面设计](英语专项页面设计.md)。

| 页面/大组件 | 主要职责 | 共用能力 |
|---|---|---|
| EnglishCourseOverview | 课程概况、训练组/句子列表、完成项和继续学习 | 计划顺序、日程、课程进度 |
| EnglishTrainingPage | 全窗口词句输入、纠错、答案、播放、继续与本轮结果 | 学习轮次、保存/退出、主题、窗口控制 |
| EnglishPrompt / TokenAnswerEditor / EnglishAnswerView | 根据同一控制器切换输入/错误/答案态 | 统一答案与检查结果，不各自产生轮次 |
| EnglishCourseDrawer | 可关闭课程目录、未完成定位；默认不占固定宽度 | 课程语义ID与本轮进度 |
| MistakeBook / MistakeDetail | 普通/英语筛选、错误对照、修正/复测 | 同一来源与生命周期 |
| 英语工具窗口 | 仅在显式拆出时转移编辑器 | 同一Engine/轮次、单编辑权 |

新增建议路由：`/english/course/:id`、`/english/study/:studyId`、`/mistakes`。英语输入/纠错/答案/结果共用训练页；复测通过该页的任务模式进入，不创建第二套英语答案系统。

英语训练页使用AppShell的immersive-learning布局变体：保留一体标题栏和原生窗口功能，默认不挂普通固定导航/阅读三栏。序光/白紫共用同一功能布局。

## 7. CLI与兼容

- v1普通课程包保留；建议v2增加course.learning_mode判别及english_items，导入器映射Exercise/EnglishItem。
- validate/import/update仍走同一发布锁、事务与课程修订；未知模式/字段/版本完整拒绝。
- 建议增量方法：course.english.check、course.english.request-review、audio.import/inspect、mistakes.list/get/summary、mistakes.retest.request。精确字段由实施时system.schema定义。
- assignment.summary/context只投需要Agent的有效条目；本地已确认结果不挤占Agent队列。Agent不能伪造LOCAL_EXACT来源。
- 旧数据默认general，迁移追加且先备份；当前轮次冻结英语规则与音频引用。导出/恢复包含英语资产和错误历史。
- 退出保护沿用返回/重试/导出/不保存退出；不承诺舍弃能回滚已落库请求。

## 8. 设计边界

本稿仅为程序设计。用户体验依据和待验证项放在需求文档；视觉映射放在页面设计；具体制课规范/提示词放在Skill；工程验证和进度放在中控/决策记录，不混入本稿。

本地固定题检查、英语全窗口布局、数据扩展与新增接口均待用户确认后实施。没有新增登录、常驻后端、在线AI对话、积分排名或第二套前端。
