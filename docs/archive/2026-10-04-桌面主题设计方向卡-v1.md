# 桌面主题设计方向卡 · T01—T10

修订依据：2026-10-03用户反馈与主题专项报告。本文是十个方向的**唯一详细设计来源**；主代理提示词和实施计划只引用，不重复维护十套规格。沿用旧T01—T10编号与原风格含义，不更改现有主题ID、旧矩阵或候选内容。

上游：[主题布局与视觉扩展设计](主题布局与视觉扩展设计.md)；派发入口：[主代理提示词](../40_开发实施/前端主题样式专项-主代理提示词.md)。

## 1. 怎样使用方向卡

主代理每次派发：**共用任务约束 + 对应的一张方向卡 + 实际基线/接口/写域**。子代理只读自己这一方向及直接必要契约，不必通读十方向和全部旧候选。

每张卡给的是体验主轴和可尝试的设计，不是固定DOM。代理可改变导航、容器、布局、教学展示和反馈；可以不采用推荐形态，但要说明替代形态如何更好服务于阅读、作答和回顾。不得把建议变成全部主题的统一三栏模板，也不为凑差异增设无用功能。

### 共同桌面基线

- **产品识别**：窗口内的个人学习工具，操作区、内容区、停靠工具区有连续关系；不是网站落地页、杂志、营销页面或监控大屏。
- **首屏**：直接进入计划/课程或当前知识点；课程简介归路径页。阅读页顶部只留必要导航、当前位置和紧凑状态，不再放大仪表盘/英雄区。
- **窗口壳**：标题栏融入主题；拖动、缩放、最小化/最大化/关闭和可见返回入口保留。按钮命中区不能被拖动区吞掉。
- **容器**：导航可以是窄轨、宽侧栏或紧凑顶部页签；阅读宽度、工具区、教学块可以变化。宽窗右工具区默认收起，展开与前两区等高、共同让宽；窄窗可转抽屉/全屏，不改“共享整课/同轮答案和计划笔记”的语义。
- **正文**：长中文与中英混排可读，标题层级、条件/推导/结论、例题/提醒/小结能快速分辨。七类教学块和旧Markdown回退全部有设计，不能只美化首屏或example。
- **状态**：未学、当前、已学、待批改、待修正、复测、通过等现有状态用颜色+图标/文字呈现，不自行新增状态、假按钮或假进度。
- **反馈**：真实按钮有轻量按下/焦点反馈，展开/定位有短过渡，成功只在业务确认后表达。音效可选、默认静音；不为打字或自动保存连续响，不强制开启主题音效。
- **小窗**：最低720×600与800×600都能读课、找知识点、作答、看反馈、记笔记、提交和退出。先收次要信息，不能靠缩小中文字体或隐藏错误来挤空间。200%缩放与原生DPI另测。
- **反模板门槛**：相对于基线至少三项可观察的非颜色变化，至少一项为布局/容器/教学结构。灰度对照只是证据之一，不是美感评分；改变色板/纹理/阴影、调几像素栏宽不能单独算结构设计。

**共有禁区**：网页式通栏刊头/首字下沉/页码装饰/巨大营销标题、黑金与黑亮玻璃、强blur、霓虹HUD、全文等宽、刺眼纯黑白、正文上的复杂底图、重复卡片墙和无用KPI。禁区不等于一律禁衬线/圆角/深色：可读的小范围排版与实体表面仍由设计代理决定。T13的直角与紧凑不是所有方向的强制模板。

## 2. 十个方向

### T01 · 纸感书卷 → 纸面学习工作台

- **想达到的感受**：安静、有书页层次，但明确像可操作的桌面学习工具，不像长文网站。
- **优先设计的工作关系**：左侧课程/章节书签，中央连续阅读纸面；定义/例题/小结靠章节带、边注或页内分区辨识。右侧练习/笔记仍可停靠，不把文字挤成窄栏。
- **可尝试的结构签名**：章节导航改为书签轨；重要提示放语义边注；例题由平铺卡片改为条件—推导—结论的连贯纸面。也允许更好的替代组织。
- **自主范围**：页边、标题字体、分段方式、温冷纸面、圆角/直角、局部章节标记都可自定；不必硬画纸张四边或十个独立卡片。
- **素材/反馈**：可用极浅纸纤维、边缘铅笔线，不要求生图；翻知识点采用轻滑动/定位反馈，不做翻书动画。缺图和无动画时结构仍成立。
- **防偏航**：不做刊头、首字下沉、杂志页码、超窄衬线长文或首屏封面；“纸感”不是棕色网页。
- **小窗策略**：边注收成相邻的短提示，章节书签可折叠；保持正常中文字号及题目/操作入口。

### T02 · 净白精研 → 净白精密工作台

- **想达到的感受**：干净、准确、容易找到下一步；有工具质感，而非空白巨大的网站。
- **优先设计的工作关系**：紧凑工具条、可辨识分割面、课程索引与主阅读面；内容表格和步骤有稳定对齐，题目/反馈自然接在当前学习任务上。
- **可尝试的结构签名**：计划课程从长卡片改成分组列表；知识点索引成为分段条或列表；例题/批改用清晰的比较面，而不是每段一个圆角盒。
- **自主范围**：索引在上方还是侧面、面板比例、圆角体系、表格密度与正文节奏可自定；白灰不等于全部纯白或无边界。
- **素材/反馈**：默认可无图片，用精确描边、按下位移和焦点变化体现反馈；少量冷纸纹理可选。
- **防偏航**：不做SaaS仪表盘、KPI墙、巨量空白、蓝色营销主按钮或重复状态小卡。
- **小窗策略**：索引折叠/简化，主阅读和当前操作保留；除代码/长表内部外，整页不能横向滚动。

### T03 · 墨夜专注 → 哑光暗色专注桌面

- **想达到的感受**：柔和深色、低干扰的长读工具；暗而有层次，不黑亮、不塑料。
- **优先设计的工作关系**：多层深灰/蓝灰实体表面区分导航、正文、工具；阅读主面突出，其余信息收敛为短条或边缘提示。
- **可尝试的结构签名**：辅助信息退到边缘；正文用连续实体阅读面；提醒/例题/反馈通过边缘标记和局部分区，而非发光卡片。
- **自主范围**：深灰的冷暖、侧轨宽度、工具位置、专注密度、标题体系可自定；不要机械沿用T12。
- **素材/反馈**：可无图或用细哑光颗粒；反馈用短促实体压下/描边，不用发光。代码区和中文区层级均须清楚。
- **防偏航**：不做近纯黑大画布、黑金、玻璃模糊、白色反光条、霓虹或大渐变；文字对比和长读舒适分别验证。
- **小窗策略**：导航与附属信息简化，错误/焦点/退出不保存始终可辨，暗色不能吞掉控件边界。

### T04 · 石墨专业 → 中性专业桌面工作台

- **想达到的感受**：专业、利落、稳定，适合阅读、作答、反馈来回处理；不强求终端气质。
- **优先设计的工作关系**：课程索引、中央阅读区和可停靠工具区像一套工作面；保存/连接状态可进入薄状态行，避免另设大仪表盘。
- **可尝试的结构签名**：合并冗余顶部信息；工具tabs和分隔把手建立清楚停靠关系；教学块按内容职责分区，批改原文与问题点形成配对结构。
- **自主范围**：宽侧栏/窄轨、面板密度、细圆角或直角、状态行是否存在可自定。不得把T13的零圆角和所有编号照搬为唯一答案。
- **素材/反馈**：可无图或局部石墨细纹；拖拽/停靠/焦点有稳定触感，错误不靠闪烁。
- **防偏航**：不做日志墙、中文等宽正文、过小字体或复杂运维控制台；专业不等于塞满读数。
- **小窗策略**：状态行只留当前必要信息，课程索引可折叠，当前知识点标题和操作不滚丢。

### T05 · 海盐清透 → 轻盈实体桌面

- **想达到的感受**：清冷、轻盈、空气感，但对象仍是实在的桌面面板，不是玻璃网页。
- **优先设计的工作关系**：用浅蓝灰/青灰实体面和清楚分层连接导航、阅读、右工具区；阅读区干净，辅助面可轻度下沉。
- **可尝试的结构签名**：横向的紧凑课程条；实体阅读面与下沉工具面；题目/反馈采用局部操作带，降低大卡片数量。
- **自主范围**：圆角大小、顶部/侧面索引、面板比例、横向工具组织与淡色范围可自定；不必所有区域都蓝色。
- **素材/反馈**：局部低细节海盐/冷纸纹理可选；工具展开采用短位移和宽度变化，保持阅读区域稳定。
- **防偏航**：不做透明玻璃、强blur、漂浮半透明卡片、青色霓虹或白底蓝色卡片墙。
- **小窗策略**：浅色低饱和状态仍有清楚图标/文字，正文和输入不能因“轻盈”而降低对比或字号。

### T06 · 林间静读 → 克制自然学习桌面

- **想达到的感受**：自然、安静、适合持续读写；不是森林风景网站或装饰型手账。
- **优先设计的工作关系**：稳定主阅读面、轻量章节标签、边缘笔记入口；提醒、小结、例题通过不同结构自然区分。
- **可尝试的结构签名**：章节书签替换等权卡片；小结形成安静的末段总结面；提醒使用边缘标记，计划笔记保持连续正文。
- **自主范围**：植物/矿物色偏好、章节标记形式、阅读节奏、边注与工具的关系可自定；可完全不用图片。
- **素材/反馈**：叶脉、柔和纸纹等只用于边缘/导航空白；按下与展开安静、短促，避免摇摆/呼吸装饰。
- **防偏航**：不铺满森林照片，不满屏棕绿卡片，不让插画承担知识内容或侵入输入区。
- **小窗策略**：装饰和边注先退场，正文、题面、反馈与退出入口不退场。

### T07 · 赤陶暖调 → 温暖触感学习工作台

- **想达到的感受**：温暖、实体、有轻触反馈，同时利落而非复古沉重。
- **优先设计的工作关系**：暖中性色主面、局部赤陶强调；题目、原答案、批改、修正/复测区以结构区分而不只变红绿。
- **可尝试的结构签名**：紧凑操作带；反馈的原句—问题—解释—修正区；稳定的不对称面板或阶梯层级，避免全等卡片。
- **自主范围**：暖色强度、实体面深浅、圆角/直角、反馈编排、是否采用不对称布局可自定；不必全应用上陶土纹理。
- **素材/反馈**：少量砂石/陶土微纹理可选；按钮按下、确认保存、错误定位有区别，声音仍默认关闭。
- **防偏航**：不整页棕色，不复古海报，不仿古纸或过度粗糙纹理，不让成功与错误色混淆。
- **小窗策略**：批改与修正的内容关系收为清楚顺序，不隐藏用户原答案，不新增独立提交语义。

### T08 · 深海蓝图 → 结构化推导学习工作台

- **想达到的感受**：有步骤、能追踪依据和结论，像分析工具；不是赛博大屏。
- **优先设计的工作关系**：低饱和蓝灰实体面、结构导航、推导与代码/表格分区；反馈和知识点入口快速可定位。
- **可尝试的结构签名**：语义步骤轨道；例题的条件/过程/结论层次；右工具区的知识点/题目索引。只使用已有字段，不伪造新图谱或改变正文顺序。
- **自主范围**：轨道在左还是块内、连线是否需要、实体分区与几何、深浅模式可自定；结构线只辅助理解。
- **素材/反馈**：局部低对比蓝图线可选；步骤定位用清楚的焦点/短滑动，不发光、不脉冲。
- **防偏航**：不做霓虹、科幻HUD、监控面板、发光连线或正文上的装饰网格。
- **小窗策略**：步骤轨道缩成可折叠索引，中文正文宽度和当前操作保留。

### T09 · 工程终端 → 代码与知识混合工作台

- **想达到的感受**：代码和数据精准，中文讲解舒服；“终端”只作为局部表达，不把整个学习软件做成命令行。
- **优先设计的工作关系**：代码/表格/参数独立表面，中文讲解正常排版；例题代码与解释能关联，题面和作答仍在同一学习工作面。
- **可尝试的结构签名**：代码—解释配对布局；长表/代码内部滚动且必要时保留表头；知识点/例题结构索引，强化“条件—运行/推导—结果”。
- **自主范围**：编辑器式细分栏、语法颜色、代码区边栏、正文/数据比例可自定；没有代码的课程也必须好看可用。
- **素材/反馈**：默认不需要背景图；等宽仅用于代码/编号/数值，中文笔记、作答输入和正文使用正常中文字体。
- **防偏航**：不做代码雨、黑客霓虹、伪终端命令提示、全文等宽或代码块占领整页。
- **小窗策略**：只有代码/长表可内部横向滚动，主工作面不能横滚才能看到题目或提交。

### T10 · 单色高对比 → 中性可访问桌面

- **想达到的感受**：结构清楚、状态准确、键盘友好；不依赖色相区分，仍要有美感和阅读层次。
- **优先设计的工作关系**：稳定导航、清楚工作面、强语义状态、可见焦点；用明度、描边、图标和标签分组而不是全页黑框。
- **可尝试的结构签名**：状态文字/图标配对；教学块边界按职责区别；导航选中/键盘焦点/禁用态分离，控制噪声。
- **自主范围**：暖灰/冷灰、留白密度、边界形态、图标语言、圆角、层次可自定；不强制纯黑纯白或一律加粗。
- **素材/反馈**：默认无图；按下/焦点与定位反馈不依赖颜色或音效，减少动态模式下仍可理解状态。
- **防偏航**：不刺眼纯黑白，不极小文字，不用一个粗黑框包所有块，不把高对比误当无层次。
- **小窗策略**：焦点、标签与按钮不被压缩截断；错误、退出确认和不保存离开均可键盘到达。

## 3. 派发时的自由度和判定

- 推荐结构是**起点**：如果另一种组织更好，允许替换；在同一方向下不同Skill应产生不同设计方法，而非不同颜色。
- 至少三项非颜色差异、至少一项结构差异是“不是色板”的最低筛查，不用于强迫加模块、改业务步骤或夸大一个字号变化。
- 设计须覆盖控制台、计划/路径、课程首屏与中段、七教学块、旧Markdown、作答、反馈、计划笔记、右工具区与独立窗、设置和空/错态；各面保持同一语言，不只截三个主页面。
- 用户先看30%里程碑：窗口壳、课程中段、右栏展开/收起、小窗。这里的30%是**骨架可操作检查点**，不是代码行数/工时/已完成数量；用户未确认不扩大派发。
- T11/T12的否决是反例；T13只暂留，不作为所有方向的复制基座。长读舒适与审美由用户确认，构建/对比度通过不能替代。
