# StudyFlow 系统定义 · v1.11 公开软件投影

2026-09-30整理已确认的软件边界，不包含个人目标、日程、答案和旧学习主控，不更改冻结定义语义。桌面及Agent路线依据2026-09-29用户确认；公开发布和目录整理另有明确授权。

## 1. 系统定位和目标用户

面向单个学习者的本地学习管理工具。用户通过唯一Vue界面阅读、练习和查看反馈，不必日常编辑散乱Markdown。外部Agent、人工、脚本通过统一CLI协作，无模型供应商绑定。

## 2. 核心功能

| 编号 | 业务 | 判据 |
|---|---|---|
| C1 | 计划与顺序课程 | 多计划、多课程；课程包含多个知识点，兼容当天安排 |
| C2 | 阅读与整课作答 | 导航和阅读进度；整课原子保存/提交，无半成功 |
| C3 | 批改、修正、复测 | 逐题保留不可覆盖历史和下一动作 |
| C4 | 外部Agent CLI和Skill | 能力发现、队列、课程导入、反馈和上下文共用规则 |
| C5 | 本地数据与迁移 | 自动SQLite、可读Markdown、一致性备份和校验 |
| C6 | 桌面与反馈 | 单一Vue UI，Tauri自动管理Engine，用户不手动开服务 |

## 3. 非目标

不做多用户/SaaS、在线AI API、内置模型对话、无授权自动答题、自动证明掌握或第二套正式前端。MySQL只作可选开发/服务端适配，本版不承诺多租户生产治理。

## 4. 冻结声明

2026-09-29确认Vue唯一前端、Tauri薄壳、Python Core/CLI、默认自动SQLite和公共Agent Skill。2026-09-30授权公开源码和整理目录。这是既有确认的去个人化摘要，不是新增需求。

冻结后修改目标、核心功能或非目标，先写决策并取得用户确认。内部工程通过不代表学习者满意或掌握。
