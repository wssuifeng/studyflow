## 2. 设计方向：桌面工具，而非网页

本产品是本地个人学习工作台。先组织窗口内阅读—作答—反馈—笔记的连续工作关系，再决定颜色/材质。

- 标题栏融入主题，保留拖动、缩放、最小化/最大化/关闭；阅读页顶部紧凑，不再放大仪表盘、重复摘要或网页英雄区。
- 计划聚合课程；整课含有序多知识点。学习与作答同一工作面，可跳题、导航临存、末尾整课提交；不分裂成每知识点独立课程/独立提交。
- 右工具区默认收起，小入口打开后成为等高右栏并让其他区域缩宽；窄窗可抽屉/全屏退化。独立窗跟随整课/同轮，共享答案与计划连续笔记，可拆出/放回/置顶/关闭。
- 样式覆盖七教学块、旧Markdown、题目、反馈、笔记和异常态；不只改应用壳或首页配色。
- 720×600与800×600都能操作；长中文/中英混排可读。状态有文字或图标，不只靠颜色。
- 禁止网页刊头/首字下沉/出版物装饰、黑金黑亮玻璃、强blur、霓虹HUD、全文等宽、刺眼纯黑白、复杂背景盖正文、重复卡片墙和无用KPI。不要把“不像网页”简化成所有主题直角、等宽或高密度。

## 3. 自主范围与冻结边界

**允许改**：AppShell/SidebarNav/WindowTitlebar的纯展示结构、课程阅读壳/知识点导航/教学template、容器合并拆分、比例/停靠几何、CSS/排版/形状/阴影、纯展示Vue、本地图片/纹理、轻量声画反馈。不要求十方向相同DOM、三个固定preset或全部使用图片；不同方向可以有真正不同的容器语言。

**冻结**：Core/CLI/Engine/数据库、shared/api名称与参数语义、事务/幂等/CAS/冻结轮次、答案和计划笔记结构、useCourseAnswers/usePlanNotebook等业务状态所有者、保存/提交/批改/修正/独立复测/超时未确认/退出保护、窗口协调逻辑与真实数据。

展示组件消费props/slots/既有UI事件，不新增业务API/IPC/SQL/文件调用、不复制业务表单逻辑。共享编辑器不因themeId重key/重建；保留输入、IME、选区、滚动锚点及未确认请求的原载荷/幂等键。必要展示解耦先列最小改动和不变量，不借主题重构改业务。

可信CSS/纯展示Vue/资产通过**构建期registry**审查打包；用户导入JSON仍是纯数据，不执行任意程序。CSS可使用本地url/grid/flex，但不得网络url/@import/路径逃逸/伪造正文或按钮文字；不得靠font-size:0与伪元素替换真实文本、堆全局!important或高具体度压平语义状态。装饰不截获点击，错误/冲突/返回/不保存退出始终可见可点。

允许使用实际宿主的imagegen及相关Skill。执行前读Skill，先定容器/比例/裁切安全区，再用已有工具生成抽象纹理/边缘背景/局部插画。首轮每试点可从1—2张起步，也可无图；不拿铺大图代替结构设计。

## 8. 验收、状态和收口

工程硬门槛：输入/IME/焦点丢失、按钮不可点、错误被藏、主题串扰、退出被失败保存锁死、假成功、业务生命周期变化，均退回。CSS检查须核对真实组件/选择器与状态，不能把min-height当height或用文本正则扫图片当网络请求证明。

实际覆盖：控制台/计划/路径、课程首屏/中段、七教学块/旧Markdown、作答/反馈/笔记、右工具区/独立窗、设置/空错态；真实Core保存→整课提交→批改→修正→独立新题复测→通过，以及失败不保存退出、未确认写入、跨窗、缺图、静音/减少动态。原生拖动/窗口按钮/拆窗/置顶/关闭、DPI/多屏另列，浏览器不代替原生。

submitted只是交付；工程结果、自动渲染、用户视觉反馈、原生与长读结论分别记录。旧颜色-only 40项、T11/T12和T13均保留为历史/反例，不能改旧selection或设默认主题。最多两轮有根因的返工；审美仍不合适时停线询问方向，不无限重图/重色。

结束更新对应任务/决策/验证与总控，运行文档audit、公开边界和diff检查。阶段不推进；未经新的明确授权不安装、发行、Git提交推送或同步公共Skill。最终目标是十个有实际设计差异的可切换主题，不是十个不同颜色的固定模板。

## 9. 白紫正式源码试点回填 · 2026-10-04

本会话已将用户选定的白底紫韵宽屏“课程阅读＋右侧作答区”设计实施到正式 Vue 源码，作为后续主题专项的工程样板；不代表其余九个方向已开始或用户已完成视觉验收。

已验证的可复用经验：

- **正式 fallback 与候选 overlay 必须双测。** `DisplaySlot` 的原生 `div` 不消费 named slots，候选预览正常不代表正式产品正常；正式空 overlay 课程页必须实际渲染导航、阅读、工具与状态区域。
- **主题 CSS 不能覆盖交互状态几何。** 通用主题规则只在 `:not(.panel-open)` 时设置默认两栏；面板打开的三栏/紧凑状态由 shell 状态优先。任何主题候选都必须验证打开工具前后真实 DOM rect、命中点和按钮可达性，不能只做文本/对比度检查。
- **旧主题输入允许规范化。** v1 JSON 没有 `display` 时由 `presentation` 推导 canonical display；导出烟测应检查信息保留与规范化结果，不要求输出与输入字面完全一致。
- **资产渠道按事实记录。** 本轮 A6 `gpt-image-2` 的 1536×1024 本地插画生成成功并接入；furry 的 429 失败单独保留。提示词不能混淆渠道、不能上传课程/答案/凭据，也不能把图片当作结构设计替代品。
- **窄窗策略必须被看见并记录。** 800×600/720×600 进入产品既有工具工作面切换：阅读面收起，答题/笔记工具仍可用；这不是遮挡修复，也不能被浏览器截图冒充原生 DPI 验收。

本轮正式变更后的白紫源码基线应重新记录；后续主代理在派发候选前先取实际 `git diff`/hash，再创建新的内容寻址构建目录。主代理可以把本节复制进子代理提示词，但不得把“白紫已实现”误写成十方向或原生验收完成。
