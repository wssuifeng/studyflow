# StudyFlow 构建与开发

直接上游：[架构](../30_系统设计/系统架构设计.md)。推荐Windows开发与桌面打包。Python3.12+、Node22、Rust stable，以及MSVC C++构建工具、Windows SDK、WebView2；前置条件以Tauri官方为准。

```powershell
# 仓库根
py -3 -m venv studyflow_app/.venv
$python = Join-Path $PWD 'studyflow_app/.venv/Scripts/python.exe'
& $python -m pip install -e './studyflow_app[dev]' 'pyinstaller>=6.10,<7'
npm --prefix desktop ci
& $python -m pytest studyflow_app/tests
npm --prefix desktop run build
& $python scripts/check_publish_boundary.py --tracked
& ./desktop/scripts/build-engine.ps1
npm --prefix desktop run tauri -- dev
# 正式打包，先完成Engine构建
npm --prefix desktop run tauri -- build
```

新导出尚未暂存时边界检查用`--all`，正常提交用`--tracked`，还需人工diff检查。

Engine在venv中打包成Tauri资源，exe不进Git。Tauri自动启停Engine，开发模式自动启动Vite。可运行smoke-engine.py检查冻结Engine，其数据仅在忽略的test-results。

外部Agent从venv使用CLI，不修改系统PATH。Skill源在skills/studyflow-agent，复制到Agent公共目录时保留完整结构；修改后同步仓库源和安装副本。

旧兼容Web仅在需要时从studyflow_app运行`python -m studyflow serve`；不是第二套正式UI。自选工作区不一定带旧Web模板。

依赖见pyproject.toml、package-lock.json、Cargo.lock。Tauri官方前置条件：

```text
https://v2.tauri.app/start/prerequisites/
```
