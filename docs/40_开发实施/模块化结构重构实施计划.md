# StudyFlow 模块化结构重构实施计划

> 执行方式：本窗口按任务逐项实施和复核，不委派子Agent，不创建新线程，不自动提交。设计已于2026-10-01由用户确认；文档位置沿用项目治理体系。

**Goal:** 以模块化单体结构支撑长期维护，保持原有业务与安装行为。
**Architecture:** 业务模块拥有自己的模型与服务，应用组合层统一事务与聚合读取；CLI、Engine与兼容Web共享同一Core。Vue保持唯一前端，Tauri保持薄壳。
**Tech Stack:** 沿用现有Python/SQLAlchemy/Typer、Vue/TypeScript、Tauri/Rust及锁文件。

直接上游：[模块化结构重构设计](../30_系统设计/模块化结构重构设计.md)。
