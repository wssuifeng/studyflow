**契约样本先行。** 前后端先对齐一套混合课、独立双组课、作文修订及音频失败的合成样本，然后分别实现。下列方法名待通过 `system.schema` 对外公布。

| 契约 | 输入与输出重点 | 错误与重放 |
|---|---|---|
| `practice.get / save / confirm / result` | 读入轮次与题组标识。答前输出题面、选项、空位、文章或音频句柄。写入带 `expected_version` 和 `idempotency_key`。确认回执返回组结果标识、缺项或整课状态。正式结果提供逐题与证据 | 版本冲突保留本地输入，重读状态。超时重放同键同载荷。末组遇到其他漏组时返回可定位的组 ID。历史轮次只读 |
| `speech.profile.* / speech.job.* / speech.asset.adopt` | 配置回读返回 `has_credential`。启动任务返回 `job_id`，状态含段号与进度。采用返回课程资源 ID、SHA-256、时长与格式 | 保存配置仅本地校验。任务绑定配置版本与文本摘要。未知计费结果需显式确认重发，已完成段和采用回执可复用 |
| 作文和课程入口 | 沿用 `course.study.*`、普通作答、`assignment.context` 和 `review.write`。补充练习展示类型、写作评价维度与个人稿次标识。入口 DTO 给出 `group_id`、已答数、当前题、结果入口 | 反馈归属到冻结的 `submission_id`。包括预览在内的学习端读路径，分别验证答前内容与结果内容 |

**前后端交接样例。** 学习端收到可见题面与 `answer_version=3`。保存 `q1 → option_b` 时携带轮次、题组、预期版本 3 和一次写入键，服务端返回版本 4。连接中断后重发同一请求得到同一版本 4，旧版本带新键进入冲突恢复。确认成功后凭结果 ID 打开解析。课程更新后旧轮次从历史入口读取冻结资源，迟到写入受既有封存规则保护。

## 五、切片顺序与前后端交接

1. **先交契约与基线。** B1 验证备份版本，B2 给出 `/7` 三套合法和三套非法样本、答前／结果 JSON、草稿版本与幂等回执。F1、F6 独立施工，F2 用同一份样本建视图。
2. **打通一篇阅读。** B2/B3/B7 的阅读切片接 F1/F2，跑通「混合课保存 → 进入 → 确认阅读组 → 回原处 → 提交普通题 → Agent 队列」。再验证独立课、旧窗口迟到保存与历史证据。它是听读共用代码的首个交付物。
3. **拉通听力生产与学习。** B5/F5 可提前用测试供应商验证配置和任务链。B6 准备已校验的合成音频样本供 F3 先联调播放器。以真实授权 Step Plan 完成「试听 → 分段合成 → 采用 → 导出恢复 → Windows 断网听答」。
