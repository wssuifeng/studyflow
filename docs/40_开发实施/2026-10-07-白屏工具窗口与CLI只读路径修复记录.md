# 2026-10-07 · 白屏、工具窗口与 CLI 只读路径修复记录

## 1. 本轮问题边界

覆盖安装后的旧构建曾出现以下问题：

- 白紫主题打开“答题/练习”或“笔记”后，主阅读区白屏；
- 独立工具窗口内容只占左侧，右侧大面积空白；
- 白紫与序光使用不同的工具侧栏业务模板，导致结构和生命周期不一致；
- `workspace purge-courses --dry-run` 在无法创建工作区租约时直接返回 `WORKSPACE_READ_ONLY`，只读预览被不必要地绑定到写租约。

本轮没有读取、删除或修改真实学习资料、真实答案和真实工作区数据库。

## 2. 根因与修复

### 2.1 白紫主窗口白屏

主题运行时 `themeShellContract=v2` 的通用网格规则覆盖了工具打开后的三栏网格：AppShell 仍按两列布局计算，`workspace-tool-panel` 被挤到错误位置，阅读区与工具区产生错位，最终表现为白屏或工具区落到异常位置。

修复内容：

- 白紫、序光统一使用 `CourseToolsSidebar` 与 `CourseToolContent` 的同一套工具 DOM 和生命周期；
- 练习、笔记使用显式工具分支，未知工具状态进入安全空状态，不再错误落入笔记分支；
- 修正主题壳契约对 `panel-open` 三栏布局的覆盖；
- 保证 `workspace-tool-panel`、工具根节点和内部滚动容器具备 `min-width:0`、`min-height:0`、`height:100%`。

白紫隔离原生探针实测：工具打开后网格为 `184px 836px 420px`，主阅读区和右侧工具区均可见。

### 2.2 独立工具窗口空白

独立工具窗口根节点是 `app-shell desktop-shell focus-shell`，不是课程页面的 `learning-shell`。此前只给 `learning-shell.focus-shell` 添加单列规则，独立窗口仍沿用主窗口的两列计算，造成内容仅位于左窄栏、右侧留白。

修复内容：

- 对 `.app-shell.focus-shell` 增加窗口级单列兜底；
- 有工具面板时使用 `minmax(0,1fr) var(--panel-width)`，无面板时使用单列 `minmax(0,1fr)`；
- `ToolWindow` 的 `native-tool-session` 及内容根节点占满窗口宽度和剩余高度；
- 加载失败显示可操作错误态，不渲染空白页面。

白紫隔离原生探针实测：独立窗口根网格为单列 `540px`，工具内容宽度为 `540px`，不再出现右侧大面积空白。

### 2.3 CLI 只读预览

只读 dry-run 之前复用了写入运行时，启动阶段会创建工作区租约、确保目录并触发数据库迁移；当当前执行身份不能创建租约时，即使只是读取预览也会失败。

修复内容：

- 增加 `read_only=True` 运行时路径；
- 只读路径不创建租约、不创建目录、不执行迁移、不提交事务；
- `workspace purge-courses --dry-run` 使用只读服务；
- 确认删除等写入命令仍必须使用原有租约和备份保护。

真实工作区仍未执行删除；租约和权限协议没有被绕过。
