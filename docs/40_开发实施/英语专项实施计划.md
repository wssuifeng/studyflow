# 英语专项实施计划

直接上游：[统一设计稿v1.4](../30_系统设计/英语专项功能设计稿-v1.md)、[需求规格R12—R14](../20_需求分析/需求规格说明.md)。2026-10-11用户授权开始实施；不包含真实课程写入、公共Skill覆盖、提交推送或安装升级。

## 目标与边界

在现有Vue/Tauri/Python模块化单体完成英语课程发布→冻结轮次→逐句检查/即时纠错→整课确认→英语聚合/复习/普通错题→Agent精准查询的闭环。发音/音标/释义优先词典；不接TTS凭据、不请求在线AI评分、不引入第二套UI/后端。

- 只在隔离合成工作区测试；既有普通课程、真实答案和旧轮次不改写。
- 一级业务模块内创建二级职责包；新规则不堆Facade/Engine/CLI。共用Runtime/Base/Session，事务、CAS与幂等不退化。
- 固定英语答案本地校验；开放表达和用户争议进入既有Agent队列。提示完成不是掌握。
- 错误按冻结计划、课程与规则版本组织；统计与复习清单分开，不自动删历史。
- 写入失败始终可保留输入、重试、导出或不保存退出。
