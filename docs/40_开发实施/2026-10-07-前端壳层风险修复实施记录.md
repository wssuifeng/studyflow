# 2026-10-07 · 前端壳层风险修复实施记录

## 1. 目的与范围

本记录收口 `2026-10-07-前端壳层与页面一致性深度审计` 的可执行修复项。范围只包含 StudyFlow 前端壳层、队列分页契约、主题 CSS 和回归测试；不修改真实学习工作区、真实答案、数据库、公共 Skill、Engine 协议或安装目录。

## 2. 已完成修复

### 2.1 生命周期、路由与反馈

- `App.vue` 的关闭流程只有在 `prepareTools('shutdown')` 成功后才保留 `shutdownRequest`，避免失败分支和 `finally` 对同一请求重复释放。
- 普通页面路由切换通过 `resetMainScrollForRoute()` 重置主内容滚动；课程阅读页与工具页不触碰课程正文滚动容器。
- 离开课程/工具路由时清除 `newFeedback`，避免新反馈跨页面残留。

### 2.2 队列分页

- 在 `shared/api/contracts/reviews.ts` 定义并导出 `QUEUE_PAGE_SIZE = 50`。
- `App.vue` 与 `QueueView.vue` 共用该常量，首屏和后续分页边界一致；`contracts/index.ts` 保留运行时导出。

### 2.3 壳层和主题

- 普通页面、课程阅读页和独立工具窗口继续分别使用 `workspace-shell`、`learning-shell`、`focus-shell`；固定导航、视口高度和主内容滚动由共享壳层规则拥有。
- 序光与白紫主题不再各自复制顶层 fixed/grid/height 几何；白紫只保留主题视觉、课程阅读和工具内容的视觉覆盖。
- 主题测试改为验证共享壳层契约，而不是要求主题文件重复声明固定导航。

### 2.4 CSS 与语义状态

- 删除不可达的 `.main-content:has(.native-tool-window)` 规则、重复 Token 与重复桌面侧栏几何。
- 保存错误、连接状态、标题栏失焦和窗口控件状态改用语义状态颜色。
- 白紫插图规则完成主题作用域化；保留窄窗和 `prefers-reduced-motion` 规则。
