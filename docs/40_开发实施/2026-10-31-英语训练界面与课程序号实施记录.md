## 2. 已实施

### 2.1 英语专项训练页

- 解析区使用当前主题背景色的独立工具栏：宽屏位于训练区右侧，窄屏位于主区下方；内容过长时只在解析自己的滚动容器内滚动，不覆盖题目、输入框和动作区。
- 训练设置改为同样不参与主布局流的受限浮层，避免打开设置时输入位置跳动。
- 训练主区补充相对定位上下文，解析浮层明确锚定在主区内部；长解析只在浮层内滚动，不相对整页漂移。
- 单词提示取消额外顶部占位，使用主题背景和边界，不以大色块覆盖输入。
- 顶部左侧返回、右侧训练设置和计划笔记改为图标按钮，保留 `title`、`aria-label`、键盘焦点和原有行为。
- 顶部不再展示课程标题或长课程简介，改为“第 N 课”与“当前题号/本课题数”；进阶训练最多显示一个短阶段标签，`Course.summary` 继续用于课程列表/概览。
- 答案经 Core 确认匹配后在动作区旁显示固定槽位内的单行“✓ 答对”反馈，并复用现有 `interactionFeedback('complete')`、全局音效开关、音量和主题静音规则；揭示答案、待审核和普通失败不触发答对反馈，反馈出现不改变检查按钮位置。

### 2.2 课程序号与数据模型

- 继续使用现有 `Course.id` 作为全局课程 UID，不新增课程 UID。
- 继续使用现有 `PlanCourseItem.sequence_number` 作为计划内课程编号。
- 为 `(plan_line_id, track, sequence_number)` 增加唯一保护；MAIN 与 SUPPLEMENT 在同一计划内分别编号，避免补充课程占用主线编号。
- 新增迁移 `0018_plan_course_sequence`：旧库迁移时按计划/轨道/旧序号/ID稳定修复重复或非法序号，再建立唯一索引。
- CLI/Agent 导入仍通过既有课程导入和计划写入入口；重排时先写临时负序号再写最终序号，避免 `1,2` 交换为 `2,1` 时触发唯一约束的中间冲突；已存在的非取消日程位置同步到新序号。
- 英语训练 `course.english.get` 回传 `sequence`、`total`、`track`，前端只读展示，不改变冻结轮次或答题事实。

## 5. 2026-10-31 视觉反馈纠偏补丁

用户抽查发现上一版仍有三个直接影响训练可读性的缺陷：答对反馈占据独立卡片、课程摘要把长说明带入训练头部、长句解析覆盖输入框。本补丁只改英语训练页源码和结构回归，不改 Core 协议、学习事实或数据模型。

- 训练头部移除 `Course.summary` 的可见渲染，仅保留“第 N 课”和“当前题号 / 本课题数”；进阶训练只显示一个短阶段标签。
- 独立“答对了 / 答案已确认”卡片改为动作区旁的单行 `✓ 答对` 微反馈，保留 `interactionFeedback('complete')`，不增加题面高度和布局跳动。
- `SentenceBreakdown` 从主训练区移到独立解析栏。宽屏使用右侧栏，窄屏使用主区下方的受限分区；内容仅在 `english-analysis-scroll` 内滚动，删除解析的绝对定位覆盖路径。
- 解析与计划笔记互斥打开，保留原有快捷键、朗读、关闭、聚焦和 Core 状态逻辑。

本补丁验证：`test:english=52/52`、`test:learning=135/135`、`test:themes=89/89`、前端 `npm --prefix apps/desktop run build` 通过，`git diff --check` 通过。1.8.12 MSI 是补丁前构建产物，未重建、未安装、未覆盖安装；原生人工体验和 `business_acceptance` 仍未验收。
