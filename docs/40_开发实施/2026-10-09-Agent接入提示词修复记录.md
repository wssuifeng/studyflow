# 2026-10-09 · Agent接入提示词修复记录

## 问题定位

用户复制“工作区与阅读设置 → 复制Agent接入说明”后，得到的接入文本只写“请使用StudyFlow公共Skill”，没有给出任何 Skill 路径；外部 Agent 拿到提示词后无法定位公共 Skill。同句“安装CLI可以通过 call --method … 使用发现的能力”语序混乱；`doctor` 未加载时工作区还会拼出 `undefined`。

问题在 `apps/desktop/src/features/workspace/components/WorkspaceSettings.vue` 的 `copyAgent()` 模板字符串，属此前开发会话写入后未修正的遗留问题（用户2026-10-09指出并授权修复）。

补充事实：

- 三份 Skill 副本——安装目录 `<install-root>/binaries/studyflow-agent/`、公共 `<user-home>/.agents/skills/studyflow-agent/`、[仓库源](../../skills/studyflow-agent/)——2026-10-09 复验 12 个文件 SHA-256 完全一致，均为 2.0.0。问题只在提示词模板，不在 Skill 本身。
- 用户消息中出现的 `%USERPROFILE%//.agents`（双斜杠）为手工补链接时引入，源码与模板中均无此字符串。

## 修复内容

`copyAgent()` 复制的接入文本现包含 Skill 实际路径：

- 安装态（`system.installation` 返回 `cli_path` 且 `source_cli=false`）：从 CLI 同目录推导 `<安装目录>\binaries\studyflow-agent\SKILL.md`；
- 开发态（无独立 CLI 路径）：回落到公共约定位置 `<user-home>/.agents/skills/studyflow-agent/SKILL.md`；
- 语序修正为“已安装的CLI还支持 call --method <method> --file <JSON> --format json，可调用capabilities中发现的方法”；
- 工作区根目录为空时不再拼出 `undefined`。
