# 1.8.25 独立作文组件与听读完整填空

## 实现

- `features/writing/EssayExercise.vue` 复用作文编辑器和反馈展示，管理题干、作答、交卷状态和稿件反馈。英语课程壳传入本轮状态和保存、交卷动作，混合课照课程题序切换。作文提交进入 `WAITING_REVIEW`，课程的客观题检查统计按词句、听力和阅读计算。
- `/8` 阅读题组可在单选之外使用 `parts` 和 `blanks`，填空保留 `evidence`。听力可用多词答案。Core 对每个空应用 Unicode NFKC、去首尾空白和 `casefold()`，然后对照作者列出的完整答案。题干固定文字始终只读。`/7` 仍是阅读单选和听力单词填空。
- `system.schema` 公布 `content.practice_groups.cloze`。仓库 Skill 2.9.17 的 `/8` 示例包含阅读短语填空，课程会话交接已更新。
