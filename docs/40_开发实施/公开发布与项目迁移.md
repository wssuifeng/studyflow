# 公开发布与项目迁移

2026-09-30用户明确授权公开源码并整理软件目录；不发布英语、其他学习资料、旧主控。

源码、软件文档、Skill集中到独立StudyFlow目录。公开仓库使用干净初始提交，不导入私人Git对象、历史或remote。原仓库保持private；原软件与运行数据保存在私人迁移备份，不删除。

白名单：`apps/desktop`源码/配置/图标/脚本；`packages/core` Core/CLI/Engine/包内迁移资源/合成测试；去个人化docs；公共skills；CI和安全说明。

排除：真实课程/答案、根学习主控、旧私人治理历史、数据库、日志、密钥、截图、MSI、venv、依赖缓存、其他Agent原型。原content未复制，公开java-reference.md重新编写为合成演示。

main目标：1人批准、CODEOWNERS、过期批准失效、讨论解决、Python/Vue CI；禁强推/删除。所有者保留管理员管理通道，无新增协作者和自动合并。访客提出PR不等于获合并权限。

实际规则和CI结果见 [验证记录](验证记录.md)，不能把本地文字当成远程已生效。此后只从新软件目录开发，不从私人目录批量同步，不merge私人历史。
