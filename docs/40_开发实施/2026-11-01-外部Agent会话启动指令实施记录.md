## 目标与边界

落实[启动指令设计](../30_系统设计/外部Agent会话启动指令设计-v1.md)：设置页复制的文本明确提供 Skill 路径、CLI 路径及参数、StudyFlow 数据工作区、Agent 协作区入口，并要求新会话先恢复上下文，再根据工作区记录和实测能力列出可做事项。启动文本只负责会话路由；课程、规划、学习和批改等业务流程仍由 Skill 单一维护。

本次没有修改 Skill 规则、真实学习数据、用户协作区指针、安装目录 Skill 或公共 Skill，也没有重建/安装 MSI。

## 实施内容

- `system.installation` 只读读取用户级 `~/.studyflow-agent/workspace.json`，校验 `format=1`、绝对协作区目录及目标入口文档，并拒绝与数据根、源码仓库或安装目录重叠的路径。返回 `found`、`missing` 或 `invalid` 及有效入口绝对路径；不创建/修复指针、不访问数据库。
- 设置页复制指令按入口状态生成行为：`found` 时读取已有入口文档；`missing` 时要求先读 Skill，再依 Skill 初始化独立协作区；`invalid` 时要求停止并报告，不自动另建目录。任务已明确时直接进入相应 Skill 流程，不再要求用户从通用菜单选择。
- `system.installation` 接口契约与前端类型同步；Core 路径校验、Engine 返回、三种入口状态文案及复制内容均增加测试。
- CLI smoke 仅在它创建的临时合成库中运行 `db-upgrade` 后验证入口发现；课程更新检查按当前合同确认发布后重置学习状态、重开读取新版、旧轮次和笔记留存。
