## 2. 本轮实现

### 2.1 LC-01：简述常显、详解按需展开

- 课程包 /3 新增受控 details：id/type/title/summary/body；标题、简述、详解分别最多 200/3,000/20,000 字符且非空，不接受嵌套块或作者 JS/CSS/组件。/1、/2 仍严格拒绝 details；/3 兼容 general/english。
- Core 生成消毒后的简述/正文 HTML，完整 Markdown 回退包含全部详解；修订保留包版本，冻结轮次不自动切换内容。
- Vue 共用原生 disclosure；简述常显、详解默认收起，支持键盘/ARIA/可见焦点、轻量反馈与减少动效。展开偏好按工作区指纹、冻结 hash、lesson/block ID 隔离，只是本地展示偏好，不写学习完成状态。
- 大纲/块定位先展开；隐藏标题不参加可见标题定位。历史冻结来源带块锚点可展开；无锚点也保留完整详解。摘录继续保留冻结块来源，不新开来源阅读轮次。

**兼容边界：** 旧课会采用新模板/单列，但只有明确 /3 details 数据才出现折叠。不能自动猜测哪段旧正文是可隐藏的补充知识，核心定义仍须常显。

主要源码：[content](../../packages/core/src/studyflow/modules/courses/content.py)、[共享教学组件](../../apps/desktop/src/features/courses/components/TeachingContent.vue)、[折叠组件](../../apps/desktop/src/features/courses/components/TeachingDisclosure.vue)、[展示偏好](../../apps/desktop/src/features/courses/detailsDisclosure.ts)、[冻结来源](../../apps/desktop/src/features/notes/components/FrozenSource.vue)。

### 2.2 LC-02/07：默认线性与共享模板

- teachingGroups 始终单列，保留作者顺序、稳定 ID 和来源；不再把连续 concept 自动两两分组。comparison 内部保留语义明确的并列对照。
- 正文开放式排版，不再为每个概念重复堆相同边框容器；统一标题/段落/列表/表格层次、对比表、已知条件/推导/结论、提醒与小结、详解提示及留白。

### 2.3 LC-03：无作答轮次安全重新开始

- 新增只读 preview 和 write restart；预检查不创建写租约，提交用 strict 字段、expected_version/expected_content_hash、原幂等键。
- 有任何 Submission（包括空草稿和旧未绑定记录）、答案写回执或英语状态/检查即拒绝重开。学习打开/重开生命周期回执不冒充作答，因此全新未作答轮次可经再次明确确认重开。
- 同事务重新检查、CAS 关闭旧轮次并创建最新内容冻结轮次；旧轮次 ABANDONED，保留阅读位置/原文/笔记，新轮次从头。旧轮次迟到写拒绝，已确认原回执可重放；旧轮次笔记只读、计划连续笔记仍可编辑。
- 课程阅读入口先预检查/确认，并复用工具窗口保存协调。双击、离开、迟到响应、缓存不可用、未知结果均保护；丢回执后 reload 用同参数同 key 重试，不多建轮次。保存失败时明确不保存离开仍可用，重开对话框不阻塞它。
- 修复只读详情在 Session rollback 后访问脱离 ORM 的风险，在 Session 内构造 DTO。兼容旧计划归属，不迁移冻结计划。
