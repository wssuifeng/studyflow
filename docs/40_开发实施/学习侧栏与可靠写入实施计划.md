# 学习侧栏与可靠写入实施计划 · 2026-10-02

**授权依据**：用户要求修复CLI诊断与Engine写入缺陷，重设计知识阅读/侧边练习/草稿、独立窗口与钉住。用户进一步明确“钉在桌面”为失去焦点仍覆盖普通窗口的Always on Top。由当前Agent实施，不另建第二套前端、不创建其他Agent会话。

**目标**：连续保存可靠；正文专注知识；工具侧栏随时切换练习/草稿；知识点导航状态清楚；独立窗口可置顶、恢复与安全关闭。

## 方案与边界

- 采用同一Vue学习页的正文 + 右侧工具标签布局，而非全页切走或多个纵向卡片。侧栏提供练习（含原位反馈）、草稿（个人推导/笔记）与大纲；窄窗口可折叠正文/工具，不重复前端。
- 草稿持久化到本地Core数据库，绑定冻结学习轮次与知识点；版本校验、失败保留、幂等重试。它不是正式答案，也不进入Agent待批改队列。
- 独立学习窗口复用Vue路线与共享Engine。钉住使用Tauri原生Always on Top；可取消、可拖动/缩放/最小化/关闭，不永久更改系统。
- 知识导航为正常尺寸按钮：未学灰、当前蓝、读完青、通过绿、待批改紫、待修正红、待复测琥珀；同时显示文字/符号/aria标签，颜色不单独承载意义。
- 不显示Markdown原文按钮。课程正文不放工时、教材页码、Agent过程或“无需实现…”元话语；来源仍保存于素材元数据/工程记录，不损失学习轮次快照。
- 真实数据库升级只能走Core受控迁移与备份；不直接SQL、不替用户作答、不删历史事件/答案。隔离副本包含私人数据，不进入公开仓库。
