# 笔记侧栏整体适配修正

日期：2026-10-12。上游：[笔记设计v1.2](../30_系统设计/计划笔记连续编辑与引用设计-v1.md)、[实施计划](计划笔记v2实施计划.md)。用户指出正式接入像嵌套小界面、导航比标签页窄，当前范围缺少清晰的分级容器；本轮纠正正式适配，不重复生成或重做原型。

## 1. 根因与修正

| 根因 | 修正 |
|---|---|
| 共享宿主与序光旧展示规则给笔记外侧保留20px padding，内部再套自己的工作面 | 明确notes宿主，去外层padding与双滚动；子页工作面、编辑工具条、范围导航与宿主标签页同宽 |
| 当前知识点直接返回noteCard，课程范围直接返回lessonGroup；三级壳只在全计划完整存在 | 所有范围共享课程 → 知识点 → 记录卡片结构；课程和知识点折叠，卡内自然段连续编辑 |
| 窄侧栏重复累积24px课程padding、24px卡片padding和外框padding | 使用容器宽度响应式收敛内边距，保留舒适初始卡片，超出自然增长 |
| 编辑器投影监听没有包含迟到的课程/知识点元数据 | 元数据到达后同步分组与选择器标题；保留稳定空输入记录与记录相对选区，不重建编辑器 |
| 独立笔记和英语笔记同样被旧宿主padding包裹 | 共用正式PlanNotebook；native-tool-content标识notes，英语drawer去外框内缩，保留原有关闭/拆窗和单编辑权 |

实际几何：1600px合成页面的标签页容器339px；修正前笔记导航299px，左右各内缩20px。修正后工作面、工具条、范围导航均339px，左右边界相同。文档是唯一滚动面，外层overflow:hidden、内部overflow:auto。

## 2. 显示及业务边界

- 打开时仍默认当前课程的当前知识点，不自动扩大成整课全部笔记；但当前范围也显示课程、知识点的紧凑分组导航壳。
- 课程整体与全计划使用同一结构，不另建保存身份。课程级随记、计划级随记保留；默认不插入没有笔记的其他知识点。
- 小分组标题不是用户正文，不自动存入笔记，也不计入复制正文。原型三级层级是课程/知识点/记录；课程和知识点可折叠，记录卡保留自然输入，不增加逐段生命周期状态栏。
- 空态保留正确课程/知识点归属的输入位，不因展示而自动写入。折叠不删记录，隐藏记录仍由既有ID增量保存保护。
- 编辑工具条不再重复一个带活跃下划线的“笔记”标签；文字工具状态与真实宿主标签分工。段落更多操作按悬浮/键盘聚焦显示，并留出角落空间，不盖正文。
- 序光/白紫共用几何、投影及保存组件；只有颜色/表面语义变量变化。英语仍仅笔记，普通课练习功能未移除。

## 3. 实际文件与工具路径

- notes/editor/projection.ts：统一分级投影、历史标题兜底和空态归属。
- notes/components/NotebookEditor.vue：元数据监听、稳定空记录和相对选区恢复。
- notes/components/PlanNotebook.vue、NotebookScopePicker.vue：安静工具条、完整可访问的同宽筛选与长标题截断。
- notes/editor/extensions.ts、notes/styles/notebook-v2.css：分组标签DOM、三级间距、卡片增长与悬浮操作。
- courses/components/CourseToolsSidebar.vue、ToolSession.vue、courses/styles/dock.css：明确notes宿主及唯一滚动责任。
- english/training/english.css：英语笔记沿用同一满宽工作面。
- scripts/test-notebook-v2.cjs、smoke-notebook-v2.py：新增真实投影和实际几何回归。

以上路径以apps/desktop/src为组件根（测试脚本根为apps/desktop）。本轮mockup-to-page走engineering-adaptation：对照已采纳原型/真实screenshot-to-code来源修正宿主适配，没有新生图/图转代码调用，不把手工适配声称为新工具生成。所有学习内容与写入均为隔离合成数据。
