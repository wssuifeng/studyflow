# StudyFlow 全 Rust 后端替换实施计划

编制于 2026-11-21。用户已采纳架构复核结论，用户已发出实施指令。**从 W0.1 开始，按第 8 节的执行账本续接。**本文是任务与证据索引的主文件，产品范围取自[已确认的架构报告第 8 节](../30_系统设计/2026-11-21-整体架构与Rust迁移评估.md)。

## 1. 目标、交付边界和基线

交付一个可覆盖安装的 Windows x64 en-US MSI。学习者从 Tauri 窗口进入 Vue 界面，外部 Agent 可在桌面关闭时运行原生 CLI。课程、学习、批改、笔记、计划、音频、工作区的业务规则各维护一份。开发按批集成，第一个对用户交付的重构版本使用完整 Rust 后端。

| 已定约束 | 实施验收会检查什么 |
|---|---|
| D1 共享业务实现 | Tauri `invoke` → 宿主 → 独立 Rust Engine（stdio JSONL 1.2）。Rust CLI 与 Engine 链接同一 Core。CLI 回执形状、退出码与 Engine 信封分别兼容。 |
| D2 SQLite 单库 | 保留已支持的 SQLite 配置、工作区结构、迁移链和回执。遇遗留 MySQL 配置给出脱敏错误。只读操作、维护锁和失败恢复分别验收。 |
| D3 桌面与语音 API | 正式 Vue 只由 Tauri 提供。旧 FastAPI/Jinja 与开发 HTTP 桥的有效断言迁到组件、命令、原生窗口。语音保留 Step Plan 与 compatible 两种接入，制课生成，学习读取已采用音频。 |
| D4 单一安装包 | `StudyFlow_<版本>_x64_en-US.msi`，升级标识 `{ABFFC78E-4655-5CA9-B66B-386907AB5FEE}`，语言 1033。沿用当前 WebView2 下载引导。测试已有 WebView2 时的离线学习，以及缺少它时的联网首装路径。 |
| D5 原生 CLI 与 Skill | `binaries/studyflow.exe`、`binaries/studyflow-engine.exe`、随包 Skill 和设置页复制的 Agent 启动指令一致。安装、学习和制课可在无 Python/Node/Rust 工具链/Docker 的目标机完成。仓库可保留独立验证脚本。 |
| D6 功能模块与共用工具 | 各域拥有自己的规则、SQL 和测试。`application` 协调跨域事务，`infrastructure` 提供连接、迁移、原子文件、系统锁、DPAPI、脱敏诊断。Vue 的路由、键盘、主题及跨窗显示状态仍归前端。 |

**基线证据。** 1.8.27 原包 SHA-256 为 `8967E7FFD2CE3D8C11FF6578B5A398DC1678B28937B295C4B10FBF2521D90BB2`，包内 Skill 2.9.19，SQLite head `0018_plan_course_sequence`，教材 `/1`—`/8`。`system.version` 的 98 个能力名称只是盘点的起点。旧版 525 个 Core 测试通过、2 个跳过，前端英语/学习/主题分别为 59/132/97。这些数字用来定位历史覆盖。当前源码还有未提交增量，应以 W0.1 的可恢复快照为输入。[1.8.27 构建记录](2026-11-21-1.8.27听力当前句字幕.md) · [历史构建入口](构建与开发.md)

**环境边界。** 功能验证使用 StudyFlow 专属隔离目录与合成教材。安装升级和失败恢复使用可还原 Windows VM 或等价隔离测试机。现有用户安装、个人学习工作区、公共 Skill、真实外发及 Git 发布各有独立动作。示例与证据使用代号、摘要、脱敏路径。不得从聊天或历史日志取用 API Key。

**证据放哪里。** 实施开始后，在本计划第 8 节逐项记录证据位置。轻量合成断言进入相应 Rust 测试目录。Windows 日志、大型合成旧库、MSI 与草稿快照用仓库现有忽略目录 `apps/desktop/test-results/rust-migration/` 或显式工程私有产物目录，按基线标识、任务号、运行号分开。记录相对定位、版本、摘要、命令、退出码、断言数和未覆盖项。恢复基线所需文件另留可还原副本。检查“测试成功”时确认目标用例实际被执行，记录零断言、跳过或空过滤器的原因。
