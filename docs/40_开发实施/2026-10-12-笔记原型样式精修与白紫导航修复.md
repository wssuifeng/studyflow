## 2. 根因与最小修复

原AppShell只有序光显式导航几何，白紫主题数据184px，工具几何又有72/184px回退。宽度与双层内边距叠加后，计划标题被严重截断；白紫没有为共享CourseOutline定义标题/状态纵向结构及返回按钮样式。这些是几何/布局根因，不能只换颜色。

| 正式文件 | 修改 |
|---|---|
| AppShell.vue | 导航宽度统一用于theme-nav、panel-nav与panelGeometry；序光旧自适应保留 |
| shared/layout/workspacePanel.ts | 增加navigationRailWidth：窄窗64、中窗上限240、桌面使用主题值；小自定义导航不被强制扩大 |
| builtin/white-violet.json | 首选184→264px |
| shared/themes/display.ts | 受控导航上限240→280，旧值兼容；新增边界验证，仍拒绝越界/小数 |
| courses/styles/white-violet.css | 去双层过大内边距、标题/状态分行、固定编号、缩小返回按钮、真正大纲滚动和低于900px图标模式 |
| test-workspace-panel.cjs / test-themes.cjs | 红/绿动态几何、旧自定义宽度与数据白名单边界回归 |

新增回归先失败于184≠264和缺少统一函数；修复后专项12/12。最初264px被既有主题校验上限240拒绝，已修同一权威解析器和边界测试，未通过放弃校验或删原断言解决。
