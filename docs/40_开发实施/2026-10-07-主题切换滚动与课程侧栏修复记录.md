# 2026-10-07 · 主题切换滚动与课程侧栏修复记录

## 1. 用户问题

本轮修复以下两个问题：

1. 白紫主题在设置/工作区页面滚动到底后，切换到序光会出现页面高度异常、下方大片空白或内容不可继续查看；
2. 白紫课程页左侧栏仍会随页面滚动，且课程页没有同步显示序光已有的课程大纲/本节大纲。

本轮只使用隔离合成工作区，不读取、修改或删除真实学习资料、答案和真实数据库。

## 2. 根因

### 2.1 序光固定视口规则污染普通页面

序光样式曾对所有 `body` 和 `.app-shell` 直接设置 `overflow:hidden`、`height:100dvh`。设置页、计划页和反馈页本质上是普通文档页面，不应继承课程阅读器的固定视口模型。主题切换发生在文档滚动到底时，旧的文档滚动位置与新主题固定视口布局叠加，造成底部空白和不可继续滚动。

修复为：

- 普通页面不再由序光设置全局 `body { overflow:hidden }`；
- 固定视口仅作用于 `.app-shell.learning-shell` 和 `.app-shell.focus-shell`；
- 课程主内容内部使用独立阅读滚动容器，设置页保持浏览器文档滚动。

### 2.2 运行时主题契约覆盖固定侧栏

`runtime.css` 的 `themeShellContract=v2` 仍有：

```css
position: sticky !important;
```

该规则优先级高于白紫和共享工作区样式，导致白紫课程侧栏实际仍为 `sticky`。

修复为共享契约统一使用 `position: fixed`，桌面窗口的顶部从标题栏下方开始；侧栏宽度复用 `--panel-nav-width`。

### 2.3 固定侧栏脱离 Grid 后主内容自动落入第一列

侧栏改为 `fixed` 后不再参与 CSS Grid 自动排布。如果主内容仍使用 `grid-column:auto`，它会被自动放入第一列，正文宽度被压缩到约 184px，表现为课程正文窄条/近似白屏。

修复为：

```css
.learning-shell:not(.focus-shell) > .main-content {
  grid-column: 2;
}
```

工具区仍沿用第三列；独立工具窗口继续使用 focus-shell 单列布局。

### 2.4 白紫未挂载课程大纲

CourseReader 原来只在 `sequenceTheme` 为真时 Teleport `CourseOutline`。白紫主题因此没有课程/本节大纲。

已改为：只要主窗口导航可见，两套正式主题都挂载同一个 `CourseOutline`，不复制业务逻辑。白紫只补充相同组件的视觉样式。
