# 2026-11-12 · 朱批纸白国风主题候选实施记录

> 性质：用户明确授权「完全自主做一版本项目的前端主题」以测试前端审美能力，并指定方向「红白主色 + 黑色辅助的国风」。本轮交付一个**可导入候选主题**「朱批纸白」（`cinnabar-paper`），不改动两套正式内置主题（序光 / 白紫轻学），不改 `DEFAULT_THEME`，不进入内置目录。候选未采纳、未设为默认、未安装、未打包、未提交推送；真实学习数据未读写；`business_acceptance=not_evaluated`，阶段不推进。

- 候选以**数据 JSON + 身份作用域 CSS + 本地 SVG 资产**交付，经设置页「导入主题JSON」真实文件入口生效（控制器 `importTheme` 闭环），与项目既有「用户自定义主题能力保留」一致。

- 几何与滚动所有权仍归共享壳层契约 v2；候选不重定义 `panel-open` 三栏、不覆盖 fixed 导航、不新增门禁债务。

## 2. 设计方向与三轮色板纠偏

艺术方向取自「朱批治学」：素白纸面、中国红批注、玄墨正文；识别符号为朱文方印（题首「学」印）、回纹锦绫（侧栏底边）、朱批眉栏（教学块左红栏）、衬线标题（思源宋体）。红白承载最大面积，墨黑只作正文与辅助。

色板按用户反馈迭代三轮，每轮均经真实 `contract.parseTheme` 全量对比度校验：

1. **v1 暖纸**：宣纸暖白底（`#f3eddf` 等）+ 朱砂 `#ad2b2b` + 暖墨。用户反馈「颜色跑偏，要红白 + 黑辅助，不要暖色」。
2. **v2 中性冷白**：冷灰白底（`#f3f4f6`）+ 中国红 `#bf1e2e` + 中性墨。用户反馈「背景不要用灰色，右侧灰色太暗，要偏亮、简洁，红白占主」。
3. **v3 纯白明亮（当前）**：`surface.canvas`/`surface.panel`/`surface.input` 均为纯白 `#ffffff`；交互态用**红晕近白**而非灰（`hover #f8f2f3`、`active #f5eaec`、`raised #faf7f7`）；中国红提亮为 `#c8102e`（`accent.strong #a60d26`、`accent.soft #fdeef0`）；正文玄墨 `#17181a`/`#3b3d42`/`#595c63`；语义色 success/info/warning/danger 各配近白软底。大面积纯白、红为唯一强强调、黑仅正文，明亮简洁。

当前契约校验：最紧文本对 `text.muted/surface.active = 5.70`，`accent.primary/surface.active = 5.00`、`accent.primary/accent.soft = 5.23`，全部 ≥4.5:1；三个素材回退色与画布对比 1.168 / 1.223 / 1.232（≥1.05）。

## 3. 工艺决策（针对 visual-v5 否决的四项根因）

- **字体落地**：本机已装 `NotoSerifSC-VF.ttf` / `NotoSansSC-VF.ttf`（族名 `Noto Serif SC` / `Noto Sans SC`）。在 `display-loader.ts` 的 editorial 字族栈于 `SimSun` 前补 `'Noto Serif SC'`、humanist 栈于 `Microsoft YaHei UI` 前补 `'Noto Sans SC'`，并同步 `runtime.css` 的 editorial 回退规则。两套正式主题用 modern/ui，字族栈原样未变（专项测试断言）。浏览器 `document.fonts.check` 实测两族可用，标题真实落到思源宋体，不再落 SimSun。
- **矢量图标**：复用共享 `SidebarNav.vue` 既有内联 SVG 线描图标，候选在作用域内启用 `.nav-icon-svg`、隐藏字形 variant `.nav-icon-glyph`（两者均为已登记装饰槽）。
- **层级与景深**：`elevation: subtle` + 作用域纸面阴影 `color-mix(shadow-ink …)`；卡片/教学块/工具签筒有明确投影，非 0 阴影。
- **cursor:pointer**：作用域内 `button{cursor:pointer}`、`:disabled{cursor:not-allowed}`、`:active` 微位移反馈。
- 表面处理用契约允许的 `paper`（实体哑光），未用玻璃/霓虹。

## 4. 本地资产（全本地，无网络引用）

- `assets/cinnabar-paper-grain.svg`：素纸纤维中性噪点（background，runtime 以 .22 opacity 叠加，极淡）。
- `assets/cinnabar-paper-meander.svg`：回纹锦绫带（texture → `--sidebar-landscape`，侧栏 `::after` 装饰槽，`pointer-events:none`）。
