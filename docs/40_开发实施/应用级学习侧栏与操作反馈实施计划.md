# 应用级学习侧栏与操作反馈实施计划

日期：2026-10-02。依据：用户已授权核心流程优化，并以截图明确右栏需应用级等高、默认关闭。本批不更换技术栈，不改变冻结学习轮次/事务/CLI数据契约。

## 1. 本批边界与设计

- 选择应用壳三栏，而非正文内部卡片或悬浮遮挡：导航、阅读、工具同起止线；桌面标题栏独立保留。
- 右栏默认隐藏，课程上方仅一个紧凑入口；点击直接打开练习，可切笔记/大纲。保留标签排序、双窗格、宽度、原生拆窗/置顶。
- 应用壳负责空间；课程组件继续唯一持有答案/笔记控制器，以Vue Teleport投送工具内容，不另建编辑器或学习轮次。
- 收起只隐藏工具，不卸载已有编辑内容。旧缓存保留宽度/排序，但新打开课程不自动展开；明确跳转作答的链接可展开。
- >=1280px打开时左导航228→184px；900–1279px左导航压缩为72px；<900px工具占内容区，提供返回阅读。不得挤出极窄正文或出现整页横滚。
- 右栏可鼠标/键盘调宽；收起恢复入口焦点；展开聚焦活动标签；减少动效偏好关闭动画。
- 视觉：统一暖中性底色、青绿色强调、细分隔与清楚的排版；不增加仪表盘容器、积分、排行或大型装饰。
- 反馈：按压/悬停、知识点切换、确认读完、成功保存/提交分别反馈；失败不播放成功音效。音效默认关闭，可在工作区启用/试听；本地合成，无网络资源，后台自动保存不持续鸣叫。
