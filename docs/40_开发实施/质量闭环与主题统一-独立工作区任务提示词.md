## 1. 产品目标与禁止事项

三个目标：在生成侧拦住不自然/错误教材；课程内容更新成功后直接重置该课程学习状态并读取最新材料；两套主题维护一套页面骨架、组件和交互。

- 本地单用户Vue3/TypeScript + Tauri/Rust + Python Core，保持模块架构，不加账号/权限/云教务/内置模型供应商。
- 保留序光与白紫的视觉特点，但功能布局不由主题ID决定。普通课程右工具=练习/笔记；英语=笔记，英语训练占主界面。
- 不接真实学习工作区、不打开私人数据库、不直接SQL、不代作答、不批量改真实课程。所有训练/改题/草稿/提交测试使用你克隆内的隔离合成工作区，并标明非学习证据。
- 不改原仓库、公共Skill、共享图转代码服务配置、系统代理/权限或已安装应用。不读取模型密钥，不把私人截图/课程答案上传外部服务。
- 不做TTS预生成、考试专项、知识库、账号系统。不得因样例出现React、Tailwind、Pinia、Vitest就顺手迁移/加库。
- 内容更新后直接重置目标课程学习状态，不做题级增量换版/复用当前进度。保留CAS/幂等，笔记不清空，旧答案/反馈如留历史不得计入新学习；用户不操作版本。

## 3. 长任务分解及关口

### W0 基线和复现

建立精简问题矩阵：页面/状态/双主题/证据/根因候选。按实际App路由覆盖控制台、计划/详情、普通阅读、英语概览/训练/复测、作答反馈、错题、设置/Agent接入、计划笔记和独立工具窗口；不是只检查文档详情页。优先复现：白紫正文视口偏小、重复导航、搜索区间距、按钮不一致、巨大计划卡/落款、英语检查后比例失衡、ANSWER_EMPTY误进保存恢复栏、旧材料无法当前纠错。

记录现有测试基线与非本任务失败。不能只读截图，也必须运行实际Vue/Core和读取现有原型/组件；只读远程README不算复现。

### W1 生成侧质量闭环

落实主设计§2—5：生成前对齐，作者逐项审查，独立语义复核，工具候选与确定性错误分开，报告绑定package hash，同链/同模板追查，更新后旧报告失效，发布回读检查实际用户读源。

英语覆盖全部目标/完整变体/角色实际词段/中文/音标及前后递进，不只改被点名句子。短语可合法但不能暗藏主语；不机械去-s或套SVO。普通课覆盖事实、首次定义、必要条件、可解性、解析泄漏、折叠后主干与合理组件。

优先扩展现有规则/脚本，若下沉Core保持一份实现。新增质量API/命令先设计并通过capabilities发现。机器不冒充语法权威；没有独立审查证据就标明，不能自签“全合格”。

### W2 内容更新后直接重置学习状态（2026-10-16更正）

按设计v1.1 §6：内容更新成功后，目标课程进度/当前位置/当前作答与训练检查/完成标记归零，回到待学习；下次打开从最新材料开始。普通和英语一致，不再做v1的题级影响分类、局部状态迁移、答案映射或材料热合并。

只作用目标课程/挂载项，不清空笔记、不影响其他课程；旧答案/反馈若保留历史，不回填本次学习。更新失败不重置，相同内容/纯CSS不重置，幂等重试不重复重置，迟到旧保存请求不得污染新状态。保留必要草稿/导出保护，但不发展为复杂换版流程。

只在隔离合成工作区实现与回归；本更正不是重置真实课程的授权。已按旧方案开工时先调整W2范围，不恢复整个交接包、不覆盖其他单元成果。遇到数据模型阻碍报告最小差异，不另建版本平台。

### W3 共享骨架与组件

先做普通阅读页 + 英语训练/检查后 + 错误提示三类代表状态的双主题试点，展示可查看的图/原型与真实路径，**等待用户确认视觉方向后**再扩展列表、控制台、弹窗、侧栏和独立工具窗。用户未确认时可继续W1/W2或不依赖视觉的W4测试，不做整仓视觉扩批。

正文一个主要滚动域，压缩重复上下文，不靠全局缩字体塞内容；保留可读行宽而去掉多层居中厚框。统一按钮/表单/tabs/状态/弹窗语义与焦点。空输入、答错、发音失败、写入失败/未知结果、材料变化分开处理。

### W4 程序主题门禁

把设计§8落到真实代码：配置校验、Vue/TS AST业务主题分支检查、CSS AST布局越权检查、真实运行时区域与状态契约。原有债务建立精确且只减不增例外，不放行整个主题目录。

用故意违规fixture证明每道门禁真的失败，合法装饰/旧配置迁移也要通过。消除业务组件的主题ID布局分支；主题只提供受控视觉值与资产，不是再复制一套组件加两套补丁。

### W5 回归与交接

测试、源码审核、实际截图目视分别给结论；有条件做Tauri/WebView2独立窗、DPI/置顶/多屏验证。无Windows/无物理多屏就保留未验，不用浏览器结果冒充原生通过。

## 4. 执行纪律

- 每单元先写失败用例→确认失败→最小实现→回归→有界审查→回写。按模块拆分，避免把逻辑继续堆入大页面或AppService。
- 默认单主代理。此提示词不授权自动启动子代理；需要并行时向用户说明写集和实际模型额度。
- 图转代码历史可能单请求占4路，上游总额度曾为5；先读实际Skill/服务能力，未知就串行并停止同渠道子任务，不能假设渠道仍免费或模型仍相同。
- 现有接口继续兼容；新增能力完成测试之前，不在制课入口宣称可用。自动保存/普通校验不得共用一个failed状态。
- 不进行无关大重构，不删除历史文档/用户数据，不升级依赖解决不存在的问题。涉及新增解析库等必要依赖，说明选择、锁定版本和边界，优先已有能力。
