# 右侧标签停靠、独立窗口与计划笔记实施计划

依据：用户2026-10-02纠正小窗含义并要求参考DSH/Codex，随后确认独立窗口跟随计划下课程、共享同轮答案，笔记默认计划级并支持正文摘录。此增量不改变个人本地软件定位。

## 已确认的交互与数据边界

1. 正文与右侧停靠面连成一体，无侧栏卡片阴影；34px标签顶边、发丝分隔、可调宽、可收起恢复。标签可关闭和重新打开、右键拆窗、拖出拆窗、调整顺序；最多两窗格，不足宽度不硬挤。
2. 拆的是练习/笔记/大纲标签，不是复制整个课程。独立原生无边框窗口可放回、置顶、拖动缩放、复用并聚焦；主程序退出级联关闭。创建命令改为异步，处理内容就绪与失败，不把命令返回当作加载完成。
3. 独立窗口跟随计划与课程，不锁定主窗当前知识点；练习窗能够切换本课程全部知识点。窗口之间复用同一冻结轮次，不自动开始第二轮，不自动正式提交。
4. 笔记是连贯的计划级文档，默认查看全计划；笔记块可关联课程或知识点用于筛选。自由笔记和正文摘录都进入该文档，摘录保留来源与学习轮次。旧知识点随手草稿保留、可显式复制进笔记，不静默迁移或删除。
5. 笔记采用独立的乐观版本与稳定幂等凭据，不属于作答/批改队列。跨窗只允许当前工具写入，其他窗口收到保存事件后刷新；提交前汇合远端编辑，冲突保留本机输入。保存失败仍能导出或明确不保存离开。
6. 单一Vue UI/Tauri窗口薄壳/Python Core保持，软件数据仍按受控迁移管理。布局持久化不保存真实答案。只能在隔离合成工作区测试，不改用户安装或正式数据，不自动提交/推送。

## 官方参考与风险

- DSH停靠面是参考设计，不引入它的插件框架；参考用户提供规格而非照搬聊天功能。
- Tauri 2.12.0官方源码注明同步命令创建WebviewWindow会在Windows死锁；现有open_study_window符合该风险条件，但用户现场尚未通过原生复现确认唯一原因。
- 原生窗口与网页浮层的缩放/位置/层级不同，OS窗口使用原生能力。主窗口大小变化不会覆盖用户摆放的浮窗位置。
