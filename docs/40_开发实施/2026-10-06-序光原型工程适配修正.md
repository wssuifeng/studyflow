# 序光原型工程适配修正 · collaboration-plan

## 用户反馈与根因
安装版和已确认原型不一致。此前仅新增序光 JSON，没有接入侧栏课程/本节大纲、背景、阅读布局与页尾导航；sound_profile=muted 强制阻断已启用的音效。主题注册/构建成功不能证明原型已经适配。

## 协作模式
engineering-adaptation：复用用户提供的序光原型，不重新生图或重新生成原型。已读 mockup-to-page、systematic-debugging、webapp-testing；本轮不调用 imagegen/screenshot-to-code，原因是已有选定原型，缺失步骤是正式工程适配。单会话执行，不派发代理，不请求模型渠道。

## 边界与映射
- SidebarNav + CourseOutline：一个左侧栏容纳主导航、计划/课程摘要、课程/本节大纲切换；真实课程数据，不增加第四栏或虚构功能。
- CourseReader：紧凑顶栏、居中受控阅读宽度、正文标题、组件化内容、页尾上/下一节。原型中的模拟保存和单题提交不移植，仍整课提交。
- 复用原型两份本地装饰资产，仅序光启用；固定窗口高度、列表内部滚动、背景不扩张页面。
- 使用现有答案/笔记/冻结轮次/安全退出状态，Core/CLI/Engine/API不变，不读真实学习数据。
- 音效修复为 soft-tap，仍尊重全局关闭、失焦静音与减少动画偏好。

## 执行与验证
- [ ] 先增加失败回归：序光不得强制静音；正式资产/样式/大纲必须存在。
- [ ] 接入真实课程与文档大纲，适配选定布局与素材。
- [ ] 真实 Vue + 合成 Core 浏览器验证：工具开关、长文滚动、大纲跳转、换节保存、主题切换不破坏输入、旧Markdown及教学组件。
- [ ] 截图人眼对照原型，覆盖1920×1080、1440×900和窄窗；不把静态测试替代视觉检查。
- [ ] 原生构建与MSI打包，记录真实产物，展示运行截图再交付。
