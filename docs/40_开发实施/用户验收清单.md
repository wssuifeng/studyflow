# StudyFlow 用户验收清单

发布不是用户体验验收，不自动填写通过。

- [ ] 备份/升级真实工作区，不丢数据。
- [ ] 同计划课程聚合，多知识点左右导航保留进度。
- [ ] 中文emoji整课保存/提交，重启持久化，错误反馈清晰。
- [ ] Agent能读取待批改叶子，修正/复测保留原答案。
- [ ] 一体窗口拖动、最小化、最大化/恢复、关闭可用，滚动条仍可操作。
- [ ] 桌面启停自动管理Engine，不需用户手动开服务。
- [ ] 其他Agent按Skill选工作区和完成授权任务，不伪造学习证据。

只报告脱敏操作、版本和诊断ID，不公开数据库、私人路径或真实答案。


## 核心学习链复验（2026-10-01增量）

以下均留待体验，不预先勾选：
- [ ] 同一个知识点界面同时查看正文、对应题目和输入区；不再切换阅读/答卷子页面。
- [ ] 允许留空进入下一项；最终提交能定位漏题；目录/上一项/下一项都保留草稿。
- [ ] 输入自动保存，等待中的旧保存结果不覆盖新输入；关闭/刷新后能恢复未保存内容。
- [ ] 保存失败留页、明确重试；版本冲突先保留内容，不自动覆盖其他窗口。
- [ ] 首次统一提交后显示待批改，控制台推进到下一未提交课程，不把提交当作掌握。
- [ ] 批改部分返回、原位修正和新的复测题清晰可见；原答案与父子历史不被覆盖。
- [ ] 源材料更新不改变学习中内容；本轮收口后显式开始新版，旧记录可查。
- [ ] 纯阅读课程可确认完成；无需手动开后端；退出窗口先保存或明确保留输入。
- [ ] 高度、窄屏、键盘焦点、滚动与简洁信息表达舒适，无冗余平台功能。
