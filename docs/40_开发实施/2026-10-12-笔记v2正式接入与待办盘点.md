## 3. Core / 数据 / 契约

- 一计划一 PlanNotebook、版本和幂等回执；记录是聚合内值对象。新增 format_version/document_json，保留旧 blocks_json；PlanNotebookSource 与现有模型共用 Base/Runtime/Session。
- 新二级职责包 `learning/notebook/{document,sources,commands,queries}.py`。Facade/CLI/Engine 只装配委派，没有新数据库运行时或卡片级事务。
- 新 `plan.notebook.read`：按计划/课程/知识点/记录 ID 有界读取，limit1—100，分页携带同版本；版本变化拒绝混读。
- 新 `plan.notebook.apply`：insert/replace/remove/move，按稳定 ID 原子批次、一次 CAS、同键同负载重放；来源/锚点无效整批回滚。Engine schema 包含判别式操作和出处规格，CLI 增加 notebook-read/apply。
- Core 核验冻结正文及英语冻结目标句；原摘录/定位不可变，当前文字可编辑；NFC/换行比较派生原文、片段或改写，不忽略大小写标点。全文清理不抹掉已保存摘录。
- 旧 quote/text 在同记录内保序转换；无法核验的旧出处明确 LEGACY_UNVERIFIED。旧全文 save 拒绝覆盖 v2；未知未来格式拒绝覆盖，也不导出伪空文档。
- 迁移新增 **0016_notebook_document**，保留0013/14/15。测试发现0008引用当前ORM会把未来字段提前带入历史迁移，已将0008历史DDL固定；0015→0016保留原文本/版本并创建一致性备份。
- 工作区 ZIP 的 revision 白名单原来只到0012，真实新增备份测试先失败，随后补入已存在0013—16；结构、出处、版本完整导出/恢复通过，不复制活动SQLite。

## 4. 正式 UI 与可靠性

- 普通课、计划页、独立工具页、英语笔记继续复用同一 PlanNotebook；英语不增加侧栏练习。旧多 textarea 改为同一连续编辑面，自然段、列表、轻格式、分卡/合卡、选区剪切复制、引用编辑与计划内撤销。
- 默认当前知识点；全计划/真实课程、整课/知识点两层选择；全计划课程→知识点分组，折叠/筛选的隐藏记录不参与覆盖。搜索结果/阅读模式只读。
- 引用按安静样式标识、悬浮来源、不常驻占位；固定/关闭、查看冻结正文、原摘录、恢复原文、去标记。收到保存回执后使用 Core 实际核验元数据。
- 850ms 自动保存、5秒恢复快照、Ctrl+S；IME合成延后。固定在途负载/键，旧回执不覆盖后续输入；恢复后重放的旧回执也不得降级已经读到的较新工作区版本。单编辑权、未知原键重试、损坏恢复件导出与“不保存离开”保留。
- 结果未知保留原键；明确参数/出处校验拒绝则保留错误请求供导出，允许修正后新请求保存，不永久锁住编辑。无用未核验出处不会反复注册。结构化剪贴板额外校验同计划和目标已知出处，跨计划/其他窗口安全降级并提示。
- 同记录/删除/移动/顺序冲突逐记录明确选择，不盲目追加副本。独立记录改动合并；本机缓存失败单独警告，不推翻成功数据库回执。
- 跨窗口保存事件沿用既有 `studyflow-tool-saved`。视图缓存按工作区+计划共享范围、折叠、记录相对选区与滚动；仅编辑者写入，输入恢复件仍按窗口隔离。代码接入不代表真实交接已验收。
- v1 兼容控制器留在 useLegacyPlanNotebook，仅兼容回归使用，正式入口全部使用 v2；既有可靠保存断言未删除，另加 v2 专项。
