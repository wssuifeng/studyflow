# 2026-11-12 · 1.8.20 朱批纸白内置主题与安装包构建记录

> 性质：用户安装 1.8.19 后反馈「新主题安装完并没有显示」，继而明确授权「也默认放安装包里面去，安装就可以选择」。据此把「朱批纸白」（`cinnabar-paper`）由**可导入候选提升为内置主题**，安装后即在设置页主题列表可选，无需导入。这是经用户明确确认的冻结内置目录边界变更（原仅序光/白紫）。默认主题仍白紫，朱批纸白为可选第三套。本轮递增版本至 1.8.20 并重建未签名 MSI。真实学习数据未读写；未安装/未同步公共 Skill/未提交推送；阶段与 `business_acceptance` 不推进。

## 1. 实施

### 1.1 候选提升为内置

- **文件移动（清单）**：`apps/desktop/theme-candidates/cinnabar-paper.json` → `apps/desktop/src/shared/themes/builtin/cinnabar-paper.json`。内容一致，仅描述去掉「候选主题，导入后生效，不影响默认外观」一句。`theme-candidates/` 目录随之清空。
- 内置目录由 `catalog.ts` 的 `import.meta.glob('./builtin/*.json')` 构建期自动发现，放入即生效；`DEFAULT_THEME` 仍 `white-violet`（`contract.ts` 未改），朱批纸白为可选而非默认。
- 候选 CSS（`src/features/courses/styles/cinnabar-paper.css`，全身份作用域，已在 `index.css` 层叠引入）与三个本地 SVG 资产（`builtin-assets.ts` 已注册）本轮未改，随 dist 编入安装包。
- 选择器 `ThemeSettings.vue` 以 `v-for="item in availableThemes"` 动态渲染，网格 `repeat(auto-fit,minmax(200px,1fr))` 自适应三卡，**无需改 UI 代码**。
- 内置语义（`controller.ts` 既有）：`select('cinnabar-paper')` 可用、`source='builtin'`；导入内置 ID 被拒（「此ID属于内置主题」）；`removeTheme` 对内置被拒，设置页移除按钮 `v-if="custom"` 对内置不显示。

### 1.2 守卫同步（4 处）

- `test-themes.cjs`：内置列表断言改 `['cinnabar-paper','sequence-light','white-violet']`，增朱批纸白名称校验，测试名更新。
- `test-white-violet.cjs`：内置列表与测试名同步含朱批纸白。
- `test-cinnabar-paper.cjs`：由「候选不改内置」守卫重写为「内置主题」守卫——契约/对比度、内置目录含朱批纸白且默认白紫、内置直选/导出/重载 + 内置ID不可导入或移除、CSS 身份作用域与门禁、素材注册、字族栈（序光/白紫保持原样，朱批纸白用 editorial/humanist）、层叠顺序、与序光/白紫≥3 项非颜色差异。
- `test-theme-lint.cjs`：`runAll` 的 `builtinThemes` 2→3，增 `cinnabar-paper` themeId 校验。

### 1.3 浏览器核验重构

`smoke-cinnabar-paper.py` 由「真实文件导入候选」改为「内置直选」：设置页初始即 3 套内置 → 点朱批纸白卡片应用并跨窗同步 → 卡片不标记「本地导入」→ 令牌/字体/资产/阅读面/工具面板往返/窄窗/英语页 → 新窗默认仍白紫、内置无移除入口、切回白紫目录不变。
