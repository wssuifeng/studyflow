## 2. 已实施的源规则候选

- [x] **目标与范围**：根据资料、学习者基础和后续依赖确定必教内容，再设计检验证据；不从现有几道题倒裁目标。
- [x] **区分两类关系**：梳理学科对象的组成/分类/功能/协作等关系，以及学习者理解所需的先修关系；不把组成树直接当教学顺序，不开发新知识图谱系统。
- [x] **知识点边界**：以完整认知问题和解释/操作闭环拆合知识点，不按术语、字数或容器数拆分。
- [x] **正文前教学骨架**：复用并扩展已有作者对齐工件，写清核心问题、必要起点、关键关系、小节依赖与检验；不把作者表格强制展示给学习者。
- [x] **内容先行**：普通课先形成连续解释链，再选展示组件；英语按自然目标表达逆向设计可独立成立的递进序列，不强套理论课正文流程。
- [x] **整条主线复核**：按学习者起点审整个知识点及衔接，发现结构问题回到骨架重排，不以局部删行代替修复。
- [x] **表格与关系子项**：标题/对象范围/共同维度对应；组成、分类、协作、对比分清；必要定义与关系常显，合法跨类别辨析不误杀。
- [x] **清退冲突入口（源规则）**：重构通用主流程与必要提示词、合并英语增量，清理旧冻结提示；既有专项模板和真实课程待效果确认后迁移，不把源规则更新当内容已修。
- [ ] **工具协同与行为验证**：工具边界已明确，CPU/计算样课已完成主代理自审及真实只读校验；英语、专门合法跨类样例、独立Agent前向验证和用户效果未完成。不用格式/截图/关键词扫描认证教学正确。
