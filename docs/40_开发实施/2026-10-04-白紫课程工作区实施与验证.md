### 本轮根因修复

1. `DisplaySlot.vue` 的原生 `div` fallback 不消费 named slots，曾导致正式产品壳为空；现已区分原生 fallback 与候选组件：原生 fallback 将已有 named slots作为真实子节点渲染，候选组件继续接收 named slots/slot props。
2. `runtime.css` 的通用 `.app-shell.learning-shell` 规则覆盖了 `.learning-shell.panel-open` 三栏规则，工具区打开后主内容被压成第二行 22px，sticky footer 覆盖顶部返回按钮。现改为仅在 `:not(.panel-open)` 时应用默认两栏，工具打开后保持导航/阅读/工具三栏。
3. 主题导出烟测按 `parseTheme` 的规范化契约修正：旧 v1 输入缺少 `display` 时，导出结果应包含由 `presentation` 推导出的 canonical display，而不是与原始 JSON 字面完全相等。
4. 设置页“恢复默认主题”文案改为通用表述，避免默认主题切换后仍显示旧的“纸感书卷”。
