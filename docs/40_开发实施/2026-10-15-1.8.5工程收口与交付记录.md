## 6. 复核命令

在软件仓库，测试务必显式隔离workspace/basetemp，不能让兼容Web导入碰旧开发库：

```powershell
$env:PYTHONUTF8='1'
$env:STUDYFLOW_WORKSPACE=Join-Path (Get-Location) 'apps/desktop/test-results/new-isolated-workspace'
& packages/core/.venv/Scripts/python.exe -m pytest packages/core/tests -o addopts='' -q --basetemp apps/desktop/test-results/new-pytest-temp
npm --prefix apps/desktop run test:learning
npm --prefix apps/desktop run test:themes
npm --prefix apps/desktop run test:english
npm --prefix apps/desktop run build
& packages/core/.venv/Scripts/python.exe scripts/check_publish_boundary.py --worktree
```

原生：`python apps/desktop/scripts/smoke-native-tools.py`，只操作自身隔离进程/合成数据。默认TEMP对本机部分工具不可写时仅对子进程指定项目专属TEMP/TMP，不改系统环境/ACL。测试通过不授予真实课程写入或公共Skill同步权限。
