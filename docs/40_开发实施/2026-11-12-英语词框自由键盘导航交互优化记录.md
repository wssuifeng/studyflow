# 2026-11-12 · 英语词框自由键盘导航交互优化记录

> 性质：用户明确授权「优化英语专项交互手感，支持更自由的键盘操作，退格与左右能够直接将输入焦点移动到前方或后方」。本轮只改英语词框输入的**键盘导航与光标落位**（展示/输入层），不改任何业务规则（保存/检查/提交/冻结/幂等/CAS/草稿恢复均未触）。真实学习数据未读写；未安装/打包/同步Skill/提交推送；阶段与 `business_acceptance` 不推进。

## 1. 现状与问题

英语训练与复测共用 `TokenEditor.vue` 词框输入（每词一个 input）。优化前：
- Space/Enter 逐词 advance，末词 Space/Enter 触发检查（`inputAdvance`）。
- Backspace **仅在空框**时回退上一词；非空框词首按 Backspace 无跨词动作。
- 左右方向键只在词框内移动光标，**不能跨词框**；要回上一词必须先把当前词删空。

用户诉求：退格与左右能直接把焦点移到前/后词框，自由编辑而不破坏已输入内容。

## 2. 实施

### 2.1 纯函数 `tokenNavigate`（`shortcuts.ts`）

新增可单测的边界导航纯函数，返回 `{index, caret:'start'|'end'}` 或 `null`（交浏览器默认）：
- **ArrowLeft**：折叠光标在词首 → 上一词，光标落词尾。
- **ArrowRight**：折叠光标在词尾 → 下一词，光标落词首。
- **Backspace**：空框或光标在词首 → 上一词，**不删除内容**。
- **Delete**：光标在词尾 → 下一词（与 Backspace 对称），**不删除内容**。
- 仅在折叠光标（`selectionStart===selectionEnd`）处于边界时触发；框内光标移动、删除、选区折叠/删除全部保留原生行为。首/末词不越界。

### 2.2 `TokenEditor.vue` 接线

- `focusWord(index, select=true, caret='start'|'end'='end')`：导航时 `select=false` 并按 caret 用 `setSelectionRange` 精确落光标（不整词选中，避免误覆盖）；训练流程的纠错/advance 仍用默认 `select=true`。
- `key()` 重构：保留 IME 守卫（`isComposing||key==='Process'` 先行返回，真实中文 IME 不被劫持）与修饰键守卫（ctrl/meta/alt 交页面级 `englishShortcut`）；Enter/Space 仍防连发（`event.repeat` 守卫移入该分支）；导航键允许按住连续移词。
- 页面级 `keydown` 首行 `event.defaultPrevented` 短路，导航 preventDefault 后不会与页面快捷键双重处理；plain 方向键/退格不被 `englishShortcut`（仅 Ctrl/Meta 组合）认领，无冲突。

### 2.3 手感与可发现性

- `english.css`：词框 input 增加 `width .12s ease` 过渡，输入时框宽增长更平滑（`prefers-reduced-motion` 既有规则已覆盖为 none）。
- `EnglishTrainingPage.vue` footer 快捷键条增加 `← → 移词 · 退格 回退` 提示。
- 复测页 `EnglishRetestPage.vue` 复用同一 `TokenEditor`，**自动继承**本导航能力。
