# Java对象模型：合成演示材料

## 对象、引用与方法调用

变量可保存引用值。方法调用传递值副本；两个引用值可指向同一对象，因此通过参数修改该对象字段，调用者也能观察到改变。重新给形参赋值不会重绑调用者变量。Java源码不提供任意地址运算。

```java
class Device {
    String status = "STOPPED";
    void start() { status = "RUNNING"; }
    void stop() { status = "STOPPED"; }
}
```
